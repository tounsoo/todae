# Security

## Reporting a vulnerability

The channel for a vulnerability report is a [GitHub private security advisory](https://github.com/tounsoo/todae/security/advisories/new) on `tounsoo/todae`. The report does not go in a public issue.

## Scope

Only the published `@tounsoo/todae` package and the docs site at [todae.omsoo.design](https://todae.omsoo.design) are in scope.

## Acknowledgement

A vulnerability report receives an acknowledgement.
