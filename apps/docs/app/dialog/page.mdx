# Dialog

Centered native `<dialog>` via `showModal()`. Controlled `open`. Escape and backdrop dismiss are opt-out. No sheet morph.

Enter is opacity + scale(0.96→1) over 200ms. `@starting-style` where supported; `data-entered` is the fallback so unsupported engines still tween. Exit stays mounted until `transitionend` (160ms fallback).

<Example>
  <DialogBasic />
</Example>

Dark compact, backdrop dismiss off.

<Example>
  <DialogThemed />
</Example>

Overlays inherit tokens from `ThemeProvider` / `DensityProvider`. They do not inherit extra classes on the provider node.

iOS may still rubber-band the page behind an open overlay. Chrome may ignore `cancel.preventDefault()` without user activation. State still resyncs from the native `close` event.
