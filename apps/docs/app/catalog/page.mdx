# Catalog

Machine-readable map of Todae components and patterns. Apps, MCP, and these docs read the same `@tounsoo/todae/catalog.json`. This is the capability surface, not a drop-in Jev config.

```ts
import { search } from '@tounsoo/todae/catalog'

search('modal')[0]?.entry.name // Dialog
```
