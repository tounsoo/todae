# Composition

The package ships atoms and compounds. Recipes live in these docs. They are not `Combobox.*` exports.

## Atoms

Shared internals. Icon, Affix, and shell chrome. Product trees import compound parts, not the raw atoms. `Field.Icon` is a Field part backed by the Icon atom. It is not an atom in the consumer tree.

## Compounds

Public siblings. `Field`, `Button`, `Popover`, `Chip`, `OptionList`, `Dialog`, and `BottomSheet`. Compose them side by side. Never nest namespaces. One interactive role per compound root.

`Field.Root` is chrome only. Adornments follow DOM order. No `side` prop.

## Recipes

Worked examples that compose compounds and hooks. Combobox is a recipe, not a package namespace. The blocks below are static. They do not run.

Desktop (`presentation="popover"`). The closed control is a real Field. Spread hook trigger props onto `Field.Root`. The list lives in `Popover`.

```tsx
const cb = useCombobox({ presentation: 'popover' })

<Field.Root {...cb.getTriggerProps()}>
  <Field.Icon><Search /></Field.Icon>
  <Field.ChipInput chips={chips} inputValue={q} onInputValueChange={setQ} onCommit={onCommit} onChipRemove={onRemove} />
  <Field.Icon><ChevronDown /></Field.Icon>
</Field.Root>
<Popover {...cb.getPopoverProps()}>
  <OptionList {...cb.getListProps()}>...</OptionList>
</Popover>
```

Touch (`presentation="sheet"`). The closed control is `Button`. Search Field lives inside the sheet.

```tsx
const cb = useCombobox({ presentation: 'sheet' })

<Button {...cb.getTriggerProps()}>Pick…</Button>
<BottomSheet {...cb.getSheetProps()}>
  <Field.Root>
    <Field.Icon><Search /></Field.Icon>
    <Field.TextInput value={q} onChange={(event) => setQ(event.target.value)} />
  </Field.Root>
  <OptionList>...</OptionList>
</BottomSheet>
```

## Coming

`useCombobox` will ship headless. It owns open, value, aria, keyboard, and listbox ids. Exact `get*Props` names land in the hook PRD. The intent is:

- `useCombobox({ presentation: 'popover' | 'sheet' })`
- `getTriggerProps()` on `Field.Root` (desktop) or `Button` (touch)
- `getPopoverProps()` on `Popover`
- `getSheetProps()` on `BottomSheet`
- `getListProps()` on `OptionList`

No Trigger sugar component. No `Combobox.*` chrome.

## Never

```
Field.Root
  └─ Field.Button.Root          nested compound namespaces

Field.Root as a button that also hosts TextInput
  two roles on one root

Combobox.Root, Combobox.Trigger, or Combobox.Icon
  recipe chrome in the package

Dual-wiring aria or open outside useCombobox while also using the hook

Combobox behavior baked into Field

Touch closed control = Field pretending to be a button

Product trees importing the raw Icon atom instead of Field.Icon or Button.Icon

Docs that call Field.Icon or Button.Icon an atom
```
