# OptionList

`role="listbox"` with `aria-activedescendant`. Options are strings. Keyboard is Arrow, Home, End, Enter, and Space. Escape is not handled so it can close a parent Popover.

Single `value` is `string | null`. Multiple `value` is `string[]`. Selected options stay `font-weight: 400`.

<Example>
  <OptionListSingle />
</Example>

Multiple keeps a check gutter on every row. Selected fills the box and draws a CSS check.

<Example>
  <OptionListMultiple />
</Example>

`Option` is also `OptionList.Option`.
