# useCombobox

`useCombobox` owns a combobox's open state, value, input, highlight and ids. The compounds own the chrome: `Field` for the input, `Popover` or `BottomSheet` for the surface, `OptionList` for the list. There is no `Combobox.*` export. The [Combobox recipe](/recipes/combobox) shows single, multi, sheet, async and create.

`presentation` defaults to `'auto'`, which picks a sheet on a coarse pointer or a narrow viewport through [useSheetPresentation](/utilities/use-sheet-presentation). Force `popover` or `sheet` to keep it fixed, as the demo below forces `popover`. [Composition](/composition) lists which getter goes on which part.

## When to use

**When:** Searchable select — typeahead + list. Hook owns open/value/input; Field + Popover/BottomSheet + OptionList own chrome, as the [recipe](/recipes/combobox) shows. Auto sheet on coarse/narrow.

**When not:** Static on-page exclusive → Radio. Non-search list → [usePopover](/utilities/use-popover) + OptionList only. Action menu → [Menu](/menu). Exporting `Combobox.*` chrome (forbidden).
