# useCombobox

`useCombobox` owns a combobox's open state, value, input, highlight and ids. The compounds own the chrome: `Field` for the input, `Popover` or `BottomSheet` for the surface, `OptionList` for the list. There is no `Combobox.*` export. The [Combobox recipe](/recipes/combobox) shows single, multi, sheet, async and create.

`presentation: 'auto'` picks a sheet on a coarse pointer or a narrow viewport through [useSheetPresentation](/utilities/use-sheet-presentation). Force `popover` or `sheet` to keep it fixed.

## When to use

**When:** A searchable select: typing filters a list, and the hook owns open, value and input.

**When not:** A static, on-page exclusive choice → Radio. A list with no search → `usePopover` and `OptionList`. An action menu → [Menu](/menu).
