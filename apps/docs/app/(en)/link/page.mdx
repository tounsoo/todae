# Link

Links are native `<a href>` elements. There is no Link component: Todae styles every `a:any-link` in the `todae.base` layer, from the `link` contract tokens. A link keeps the text color and stands out by its underline, which darkens on hover, so it suits a neutral ink palette. An `<a>` without `href` is not a link and gets no link style.

</Example>

The rules sit in `:where()`, so they add no specificity, and in `todae.base`, under every component. Any class you add wins, including your router's link component:

```tsx
// Next.js renders an <a href>, so it gets the link style as it is.
<NextLink href="/billing">Billing</NextLink>
```

Restyle every link through the `link.fg.*`, `link.decoration.*` and `link.ring.focus` tokens. The `link.fg.current`, `link.decoration.current` and `link.decoration.current-thickness` tokens style the current link.

## Current page

Mark the link to the page you are on with `aria-current="page"`, or another `aria-current` value such as `step`. Its underline turns thicker, so it stands out without a hover. Your router sets the attribute: Next.js and React Router both let you pass it, and React Router's `NavLink` adds it for you.

## Accessible composition

**Todae handles:** Style only, on a native `<a href>`: an underline that marks the link while its color stays the text color, a focus ring on `:focus-visible` from `link.ring.focus`, and a thicker underline for any `aria-current` other than empty or `false`. The browser gives the link its role, its Enter key and its place in the tab order.

**You supply:** An `href`, so the element is a link at all. Link text that says where it goes. `aria-current` on the current link, from your router. A company link component should render the `<a>` itself and spread its rest props onto it, so `aria-current`, `aria-label` and `ref` reach it.

**Watch for:** A class that sets `text-decoration: none` or `outline: none`: any class wins over these rules, and without the underline a link looks like the text around it, as it has the same color. An `<a>` with `onClick` and no `href`, or a styled `span`, which has no link role and no keyboard. A link that does something on this page instead of going somewhere.

## When to use

**When:** Moving to another page or place: inline in text, in navigation, or as an action in an Alert.

**When not:** Doing something on this page, such as saving or opening a dialog → Button. A list of actions → Menu.
