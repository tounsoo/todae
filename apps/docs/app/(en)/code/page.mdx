# Code and Kbd

`Code.Root` is a native `<code>`, or with `as="pre"` a native `<pre>`, and `Kbd.Root` a native `<kbd>`, styled from the `code` and `kbd` contract tokens. Server Components can import them from `@tounsoo/todae/code` and `@tounsoo/todae/kbd`.

## Code

`Code.Root` keeps the text color around it and tints its box from that color, so it reads the same in a link or a primary button. It is a step smaller than the text around it. `Code.Root as="pre"` is a block that scrolls sideways when a line is too long, and code inside it, a `Code.Root` or a plain `<code>`, drops its own box.

```tsx
<Text.Root>
  Call <Code.Root>getPlan()</Code.Root> before you render the billing page.
</Text.Root>
<Code.Root as="pre" tabIndex={0} role="region" aria-label="Example code">
  <code>{source}</code>
</Code.Root>
```

A code block that scrolls needs `tabIndex={0}` so keyboard users can reach and scroll it, and `role="region"` with an `aria-label` so that stop has a name. `code.font.family` and `code.font.scale` (the size as a share of the text around it) set the font of inline code and code blocks alike. Restyle the inline box through `code.tint` (how much of the text color it takes), `code.radius`, `code.padding.x` and `code.padding.y`, and the block through the `code.block` tokens.

## Kbd

`Kbd.Root` is drawn as a key cap. For a shortcut, put one `Kbd.Root` per key inside an outer one, as HTML defines it: the outer one stays plain text in the color around it, so the joining `+` is not boxed.

```tsx
<Kbd.Root>
  <Kbd.Root>Ctrl</Kbd.Root>+<Kbd.Root>K</Kbd.Root>
</Kbd.Root>
```

Restyle keys through `kbd.fg`, `kbd.bg`, `kbd.border`, `kbd.border-width`, `kbd.radius`, `kbd.font.family`, `kbd.font.scale`, `kbd.padding.x` and `kbd.padding.y`.

## Accessible composition

**Todae handles:** Only the look. The parts stay native `<code>`, `<pre>` and `<kbd>` elements, and Todae adds no role, `tabindex` or name. `Code.Root` keeps the text color around it. A code block scrolls sideways when a line is too long, but Todae does not make it focusable.

**You supply:** For a code block that scrolls, the `tabIndex={0}`, `role="region"` and `aria-label` described above. A company code block component should require the name in its props instead of filling in one default. If it adds a copy button, give the button a name and report the result, for example with [useAnnouncer](/utilities/use-announcer).

```tsx
// The server entry, so a Server Component can render it.
import { Code } from '@tounsoo/todae/code';

type CodeBlockProps = { label: string; children: string };

export function CodeBlock({ label, children }: CodeBlockProps) {
  return (
    <Code.Root as="pre" tabIndex={0} role="region" aria-label={label}>
      <code>{children}</code>
    </Code.Root>
  );
}
```

**Watch for:** A default name such as "Code" on every block, which gives a page many regions with the same name; name each block after what it shows. `tabIndex={0}` without `role` and `aria-label`, which adds a Tab stop that has no name.

## When to use

**When:** Code → a name, value or snippet the reader types or reads in code. Kbd → a key or shortcut the reader presses.

**When not:** A label for a state or count → [Badge](/badge). Text that only needs a mono font → your own class, so screen readers and search do not treat it as code.
