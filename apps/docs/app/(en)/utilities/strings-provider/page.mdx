# StringsProvider

`StringsProvider` sets the text Todae writes by itself for everything inside it: the default names of parts with no words of their own, such as an icon-only `Dialog.Close`, and screen reader messages, such as those of `Field.Counter`. Todae ships English only. Pass the keys you want to change; each key you leave out comes from the nearest `StringsProvider` above, else English. It renders no element.

```tsx
const korean: Partial<Strings> = {
	close: '닫기',
	dismiss: '닫기',
	removeChip: (label) => `${label} 삭제`,
	moreChips: (count) => `${count}개 더 있음`,
	characterLimit: (max) => `최대 ${max}자`,
	charactersLeft: (remaining) => `${remaining}자 남음`,
	characterLimitReached: '글자 수 한도에 도달했습니다',
}

<StringsProvider strings={korean}>
	<App />
</StringsProvider>
```

A nested provider changes only the keys it passes:

```tsx
<StringsProvider strings={korean}>
	<StringsProvider strings={{ close: '취소' }}>
		{/* close is 취소 here; every other key is still Korean. */}
	</StringsProvider>
</StringsProvider>
```

A part's own prop still wins over the provider: a non-empty `aria-label` on a close button, `Attachment.Remove`, `Conversation.ScrollButton`, `Composer.Submit` or landmark, `removeLabel` on `Chip.Root`, `removeLabel`, `overflowLabel` or `panelLabel` on `ChipList.Root`, `chipRemoveLabel` or `overflowLabel` on `Field.ChipInput`, a non-empty `statusLabel` on `Steps.Item`, and `createLabel` on `useCombobox`. `useStrings()` returns the strings in effect, for your own components.

`Breadcrumbs` and `Pagination` from the server entries, `@tounsoo/todae/breadcrumbs` and `@tounsoo/todae/pagination`, render on the server without context, so they always use English. Pass `aria-label`, or import them from `@tounsoo/todae` to use the provider.

## Accessible composition

**Todae handles:** The text Todae writes by itself: default names of close buttons, landmarks, chip and attachment remove buttons, the `+N` chip and `Conversation.ScrollButton`, the sheet name from `useCombobox`, and the live messages of `Field.Counter`, `useClipboard` and `Conversation`, with the counter's description, and the status words of `Steps.Item`. A part's own prop wins, as listed above.

**You supply:** Every key your app shows, in the reader's language. The function keys get the label or the number, so place it where your language needs it and pick the plural form there. `StringsProvider` renders no element and sets no `lang`, so set `lang` on `<html>`, or on an element around a part in another language, so screen readers pronounce the words right. For `Breadcrumbs` and `Pagination` from the server entries, pass `aria-label` yourself, as above.

**Watch for:** An empty string. Unlike `undefined`, it replaces the string above it, so a close button with no words of its own loses the name Todae would have given it. Expecting `close` or `dismiss` to name a close button that shows words: the button is named by its own words, and the key is not used.

## When to use

### StringsProvider

**When:** Your app is not in English, or you want other wording for Todae's own text, across a whole app or one part of it.

**When not:** A name for one part → pass its prop, such as `aria-label`. Text you write yourself, such as a dialog title → it is yours to translate.

### useStrings

**When:** A component of your own that writes text Todae's strings cover, such as a close button's name.

**When not:** Text only your component writes → your own translations.
