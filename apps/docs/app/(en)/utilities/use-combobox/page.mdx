# useCombobox

`useCombobox` owns a combobox's open state, value, input, highlight and ids. Components own the chrome: `Field` for the input, `Popover`, `BottomSheet` or `Dialog` for the surface, `OptionList` for the list. There is no `Combobox.*` export. The [Combobox recipe](/recipes/combobox) shows single, multi, sheet, async and create.

`presentation` defaults to `'auto'`, which picks a sheet on a coarse pointer or a narrow viewport through [useSheetPresentation](/utilities/use-sheet-presentation). Force `popover` or `sheet` to keep it fixed, as the demo below forces `popover`. `dialog` puts the input and list in a `Dialog`, as the [Command palette](/recipes/command-palette) does. [Composition](/composition) lists which getter goes on which part.

## Accessible composition

**Todae handles:** `getInputProps()` and `getChipInputProps()` make the input a `role="combobox"` with `aria-expanded`, `aria-controls` (the listbox id), `aria-autocomplete="list"`, `autoComplete="off"`, and `aria-activedescendant` on the active option while open, so focus stays in the input. ArrowDown, ArrowUp, Home and End open the list and move the active option, skipping disabled ones. Enter selects or creates, Escape closes, and Tab closes. `getListboxProps()` gives `OptionList.Root` the listbox id and `tabIndex={-1}`. `getTriggerProps()` sets `aria-haspopup="dialog"`, `aria-expanded` and `aria-controls`. Escape in a popover returns focus to the input; a sheet returns it to the trigger when it closes.

**You supply:** The input's name: a [Label](/label) whose `htmlFor` is `ids.input`, or `aria-label` on `Field.Root` inside a sheet or dialog. Trigger text that names the field and its value. A more specific name for the sheet or dialog when needed: `getSheetProps()` and `getDialogProps()` use the `options` string ("Options" by default), and an `aria-label` after the spread replaces it. Status text: the hook reports `loading`, `error` and `isEmpty` but renders and announces none of them.

**Watch for:** Unmounting `OptionList.Root` while it is empty or loading: `aria-controls` then points at nothing, so set `hidden` instead. Your own `onKeyDown`, `onFocus` or `onBlur` after the spread, which replaces the hook's handlers. Buttons or links inside an option.

## When to use

**When:** Searchable select — typeahead + list. Hook owns open/value/input; Field + Popover/BottomSheet + OptionList own chrome, as the [recipe](/recipes/combobox) shows. Auto sheet on coarse/narrow.

**When not:** Static on-page exclusive → Radio. Non-search list → [usePopover](/utilities/use-popover) + OptionList only. Action menu → [Menu](/menu). Exporting `Combobox.*` chrome (forbidden).
