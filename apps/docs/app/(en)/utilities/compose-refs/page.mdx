# composeRefs

`composeRefs(...refs)` returns one callback ref that sets every ref you give it. Use it to keep a ref of your own on an element whose `ref` slot a hook's prop getter already fills.

```tsx
const popover = usePopover({ open, onOpenChange: setOpen });
const mine = useRef<HTMLDivElement>(null);
const { ref, ...props } = popover.getPopoverProps();

<Popover.Root {...props} ref={composeRefs(ref, mine)}>…</Popover.Root>
```

Each call returns a new callback, so React detaches and reattaches it on every render.

The live popover is on [Popover](/popover). Its demo spreads `getPopoverProps()`, which takes no props, so a ref of your own has to be composed with the one it returns.

## When to use

**When:** Two or more refs on one element, such as your own and one from a prop getter that takes no props, like `getPopoverProps()`.

**When not:** One ref → pass it as is. A getter that takes your props, such as `popover.getTriggerProps({ ref })` → pass your ref through it.
