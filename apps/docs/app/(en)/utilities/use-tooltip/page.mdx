# useTooltip

`useTooltip` is the open machine behind [Tooltip](/tooltip). Spread `getTriggerProps` on the trigger and `getTooltipProps` on `Tooltip.Root`, which is tip chrome only. Hover waits `showDelay` (300ms by default), focus opens at once, and a coarse pointer uses focus only. Pass `interactive: true` for a tip with links: it becomes a non-modal tip dialog that Tab can move into, and `Tooltip.Root` then needs exactly one of `aria-label` or `aria-labelledby`.

Overflow chips and other non-button triggers use the hook directly. Mark a non-tabbable wrap with `tabIndex={0}`. `Button.Root` already tips its own label, so set `tooltip={false}` on it when the hook owns the tip.

```tsx
const tooltip = useTooltip();

<>
  <span {...tooltip.getTriggerProps({ tabIndex: 0 })}>
    <Chip.Overflow overflowCount={2} />
  </span>
  <Tooltip.Root {...tooltip.getTooltipProps()}>Schema, Docs</Tooltip.Root>
</>
```

## Accessible composition

**Todae handles:** `getTriggerProps` adds pointer and focus handlers and, while the tip is open, an `aria-describedby` that points at it. Focus opens the tip at once, so keyboard users get it too. `Tooltip.Root` adds `role="tooltip"`, or `role="dialog"` with `interactive: true`. Escape closes the tip, and from inside an interactive one sends focus back to the trigger.

**You supply:** A trigger that takes focus. The getter adds no `tabIndex` or role, so give a wrap that is not tabbable `tabIndex={0}`, as above. A name for the trigger itself: `aria-describedby` makes the tip a description, not a name, so an icon-only trigger needs `aria-label`. With `interactive: true`, exactly one of `aria-label` or `aria-labelledby` on `Tooltip.Root`, and only links inside.

**Watch for:** While open, the getter's `aria-describedby` replaces one you passed instead of joining it, so that description is not read while the tip shows. Pass your own `onFocus`, `onBlur`, `onPointerEnter` and `onPointerLeave` through `getTriggerProps(props)`; put after the spread, they replace the tip's. Set `tooltip={false}` on a `Button.Root` when the hook owns its tip.

## When to use

**When:** A short hint on a trigger that is not a `Button.Root`, or a tip with links (`interactive: true`).

**When not:** An icon-only or truncated `Button.Root` → its built-in tooltip. Action menus → [Menu](/menu). Other anchored panels → [usePopover](/utilities/use-popover). Long help → Description.
