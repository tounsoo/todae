# GlyphsProvider

Todae ships no icon set. A few parts still need a glyph to look whole, such as the cross on a close button or the check in a checkbox, so Todae draws those itself. `GlyphsProvider` sets them for everything inside it, so they can come from your icon library instead. Pass the keys you want to change; each key you leave out comes from the nearest `GlyphsProvider` above, and `null` brings back Todae's own. It renders no element.

```tsx
import { Check, ChevronDown, ChevronRight, Ellipsis, X } from 'lucide-react';

<GlyphsProvider
  glyphs={{
    close: <X />,
    check: <Check />,
    chevron: <ChevronDown />,
    separator: <ChevronRight />,
    ellipsis: <Ellipsis />,
  }}
>
  <App />
</GlyphsProvider>
```

Draw `chevron` pointing down: a closed disclosure or tree item turns it toward its text, a closed nav branch toward the end of its row, and a month button turns it toward its month. Draw `sort` pointing up: a descending column turns it. Draw `separator` pointing toward the next item in a left-to-right page, and `back` pointing left, toward the start of a left-to-right line: both are mirrored in right-to-left. In `Field.Select`, the chevron sits over the browser's picker icon when the browser supports `::picker-icon` and the select is the field's last part; otherwise the browser's icon stays. The check mark beside a selected `<option>` is the browser's own.

Each glyph that is an `svg` or `img`, as icon libraries render, takes the size of the box its part gives it, whatever its own `size` or `width`: `button.icon.size` in a close part, `Attachment.Remove` and `Conversation.ScrollButton`, `chip.icon.size` in a chip, `field.icon.size` in a select and a date or time picker, `calendar.nav.icon.size` in a calendar's month buttons, `drilldown.back.icon.size` in `Drilldown.Back`, `calendar.heading.icon.size` in its heading, `tree.chevron.size` in a tree, `nav.chevron.size` in a nav branch, `steps.icon.size` in a step's marker, `table.sort.icon.size` in a sort button, the whole box in a checkbox, and a box about the size of the text elsewhere. An icon drawn in `currentColor` takes the part's text color.

The radio dot, the switch thumb, the spinner and the selected tab's bar are shapes drawn from tokens, not glyphs, so they are not here.

`Breadcrumbs`, `Pagination` and `Disclosure` from the server entries, such as `@tounsoo/todae/breadcrumbs`, render on the server without context, so they always draw Todae's own. Import them from `@tounsoo/todae` to use the provider.

## Accessible composition

**Todae handles:** Keeping every glyph out of the accessible name: it is inside an `aria-hidden` element, or in a button named by `aria-label`, such as a chip's remove button. A close part with no content is named by the `close` or `dismiss` string of [StringsProvider](/utilities/strings-provider), and `Attachment.Remove` by `removeAttachment`, and shows no tooltip unless you pass `tooltip`.

**You supply:** Icons that read as what they stand for, in every key you set: a cross for close, a check mark for check. The names stay Todae's, so an icon that means something else leaves the picture and the name apart.

**Watch for:** Text as a glyph, such as `'×'`: it renders in the part's font, so it may not match your icons. Use an `svg` icon.

## When to use

### GlyphsProvider

**When:** Your design system uses an icon library, and Todae's crosses, checks, chevrons, separators or ellipses should match it, across a whole app or one part of it.

**When not:** An icon in a slot such as `Button.Icon`, `Field.Icon` or `Alert.Icon` → put it there directly. A different icon for one close button or chip → pass it as that part's content or `removeIcon`.

### useGlyphs

**When:** A component of your own that should draw the glyph a GlyphsProvider sets for Todae's parts, such as a close cross.

**When not:** An icon only your component uses → your icon library.
