# usePopover

`usePopover` is the open machine behind [Popover](/popover). Spread `getTriggerProps` on the trigger and `getPopoverProps` on `Popover.Root`, which is surface chrome only. [Menu](/menu) and the [Combobox recipe](/recipes/combobox) are built on it.

An outside press and Escape call `onOpenChange(false, reason)` with `outside` or `escape`. The trigger toggles, so it reports `trigger` on both open and close. An owner can veto one reason and keep the others; in `onOpenChange(open, reason)`, check `open === false` before vetoing a `trigger` close. [Popover](/popover) has a veto demo. `haspopup` sets the trigger's `aria-haspopup`. `anchorRef` is the CSS anchor when the trigger is not the element `getTriggerProps` marks; do not pass it and also spread `getTriggerProps`.

```tsx
const [open, setOpen] = useState(false);
const [value, setValue] = useState<string | null>(null);
const { getTriggerProps, getPopoverProps } = usePopover({ open, onOpenChange: setOpen, haspopup: 'listbox' });

<>
  <Button.Root tooltip={false} {...getTriggerProps()}>{value ? `Fruit: ${value}` : 'Choose fruit'}</Button.Root>
  <Popover.Root {...getPopoverProps()}>
    {/* Selecting does not close the popover: the owner closes it. */}
    <OptionList.Root aria-label="Fruit" value={value} onValueChange={(next) => { setValue(next); setOpen(false); }}>
      <OptionList.Option value="apple">Apple</OptionList.Option>
    </OptionList.Root>
  </Popover.Root>
</>
```

## Accessible composition

**Todae handles:** `getTriggerProps` adds `aria-expanded`, `aria-controls` with the surface's id, `aria-haspopup` (`dialog` unless you set `haspopup`) and an `onClick` that toggles. On open, focus moves into the surface: `initialFocusRef`, else its first tabbable element, else the surface. Escape and an outside press ask to close. On close, focus goes to `restoreFocusRef`, else back to what had focus before it opened, unless the person already moved it elsewhere.

**You supply:** The trigger element. `getTriggerProps` sets no role, `tabIndex` or key handling, so spread it on a `<button>` or `Button.Root`. The surface's role and name: for `haspopup: 'dialog'`, `Popover.Root` with `role="dialog"` and `aria-label` or `aria-labelledby`; for `listbox`, a role-less surface with a named `OptionList.Root` inside, as above. Your own `onClick`, `ref` and `style` go through `getTriggerProps(props)`, which merges them. Your `onClick` runs first, and calling `event.preventDefault()` in it skips the toggle.

**Watch for:** Props put after the `getTriggerProps()` spread replace what it set: a later `onClick` drops the toggle. A trigger keeps `aria-expanded` and `aria-haspopup` while `enabled` is false, so disable the trigger too. A role-less popover left on the default `haspopup` announces a dialog that is not there.

## When to use

**When:** A non-modal surface anchored to a trigger, with open and dismiss on the hook and chrome on `Popover.Root`.

**When not:** An action menu → [Menu](/menu). Modal, focus-trapped work → Dialog. A mobile full-bleed picker → BottomSheet, or [useSheetPresentation](/utilities/use-sheet-presentation) to choose at runtime. A text-only hover hint → [Tooltip](/tooltip).
