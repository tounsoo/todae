# useField

`useField()` joins your own control to the nearest `Field.Root`, the way the built-in parts join it. Spread `getControlProps()` on the control: it carries the Root's `id`, `name`, `disabled`, `aria-invalid`, the merged `aria-describedby`, the Root's name unless the control names itself, and a ref so a press on the shell focuses the control. The shell draws its focus ring for it too. For a control that is not a native form element, call `getControlProps(props, { native: false })`: it sets `aria-disabled` instead of `disabled` and leaves out `name`, which only form elements submit. Read `disabled` from `useField()`, the Root's, to skip the tab stop and ignore keys; a `disabled` or `aria-invalid` you pass in adds to the Root's and never clears it, so combine your own with it in the same checks. `Label htmlFor` only names labelable elements, so name a custom element through `aria-labelledby` on the Root.

```tsx
function Stars(props) {
	const field = useField()
	return <span {...field.getControlProps({}, { native: false })} role="slider" tabIndex={field.disabled ? -1 : 0} … />
}
```

## Accessible composition

**Todae handles:** `getControlProps()` gives your control the Root's `id`, its `aria-describedby` merged with yours, `aria-invalid` while the Root is invalid, the Root's `aria-label` or `aria-labelledby` unless the control names itself, and `disabled`, or `aria-disabled` with `{ native: false }`. Its ref lets a press on the shell focus the control, and the shell draws its focus ring while the control or anything inside it is focus-visible. The Root's `disabled` and `invalid` include a surrounding [Fieldset](/fieldset)'s.

**You supply:** What the control is and does: a `role`, since the hook sets none, a `tabIndex`, keyboard handling, and the role's state, such as `aria-valuenow`, `aria-valuemin` and `aria-valuemax` for a `slider`. A name through `aria-labelledby` or `aria-label` on `Field.Root`. While `field.disabled` is true, skip the tab stop and ignore keys.

**Watch for:** An `aria-describedby` or `ref` spread after `getControlProps()` replaces the wired one; pass yours in as `getControlProps(props)` so they merge. The `aria-disabled` from `{ native: false }` does not stop focus or keys. Every control that calls `getControlProps()` gets the same `id`, so use one per `Field.Root`.

## When to use

**When:** Your own control, such as a rating or a color well, sits inside `Field.Root` and needs its id, name, description and invalid state.

**When not:** A built-in part already fits → use it. A control outside any `Field.Root` → wire its own ids.
