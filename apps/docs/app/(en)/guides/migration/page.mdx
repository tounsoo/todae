# Migrate an existing app

Move an app that still uses a removed prop or token onto the current package. Each section below is one break already in the release. Do the ones your app still has.

## Install the current release

Install the `latest` dist-tag.

```sh
npm install @tounsoo/todae@latest
```

Do not install version `0.0.0-stage`. That version is a stub published on 2026-10-16 so the package name could exist on npm before trusted publishing. npm describes it as "Temporary package placeholder for staged publishing". It is not a dist-tag. `npm dist-tag ls @tounsoo/todae` shows `latest` only, and `latest` does not point at `0.0.0-stage`.

A maintainer with publish access deprecates that version by hand. The release workflow does not. The command and the message are in [Deprecate the placeholder version](https://github.com/tounsoo/todae/blob/main/CONTRIBUTING.md#deprecate-the-placeholder-version).

## Replace Text `size`

`Text.Root` no longer takes `size`. In development it logs an error and drops the prop. Body text stays on `font.size.3`. A heading's `as` still picks its scale.

Replace `size="label"` with `variant="label"`.

```tsx
<Text.Root size="label">Name</Text.Root>
```

```tsx
<Text.Root variant="label">Name</Text.Root>
```

Replace any other `size` by setting `font-size` from the foundation step that size used. Those steps were `text.size.*`. Those tokens are gone. Use `font.size.*`, which is `--todae-font-size-*`. Changing the token resizes every use of that step.

| Old `size` | Replacement |
| --- | --- |
| `s` | `var(--todae-font-size-2)` |
| `m` | Omit `size`. Body is already `font.size.3`. |
| `l` | `var(--todae-font-size-4)` |
| `xl` | `var(--todae-font-size-5)` |
| `2xl` | `var(--todae-font-size-6)` |

```css
.lede {
  font-size: var(--todae-font-size-4);
}
```

Heading scales stay h1 on `font.size.6`, h2 on `font.size.5`, h3 on `font.size.4`, h4 and h5 on `font.size.3`, and h6 on `font.size.2`. See [Text](/text).

## Replace Avatar `size` and `Avatar.Group`

Remove `size` from `Avatar.Root`. In development it logs an error and drops the prop. The avatar draws at `avatar.size`, which is `2rem` (`--todae-avatar-size`). `data-size` is no longer rendered. `AvatarSize` is removed. The `avatar.size.sm`, `avatar.size.md`, and `avatar.size.lg` tokens are gone.

| Old `size` | `--todae-avatar-size` |
| --- | --- |
| `sm` | `1.5rem` |
| `md` | `2rem`, the default |
| `lg` | `2.5rem` |

```css
.avatar {
  --todae-avatar-size: 1.5rem;
}
```

Set that variable, or set `inline-size` and `block-size`, on the avatar or an ancestor. A `ThemeProvider` or a `DensityProvider` between that ancestor and the avatar declares the token again. A scoped theme root does too. You can also override `avatar.size` on [ThemeProvider](/tokens).

`Avatar.Group` is removed, with `AvatarGroupProps` and the tokens `avatar.group.overlap`, `avatar.group.ring.width`, and `avatar.group.ring.color`. Replace the group with the [Avatar group](/recipes/avatar-group) recipe. Copy that recipe's CSS. The ring color there is `--avatar-group-ring`, set on the stack, and it falls back to the surface color.

```tsx
<Avatar.Group aria-label="Assignees" size="md">
  <Avatar.Root label={person.name}>
    <Avatar.Fallback>{person.initials}</Avatar.Fallback>
  </Avatar.Root>
</Avatar.Group>
```

```tsx
<div role="group" aria-label="Assignees" className={styles.avatarGroup}>
  <Avatar.Root className={styles.avatar} label={person.name}>
    <Avatar.Fallback>{person.initials}</Avatar.Fallback>
  </Avatar.Root>
</div>
```

## Replace the component type scale

Remove `text.size.2` through `text.size.6`, and remove every `--todae-text-size-*` variable. Remove `prose.size` and `prose.h1.size` through `prose.h6.size`. Remove `--todae-prose-size` and `--todae-prose-h1-size` through `--todae-prose-h6-size`.

Point those sizes at `font.size.*`. The same step number is the replacement, so `text.size.4` becomes `font.size.4` and `--todae-font-size-4`. Body stays step 3. Headings and prose stay on the scales in the Text section above.

Keep the foundation tokens `font.size.1` through `font.size.6`. Keep component tokens whose path ends in `font.size`, such as `text.label.font.size`, `field.font.size`, and `button.base.font.size`. Those still reference a `font.size.*` step.

Search the app for the removed names.

```sh
rg -n 'text\.size\.|prose\.size|prose\.h[1-6]\.size|--todae-text-size-|--todae-prose-' .
```
