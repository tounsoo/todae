# Slider

`Slider.Root` is a native `<input type="range">`. The browser handles arrow keys, Page Up and Down, Home and End, and announces the value. Todae paints the thumb and the filled track from `slider.fill`.

<Example of={SliderVolume} block />

Server Components can import it from `@tounsoo/todae/slider`. Inside a [Fieldset](/fieldset), `Slider.Root` from `@tounsoo/todae` takes the Fieldset's `disabled` and `invalid`, and its own `aria-invalid` wins. `@tounsoo/todae/slider` reads no Fieldset, since that needs a client component. Name it with [Label](/label) and show the current value as text nearby when the exact number matters. Restyle through `slider.fill` and `slider.ring.focus`. `mode="range"` puts two thumbs on one track. A thumb stops when it meets the other.

## Range

`mode="range"` places two native range inputs on one track. `startLabel` and `endLabel` name the two thumbs. `startValueText` and `endValueText` are what a screen reader says for each thumb instead of the number. `value` holds the start and the end. `onValueChange` receives the next pair. The filled part runs from the start thumb to the end thumb. `name` is the two field names. Omit `name` and neither input submits.

## Accessible composition

**Todae handles:** Styles. One thumb is a native `<input type="range">` with the `slider` role, its value, minimum and maximum, and the keys above. `mode="range"` also stops a thumb where it meets the other, fills the track between them, and moves the nearer thumb when the empty track is pressed. Todae paints the thumb and the filled track from `slider.fill` and draws a focus outline from `slider.ring.focus` while it is focus-visible.

**You supply:** A name. For one thumb, a [Label](/label) with `htmlFor` or `aria-label`. For two, `startLabel` and `endLabel`. `aria-valuetext` on one thumb, or `startValueText` and `endValueText` on a range, when the number alone does not mean much, such as `"40%"` or `"Medium"`. The current value as visible text when the exact number matters, and `aria-describedby` for any hint.

**Watch for:** A `div` slider built by hand needs its role, value attributes and keys added one by one; inside a Field, see [useField](/utilities/use-field). An `outline: none` of yours removes the focus ring.

## When to use

**When:** Picking a value in a range where the rough position matters more than the exact number, such as volume or zoom.

**When not:** An exact number → [Field.NumberInput](/field/number-input). A few named choices → [Radio](/radio). Showing progress the user does not control → [Progress](/progress).
