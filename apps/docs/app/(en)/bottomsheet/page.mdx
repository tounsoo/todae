# BottomSheet

Modal custom portal. Not a native dialog. Scrim, focus trap, Escape, `aria-modal`, scroll lock. Mid and full snap. Drag from the grabber or from the body at `scrollTop === 0`. List scroll stays free.

Enter slides from `translateY(100%)` into the snap height (first-frame pose, not a height tween). Both overlays use `data-entered`; Dialog also keeps `@starting-style`. Exit slides off and unmounts on `transitionend` (240ms fallback). Drag keeps `transition: none`.

<Example>
  <BottomSheetBasic />
</Example>

The portal re-applies appearance, density, and theme overrides. Extra classes on the provider node do not follow the portal.

## Consumer sketch

Touch Combobox later. A button opens this sheet. Search plus options live in the sheet. Desktop typeahead-while-open stays a popover in the Combobox PRD.

  <ComboboxTouchSketch />
</Example>

## When to use

**When:** Modal sheet from the bottom (touch Combobox closed control, mobile pickers). Scrim, focus trap, snap mid/full.

**When not:** Desktop anchored non-modal → Popover. Centered confirm/form → Dialog. Hover tip → Tooltip.
