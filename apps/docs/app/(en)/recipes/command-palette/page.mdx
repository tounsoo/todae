# Command palette

A recipe, not a package namespace. [Dialog](/dialog) holds the palette, and [useCombobox](/utilities/use-combobox) owns the input, filtering, the active option and ids. There is no `CommandPalette.*` export.

Use the `sheet` presentation, which keeps the input and the list together in one modal surface, and wire its open state to `Dialog.Root` instead of `BottomSheet.Root`. Keep `value` at `null` and run the command in `onChange`, so choosing one leaves nothing selected. Control the input text and clear it when the palette opens, so each search starts from the full list.

```tsx
const cb = useCombobox({
  options: commands,
  presentation: 'sheet',
  value: null,
  onChange: (value: string | null) => { if (value) run(value) },
  inputValue: query,
  onInputValueChange: setQuery,
  onOpenChange: (open) => { if (open) setQuery('') },
})

<Button.Root {...cb.getTriggerProps()} aria-keyshortcuts="Control+K Meta+K">
  Search commands
</Button.Root>
<Dialog.Root open={cb.open} onOpenChange={cb.setOpen} initialFocusRef={cb.inputRef} aria-label="Commands">
  <Field.Root id={cb.ids.input} aria-label="Command">
    <Field.TextInput {...cb.getInputProps()} placeholder="Type a command" />
  </Field.Root>
  <OptionList.Root {...cb.getListboxProps()}>
    {cb.items.map((item) => (
      <OptionList.Option key={item.id} {...cb.getOptionProps(item)} />
    ))}
  </OptionList.Root>
  <Text role="status">{cb.isEmpty ? 'No matching commands.' : ''}</Text>
</Dialog.Root>
```

The shortcut is a `keydown` listener on `document` that calls `cb.setOpen(true)` for Ctrl+K or ⌘K. It checks `event.code`, the physical key, so it works on any keyboard layout. `aria-keyshortcuts` on the trigger tells assistive technology about it. Escape and a click on the backdrop close the dialog, and focus goes back to the element that had it when the palette opened. The empty message sits in a `role="status"` region, so screen readers announce it.

## When to use

**When:** One place to search and run actions across an app.

**When not:** Picking a value for a form field → the [Combobox recipe](/recipes/combobox). A short, fixed list of actions → [Menu](/menu).
