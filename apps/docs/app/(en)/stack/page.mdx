# Stack

Gap is `stack.gap` (density-aware). There is no `gap` prop.

Server Components can import it from `@tounsoo/todae/stack`. That entry has no `'use client'` and no hooks; the main `@tounsoo/todae` entry is a client module.

<Example>
  <StackButtons />
</Example>

## When to use

**When:** Flex row or column spaced by density-aware `stack.gap`. Spacing between fields or buttons.

**When not:** Label-to-control gap → `.labelled-field` wrapper (`field.label.gap`). Custom gap values (no gap prop). Attached button row → Button.Group.
