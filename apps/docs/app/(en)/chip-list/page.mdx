# ChipList

A list of chips that shows up to `maxRows` rows and folds the rest into a +N button. +N opens a popover with the folded chips. Name the list with `aria-label` or `aria-labelledby`.

With `onRemove`, each chip gets a remove button. Once `chips` drops the focused chip, focus moves to the chip that now fills its place, else the one before it, else +N, else the list.

```tsx
<ChipList.Root
  aria-label="Tags"
  chips={tags}
  maxRows={1}
  onRemove={(index) => setTags((current) => current.filter((_, i) => i !== index))}
/>
```

In the popover, Tab past the last chip goes on to the control after +N, Shift+Tab from the first chip returns to +N, and Escape closes it and returns to +N.

`getTone` gives each chip a `tone`, as on Chip. To color tags by name, pass `categoryTone`, which maps a string to the same category tone every time: `getTone={(value) => categoryTone(value)}`.

## Accessible composition

**Todae handles:** The chips sit in a `role="list"` element that gets your `aria-label`, `aria-labelledby`, `aria-describedby` and `aria-details`. Each chip in the row, and +N, is a `role="listitem"`. +N is a native button with `aria-expanded`, `aria-controls` and `aria-haspopup="dialog"`, named by `overflowLabel` or the `moreChips` string. The popover is a `role="dialog"` named by `panelLabel` or the `moreChipsPanel` string. Remove buttons are named by `removeLabel` or `Remove {value}`. Focus after a removal, and Tab, Shift+Tab and Escape in the popover, work as described above. The measure row is `aria-hidden` and `inert`.

**You supply:** `aria-label` or `aria-labelledby` that says what the chips are, such as "Applied filters". Without one the list has no name. A `removeLabel` when `Remove {value}` is not enough on its own. A stable `getKey` when two chips can share a value, so focus follows the right one. Any announcement of a change made elsewhere, such as filters cleared by another button: the list announces nothing.

**Watch for:** Naming a wrapper instead of the list: `aria-label` on `ChipList.Root` reaches the list, but on your own `<div>` around it, it names nothing. Removing by value when values repeat: `onRemove` passes the index of the chip that was pressed. A wrapper that always passes `onRemove`, which gives read-only chips a remove button.

## When to use

**When:** Chips outside a text field, such as applied filters, read-only tags or recipients, capped at `maxRows` with a +N count.

**When not:** Typing new chips → `Field.ChipInput`. Picking from options → [Combobox recipe](/recipes/combobox). Selectable or toggle chips → Checkbox / Button.Root. One chip → `Chip.Root`. Your own markup around the fold → [useChipList](/utilities/use-chip-list).
