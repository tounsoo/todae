# Field.Textarea

`Field.Textarea` is a native `<textarea>` for multi-line text inside a [Field](/field). Height is CSS only: `rows` sets the height and the drag floor, and `maxRows` sets the cap. Padding sits on the textarea, inside the shell.

```tsx
<Field.Root aria-label="Note">
  <Field.Textarea value={note} onChange={(event) => setNote(event.target.value)} rows={3} />
</Field.Root>
```

## Height

`autoGrow` uses `field-sizing: content` where the browser has it, and grows with no cap when `maxRows` is omitted. Browsers without `field-sizing` stay at `rows` and scroll inside. Do not set an inline `height` when `autoGrow` is on; it overrides the growth.

`autoGrow` with `maxRows={6}`.

```tsx
<Field.Root aria-label="Note">
  <Field.Textarea value={note} onChange={(event) => setNote(event.target.value)} autoGrow maxRows={6} />
</Field.Root>
```

## Highlights

`highlights` draws ranges of the text as tokens, on a layer behind the textarea that copies its type, padding and scroll. Each range is `{ start, end }`, with an optional `kind` set as `data-kind`, an `anchorName` a popover can sit at, and `draw: false` to keep only the anchor. [useMentions](/utilities/use-mentions) sets it through `getTextareaProps()`, for mentions and slash commands. Tokens read `field.token.bg` and `field.token.radius`.

## Accessible composition

**Todae handles:** The textarea takes `id`, `name`, `aria-label`, `aria-labelledby` and `aria-describedby` from `Field.Root`, and native `disabled` and `aria-invalid` from the Root or a surrounding [Fieldset](/fieldset).

**You supply:** A name, through a [Label](/label) whose `htmlFor` is the Root `id` or `aria-label` / `aria-labelledby` on the Root.

**Watch for:** An inline `height` with `autoGrow` on stops the growth. Without `field-sizing`, an `autoGrow` textarea stays at `rows` and scrolls.

## When to use

### Field.Textarea

**When:** Multi-line free text such as notes, messages or descriptions. `rows` sets the starting height, and `autoGrow` grows it up to `maxRows` with CSS only.
**When not:** Single-line values, use `Field.TextInput`. Separate tags or tokens, use `Field.ChipInput`. Rich text or formatting, not shipped.
