# Field.ColorInput

`Field.ColorInput` is a native `<input type="color">` inside a [Field](/field), drawn as a swatch one field line tall. Its value is a `#rrggbb` string. A press elsewhere in the field opens the browser's picker. To show the value as text, put a `Field.Affix` after it. On its own, the field is as wide as the swatch.

```tsx
<Label.Root htmlFor={id}>Accent</Label.Root>
<Field.Root id={id}>
	<Field.ColorInput value={color} onValueChange={setColor} />
	<Field.Affix>{color}</Field.Affix>
</Field.Root>
```

## Accessible composition

**Todae handles:** The input takes `id`, `name`, `aria-label`, `aria-labelledby` and `aria-describedby` from `Field.Root`, and native `disabled` and `aria-invalid` from the Root or a surrounding [Fieldset](/fieldset). A mouse press elsewhere in the field focuses the input and, where the browser allows, opens its picker. The browser handles the keyboard and the picker.

**You supply:** A name, through a [Label](/label) whose `htmlFor` is the Root `id` or `aria-label` / `aria-labelledby` on the Root. `onChange` or `onValueChange`; without either, the input is read-only.

**Watch for:** The swatch shows the color but not its value; put the value in a `Field.Affix` when people need to read it.

## When to use

### Field.ColorInput

**When:** Pick one color with the browser's picker, such as a brand or accent color.

**When not:** A color in another form, such as `oklch()` → `Field.TextInput`, with a `Field.ColorInput` in its own field beside it for picking. A fixed set of colors → RadioGroup.
