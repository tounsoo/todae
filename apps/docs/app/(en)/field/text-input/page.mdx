# Field.TextInput

`Field.TextInput` is a native `<input>` for one line of text inside a [Field](/field). Its `value` is a string and `onChange` is required; `onValueChange` also gets the new string. `type` takes `text`, `search`, `email`, `url`, `tel`, `password` or `number`. Times have their own parts, [Field.TimeInput](/field/time-input) and [Field.DateTimeInput](/field/date-time-input). For a typed date, read the text with `parseDate`, beside a [Field.DatePicker](/field/date-picker). Put `id` on `Field.Root`.

```tsx
const id = useId();

<Field.Group>
  <Label.Root htmlFor={id}>Email</Label.Root>
  <Field.Root id={id}>
    <Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
  </Field.Root>
</Field.Group>
```

## Number

`Field.TextInput` with `type="number"` stays a native input, with the browser's own spinner, styled from the field tokens with figures lined up. `value` is the input's string: `"2"`, or an empty string while the input is incomplete. Constrain it with the native `min`, `max` and `step`.

```tsx
const id = useId();

<Field.Group>
  <Label.Root htmlFor={id}>Seats</Label.Root>
  <Field.Root id={id}>
    <Field.TextInput type="number" min={1} max={20} value={quantity} onChange={(event) => setQuantity(event.target.value)} />
  </Field.Root>
</Field.Group>
```

## Accessible composition

**Todae handles:** The input takes `id`, `name`, `aria-label`, `aria-labelledby` and `aria-describedby` from `Field.Root`, and native `disabled` and `aria-invalid` from the Root or a surrounding [Fieldset](/fieldset).

**You supply:** A name, through a [Label](/label) whose `htmlFor` is the Root `id` or `aria-label` / `aria-labelledby` on the Root.

**Watch for:** An `id` on `Field.TextInput` is replaced by the Root's; put it on the Root. A number input whose value is incomplete reports an empty string, so don't treat an empty `value` as a cleared field while the user is still typing.

## When to use

### Field.TextInput

**When:** Single-line typed value inside `Field.Root` (text / search / email / url / tel / password), or a native number.

**When not:** A time → `Field.TimeInput` or `Field.DateTimeInput`. Multi-value tokens → `Field.ChipInput`. Multi-line → `Field.Textarea`. Standalone without Root.
