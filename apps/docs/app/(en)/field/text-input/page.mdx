# Field.TextInput

`Field.TextInput` is a native `<input>` for one line of text inside a [Field](/field). Its `value` is a string. Pass `onChange` for the event or `onValueChange` for the new string, or both; without either, the input is read-only. `type` takes `text`, `search`, `email`, `url`, `tel` or `password`. A number is [Field.NumberInput](/field/number-input). For a typed date, time, or date and time, read the text with `parseDate`, `parseTime` or `parseDateTime`, beside a [Field.DatePicker](/field/date-picker), [Field.TimePicker](/field/time-picker) or [Field.DateTimePicker](/field/date-time-picker). Put `id` on `Field.Root`.

```tsx
const id = useId();

<Field.Group>
  <Label.Root htmlFor={id}>Email</Label.Root>
  <Field.Root id={id}>
    <Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
  </Field.Root>
</Field.Group>
```

## Accessible composition

**Todae handles:** The input takes `id`, `name`, `aria-label`, `aria-labelledby` and `aria-describedby` from `Field.Root`, and native `disabled` and `aria-invalid` from the Root or a surrounding [Fieldset](/fieldset).

**You supply:** A name, through a [Label](/label) whose `htmlFor` is the Root `id` or `aria-label` / `aria-labelledby` on the Root.

**Watch for:** An `id` on `Field.TextInput` is replaced by the Root's; put it on the Root.

## When to use

### Field.TextInput

**When:** Single-line typed value inside `Field.Root` (text / search / email / url / tel / password).

**When not:** A number → `Field.NumberInput`. A time → `Field.TimePicker`. A date and time → `Field.DateTimePicker`. Multi-value tokens → `Field.ChipInput`. Multi-line → `Field.Textarea`. Standalone without Root.
