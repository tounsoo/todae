# Field.DateTimeInput

`Field.DateTimeInput` is a native `<input type="datetime-local">` inside a [Field](/field), with the browser's own date and time picker and locale format. Its `value`, `min` and `max` are a `Temporal.PlainDateTime`, and `onValueChange` gets a `Temporal.PlainDateTime`, or `null` while the input is empty or incomplete. A `PlainDateTime` has no time zone: it is the date and time on the user's clock. To store an instant, combine it with a time zone in your own code, such as `value.toZonedDateTime(zone)`. `step` is the native one, in seconds. Put `id` on `Field.Root`.

```tsx
const id = useId();
const [start, setStart] = useState<Temporal.PlainDateTime | null>(null);

<Field.Group>
  <Label.Root htmlFor={id}>Meeting starts</Label.Root>
  <Field.Root id={id}>
    <Field.DateTimeInput value={start} onValueChange={setStart} />
  </Field.Root>
</Field.Group>
```

## Temporal

Todae ships no Temporal polyfill. `onValueChange` reads the input with `Temporal`, so where the browser has no Temporal, the app loads a polyfill (see [Native platform](/platform)). Todae's types need TypeScript 6 or later, which declares `Temporal`.

## Accessible composition

**Todae handles:** The input takes `id`, `name`, `aria-label`, `aria-labelledby` and `aria-describedby` from `Field.Root`, and native `disabled` and `aria-invalid` from the Root or a surrounding [Fieldset](/fieldset). The browser handles the keyboard and the picker.

**You supply:** A name, through a [Label](/label) whose `htmlFor` is the Root `id` or `aria-label` / `aria-labelledby` on the Root. `onChange` or `onValueChange`; without either, the input is read-only.

**Watch for:** While the user is still filling in the input, `onValueChange` gets `null`, so don't treat `null` as a cleared field until they leave it.

## When to use

### Field.DateTimeInput

**When:** A date and time on the user's own clock, such as when a meeting starts.

**When not:** A date alone → [Field.DatePicker](/field/date-picker). A time alone → [Field.TimePicker](/field/time-picker).
