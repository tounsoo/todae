# OptionList

`role="listbox"` with `aria-activedescendant`. Options are strings. Keyboard is Arrow, Home, End, Enter, and Space. Escape is not handled so it can close a parent Popover.

Single `value` is `string | null`. Multiple `value` is `string[]`. Selected options stay `font-weight: 400` and use an accent-soft row fill (`color.bg.selected`, 12% accent). Highlighted selected is 20% (`color.accent.soft-strong`). Rows are `2px` apart. Hover is gated with `@media (hover: hover)`.

Options are `OptionList.Option` parts inside `OptionList.Root`.

A combobox can pass `id`, `activeValue`, `onActiveValueChange`, and `tabIndex={-1}` so the input owns focus and `aria-activedescendant`. Uncontrolled lists keep `tabIndex={0}`.

## Icons

A selected option shows the `check` glyph: Todae's check mark, unless a [GlyphsProvider](/utilities/glyphs-provider) sets one. In a multiple list it sits inside the box.

```tsx
import { Check } from 'lucide-react';

<GlyphsProvider glyphs={{ check: <Check /> }}>
	<OptionList.Root aria-label="Fruit" value={value} onValueChange={setValue}>
		<OptionList.Option value="apple">Apple</OptionList.Option>
		<OptionList.Option value="pear">Pear</OptionList.Option>
	</OptionList.Root>
</GlyphsProvider>
```

## Accessible composition

**Todae handles:** `OptionList.Root` is a `role="listbox"` with `aria-activedescendant` on the active option, and `aria-multiselectable` in multiple mode. Each `OptionList.Option` is a `role="option"` with `aria-selected`, `aria-disabled` when disabled, and an id built from the list's `id` and its `value`. The arrow keys, Home and End skip disabled options and stop at the ends. An option the keyboard moves to scrolls into view inside its scroll box. Focus stays on the list, or on the input that owns it.

**You supply:** A name with `aria-label`, or `aria-labelledby` pointing at a visible label; the type does not require one. Option text that reads well on its own, since the string is the option's name. When an input owns focus, wire it with [useCombobox](/utilities/use-combobox), which gives the list `tabIndex={-1}` and puts `aria-activedescendant`, `aria-controls` and `aria-expanded` on the input.

**Watch for:** Escape is not handled, so a list in your own overlay needs something else to close on Escape, such as Popover. Two lists with the same `id` give their options the same ids. `tabIndex={-1}` without an input that carries `aria-activedescendant` leaves the list out of keyboard reach.

## When to use

**When:** Overlay listbox inside Popover or BottomSheet. Single or multiple string options. Keyboard listbox pattern.

**When not:** Choices that stay on the page → Radio or Checkbox. Do not dual-wire the same value to Radio/Checkbox.
