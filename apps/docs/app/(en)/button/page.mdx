# Button

`Button.Root` is the control. `Button.Icon` is a compound part. Icon position is DOM order. The icon is decorative (`aria-hidden`). Icon-only roots need `aria-label` or `aria-labelledby` on `Button.Root`.

Icon-only roots tip that name. A labeled button tips the full string only while the label overflows. `tooltip={false}` opts out. Fitting labeled buttons do not tip. Auto tips are never interactive.

Variants use the existing paint packs. Default `type` is `button`.

## Toggle

Pass `pressed` or `defaultPressed` and the button becomes a toggle: it sets `aria-pressed` and flips on click. `onPressedChange` gets the new state. A pressed button keeps the active colors with an inset ring. For a set of toggles, use [ToggleGroup](/toggle-group).

```tsx
<Button.Root variant="secondary" pressed={muted} onPressedChange={setMuted}>
  Mute
</Button.Root>
```

## Button.Group

Sibling chrome. `role="group"`. Children are `Button.Root`. Attached edges overlap by 1px and share the outer radius. No selection state.

## Accessible composition

**Todae handles:** A native `<button>` with `type="button"`, so it keeps the browser's keyboard behaviour, and a focus ring on `:focus-visible`. `pressed` sets `aria-pressed`. `Button.Icon` is `aria-hidden`. An icon-only root shows its `aria-label` or `aria-labelledby` text as a tooltip, linked by `aria-describedby` while it shows, and logs an error in development when it has no name. `Button.Group` is always `role="group"`.

**You supply:** A name for every icon-only button, and an `aria-label` for each `Button.Group`. A wrapper whose buttons can be icon-only should require the name in its props type, and spread the rest so `ref`, `disabled` and the name reach the button.

```tsx
import type { ReactNode } from 'react';
import { Button, type ButtonRootProps } from '@tounsoo/todae';

type IconButtonProps = Omit<ButtonRootProps, 'aria-label' | 'aria-labelledby' | 'children'> & {
  label: string;
  icon: ReactNode;
};

export function IconButton({ label, icon, ...props }: IconButtonProps) {
  return (
    <Button.Root {...props} aria-label={label}>
      <Button.Icon>{icon}</Button.Icon>
    </Button.Root>
  );
}
```

**Watch for:** A wrapper that drops the rest props, which loses `ref` and ARIA. A `Button.Root` inside a link, or a link inside a button: interactive content cannot nest. A toggle whose text flips, such as "Mute" to "Unmute", as `aria-pressed` changes; keep one label and let `pressed` carry the state. `tooltip={false}` on an icon-only button, which removes its only visible name.

## When to use

### Button.Root

**When:** One action in a native button. Variants primary / secondary / ghost; default `type="button"`. Icon-only needs `aria-label`, which it auto-tips.

**When not:** Navigation → native link (no Link shipped). A setting that takes effect at once → Switch. A form choice → Checkbox. Selected segment → ToggleGroup (Button.Group has no selection).

### Button.Icon

**When:** Decorative icon inside `Button.Root`. Position = DOM order. Always aria-hidden.

**When not:** Icon in a field → `Field.Icon`. Icon as the only name with no `aria-label` on Root. Outside `Button.Root`.

### Button.Group

**When:** Attached horizontal row of related `Button.Root` actions (`role="group"`). Name it with `aria-label`.

**When not:** Toggles → ToggleGroup (no selection state here). Vertical or wrapping rows → Stack. Unrelated actions → separate buttons in Stack.
