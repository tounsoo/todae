# Text

Sizes `s` / `m` / `l` map to `text.size.2` / `3` / `4`.

<Example>
  <Text size="s" tone="muted">
    Small muted
  </Text>
  <Text>Medium default</Text>
  <Text size="l" tone="accent" weight="bold" as="strong">
    Large accent
  </Text>
</Example>

## When to use

**When:** Body text on the token scale: size s / m / l, tone default / muted / accent, weight; `as` p / span / strong.

**When not:** Headings → native heading (no h levels). Field names → Label. Hints and errors → Description / ErrorMessage. Dialog heading → `Dialog.Title`.
