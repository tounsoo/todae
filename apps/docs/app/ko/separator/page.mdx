# Separator

구분선은 네이티브 `<hr>`입니다. 컴포넌트는 없습니다. 이 요소에는 이미 separator 역할이 있고, Todae는 `separator` contract 토큰으로 `todae.base` 레이어에서 모든 `hr`의 스타일을 정합니다.

<Example>
  <SeparatorBetween />
</Example>

```tsx
<Text>Account settings apply to every workspace.</Text>
<hr />
<Text>Workspace settings apply to this workspace only.</Text>
```

`separator.color`, `separator.thickness`, 그리고 선 위아래 여백인 `separator.space`로 스타일을 바꾸세요.

## 언제 쓰나요

**쓸 때:** 같은 페이지에 속한 두 콘텐츠 묶음 사이를 끊을 때.

**쓰지 않을 때:** 간격만으로 묶음이 구분될 때 → [Stack](/stack). 장식일 뿐인 선 → 스크린 리더가 구분선을 읽지 않도록 자체 CSS의 테두리.
