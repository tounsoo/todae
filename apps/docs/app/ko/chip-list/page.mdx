# ChipList

칩을 `maxRows` 줄까지 보여 주고 나머지는 +N 버튼으로 접는 목록입니다. +N을 누르면 접힌 칩이 담긴 팝오버가 열립니다. 목록 이름은 `aria-label`이나 `aria-labelledby`로 붙이세요.

`onRemove`를 주면 칩마다 제거 버튼이 생깁니다. 포커스가 있던 칩이 `chips`에서 빠지면 포커스는 그 자리를 채운 칩으로, 없으면 앞 칩으로, 그것도 없으면 +N으로, 그마저 없으면 목록으로 옮겨 갑니다.

```tsx
<ChipList.Root
  aria-label="Tags"
  chips={tags}
  maxRows={1}
  onRemove={(index) => setTags((current) => current.filter((_, i) => i !== index))}
/>
```

팝오버에서 마지막 칩에서 Tab을 누르면 +N 다음 컨트롤로 가고, 첫 칩에서 Shift+Tab을 누르면 +N으로 돌아가며, Escape를 누르면 팝오버가 닫히고 +N으로 돌아갑니다.

`getTone`은 Chip처럼 칩마다 `tone`을 줍니다. 태그를 이름별로 색칠하려면 문자열을 늘 같은 카테고리 톤으로 바꾸는 `categoryTone`을 넘기세요. `getTone={(value) => categoryTone(value)}`처럼 씁니다.

## 읽기 전용

`onRemove`를 빼면 칩에 제거 버튼이 없습니다.

```tsx
<ChipList.Root aria-label="Tags" chips={tags} maxRows={1} />
```

## 아이콘

제거 버튼은 `close` 글리프를 보여 주며, [GlyphsProvider](/utilities/glyphs-provider)가 정하지 않으면 X 모양입니다. 이 목록에만 다른 아이콘을 쓰려면 [Chip](/chip)처럼 `removeIcon`을 전달하세요.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 칩은 `role="list"` 요소 안에 있고, 이 요소가 `aria-label`, `aria-labelledby`, `aria-describedby`, `aria-details`를 받습니다. 줄에 보이는 각 칩과 +N은 `role="listitem"`입니다. +N은 `aria-expanded`, `aria-controls`, `aria-haspopup="dialog"`가 있는 네이티브 버튼이고, 이름은 `overflowLabel`이나 `moreChips` 문자열입니다. 팝오버는 `role="dialog"`이고, 이름은 `panelLabel`이나 `moreChipsPanel` 문자열입니다. 제거 버튼의 이름은 `removeLabel`이나 `Remove {value}`입니다. 제거 뒤의 포커스와 팝오버 안의 Tab, Shift+Tab, Escape는 위에서 설명한 대로 동작합니다. 측정용 줄은 `aria-hidden`이고 `inert`입니다.

**직접 제공할 것:** "Applied filters"처럼 칩이 무엇인지 말하는 `aria-label`이나 `aria-labelledby`를 주세요. 없으면 목록에 이름이 없습니다. `Remove {value}`만으로 부족하면 `removeLabel`을 주세요. 두 칩이 같은 값을 가질 수 있다면 포커스가 맞는 칩을 따라가도록 안정적인 `getKey`를 주세요. 다른 버튼으로 필터를 모두 지우는 것처럼 바깥에서 바뀐 내용은 직접 알리세요. 목록은 아무것도 읽어 주지 않습니다.

**주의할 점:** 목록 대신 래퍼에 이름을 붙이지 마세요. `ChipList.Root`의 `aria-label`은 목록에 닿지만, 그 바깥의 직접 만든 `<div>`에 붙이면 아무것도 이름 짓지 않습니다. 값이 겹칠 때 값으로 지우지 마세요. `onRemove`는 누른 칩의 인덱스를 넘겨줍니다. 래퍼가 `onRemove`를 늘 넘기면 읽기 전용 칩에도 제거 버튼이 생깁니다.

## 언제 쓰나요

**언제:** 적용된 필터, 읽기 전용 태그, 수신자처럼 텍스트 필드 밖의 칩을 `maxRows`로 제한하고 +N 개수를 보일 때.

**쓰지 않을 때:** 새 칩 입력 → `Field.ChipInput`. 옵션에서 고르기 → [Combobox 레시피](/recipes/combobox). 선택하거나 토글하는 칩 → Checkbox / Button.Root. 칩 하나 → `Chip.Root`. 접기 둘레의 마크업을 직접 만들 때 → [useChipList](/utilities/use-chip-list).
