# ToggleGroup

텍스트 정렬, 보기 전환, 텍스트 스타일처럼 하나의 컨트롤로 읽히는 토글 버튼 묶음입니다. `ToggleGroup.Root`는 `role="group"`이고, 각 `ToggleGroup.Item`은 `aria-pressed`가 있는 secondary [Button.Root](/button)입니다. 묶음은 Tab 순서에서 한 자리를 차지하며, 그 자리는 single 모드에서는 눌린 항목, multiple 모드에서는 첫 항목입니다. 화살표 키는 항목을 누르지 않고 포커스만 옮깁니다.

기본값인 single 모드에서는 많아야 한 항목이 눌리며, 눌린 항목을 다시 누르면 값이 `null`이 됩니다.

```tsx
<ToggleGroup.Root aria-label="Alignment" value={align} onValueChange={setAlign}>
  <ToggleGroup.Item value="left">Left</ToggleGroup.Item>
  <ToggleGroup.Item value="center">Center</ToggleGroup.Item>
  <ToggleGroup.Item value="right">Right</ToggleGroup.Item>
</ToggleGroup.Root>
```

</Example>

`selectionMode="multiple"`이면 몇 개든 누를 수 있고, 값은 배열입니다.

```tsx
<ToggleGroup.Root aria-label="Text style" selectionMode="multiple" defaultValue={['bold']}>
  <ToggleGroup.Item value="bold">Bold</ToggleGroup.Item>
  <ToggleGroup.Item value="italic">Italic</ToggleGroup.Item>
  <ToggleGroup.Item value="underline">Underline</ToggleGroup.Item>
</ToggleGroup.Root>
```

묶음에는 `aria-label`이나 `aria-labelledby`로 이름을 붙이세요. 가로 항목은 [Button.Group](/button)처럼 붙습니다. [Toolbar](/toolbar) 안에서는 툴바가 화살표 키와 탭 위치를 맡습니다.

## 세그먼트 모양

기본값인 secondary 항목으로 된 가로 묶음은 prop 없이 토큰만으로 세그먼트 컨트롤 모양으로 바꿀 수 있습니다. `togglegroup.bg`, `togglegroup.border`, `togglegroup.border-width`, `togglegroup.padding`, `togglegroup.radius`, `togglegroup.gap`이 트랙을 그립니다. 세그먼트는 Button과 다른 곳만 자기 토큰을 갖고, 나머지는 `button.*`을 그대로 씁니다. `togglegroup.item.radius`와 `togglegroup.item.padding.y`가 크기를 정하고, `togglegroup.item.bg.default`, `hover`, `active`가 평소 색을 정하며, `togglegroup.item.bg.pressed`, `fg.pressed`, `border.pressed`, `shadow.pressed`가 눌린 항목의 색을 정합니다. `togglegroup.item.pressed-ring-width`는 안쪽 링입니다. 포커스는 평소 채우기를 유지하고 Button의 포커스 링을 씁니다. 기본값에서는 트랙이 비어 있고 항목은 한 줄로 붙은 secondary 버튼처럼 보입니다. 트랙과 이 색은 secondary 항목에만 적용되므로 ghost 아이콘 토글 줄은 그대로입니다. 세로 묶음은 트랙을 그리지 않고 `toolbar.gap`으로 쌓습니다. [Playground](/playground)의 Anvil 프리셋이 세그먼트 토큰을 씁니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** `ToggleGroup.Root`는 `role="group"`입니다. 각 `ToggleGroup.Item`은 그룹의 값에서 `aria-pressed`를 가져오는 `Button.Root`이며, 항목이나 그룹이 비활성이면 네이티브 `disabled`를 가집니다. 단독으로 쓸 때 그룹은 탭 정지를 하나 두고 방향 키로 포커스를 옮깁니다. Toolbar 안에서는 둘 다 툴바에 맡깁니다. 눌린 항목은 색과 함께 안쪽 테두리도 유지합니다.

**직접 제공할 것:** `aria-label`이나 `aria-labelledby`로 그룹의 이름을 주세요. 타입은 이를 요구하지 않습니다. 각 항목에 이름을 주세요. 텍스트 자식을 쓰거나, 아이콘만 있는 항목에는 `aria-label`을 주세요. 이 값은 `Button.Root`가 툴팁으로도 보여줍니다. 눌렸을 때도 레이블은 그대로 두세요. 상태는 `aria-pressed`가 전하므로 "Bold"는 계속 "Bold"입니다.

**주의할 점:** 단일 모드라고 항목에 `role="radio"`를 주지 마세요. 항목은 `aria-pressed`를 가진 토글 버튼이고, 그룹의 `role`은 고정되어 있습니다. 눌린 상태를 채우기 색 변화만으로 다시 꾸미면 상태가 색에만 의존하게 됩니다. `aria-label`처럼 받은 props를 버리는 요소로 각 항목을 감싸지 마세요.

## 언제 쓰나

**쓸 때:** 무언가를 보여 주는 방식을 바꾸는 옵션으로, 눌린 상태가 한눈에 보이고 바로 적용될 때.

**쓰지 않을 때:** 제출하는 폼의 선택 → Radio나 Checkbox. 설정 하나를 켜고 끔 → Switch나 토글 [Button.Root](/button) 하나. 콘텐츠 패널 사이 전환 → Tabs.
