# Stack

간격은 `stack.gap`(밀도에 따라 달라짐)입니다. `gap` prop은 없습니다.

Server Components는 `@tounsoo/todae/stack`에서 가져올 수 있습니다. 이 엔트리에는 `'use client'`도 훅도 없습니다. 메인 `@tounsoo/todae` 엔트리는 클라이언트 모듈입니다.

<Example>
  <StackButtons />
</Example>

## 언제 쓰나요

**언제:** 밀도에 따라 달라지는 `stack.gap`으로 간격을 둔 flex 행이나 열. 필드나 버튼 사이의 간격.

**쓰지 않을 때:** 레이블과 컨트롤 사이 간격 → `.labelled-field` 래퍼(`field.label.gap`). 커스텀 간격 값(gap prop 없음). 붙어 있는 버튼 행 → Button.Group.
