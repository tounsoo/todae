# Command palette

패키지 네임스페이스가 아니라 레시피입니다. [Dialog](/dialog)가 팔레트를 담고, [useCombobox](/utilities/use-combobox)가 입력, 필터링, 활성 옵션, id를 맡습니다. `CommandPalette.*` export는 없습니다.

`dialog` 표시 방식을 쓰고 `getDialogProps()`를 `Dialog.Root`에 펼치세요. 팔레트가 열릴 때 훅이 입력을 비우고 첫 행을 활성으로 만들며, 팔레트가 닫히는 동안 고른 명령은 다시 실행되지 않습니다. `value`를 `null`로 두고 `onValueChange`에서 명령을 실행하면, 명령을 골라도 선택된 것이 남지 않습니다.

```tsx
const cb = useCombobox({
  options: commands,
  presentation: 'dialog',
  value: null,
  onValueChange: (value: string | null) => { if (value) run(value); },
});
useHotkey(['Control+K', 'Meta+K'], () => !cb.open && cb.setOpen(true));

<Button.Root {...cb.getTriggerProps()} aria-keyshortcuts="Control+K Meta+K">
  Search commands
</Button.Root>
<Dialog.Root {...cb.getDialogProps()} aria-label="Commands">
  <Field.Root id={cb.ids.input} aria-label="Command">
    <Field.TextInput {...cb.getInputProps()} placeholder="Type a command" />
  </Field.Root>
  <OptionList.Root {...cb.getListboxProps()} aria-label="Commands" hidden={cb.isEmpty}>
    {cb.items.map((item) => (
      <OptionList.Option key={item.id} {...cb.getOptionProps(item)} />
    ))}
  </OptionList.Root>
  <Text.Root role="status">{cb.isEmpty ? 'No matching commands.' : ''}</Text.Root>
</Dialog.Root>
```

단축키는 [useHotkey](/utilities/use-hotkey)로, Ctrl+K나 ⌘K에서 팔레트를 엽니다. 트리거의 `aria-keyshortcuts`가 보조 기술에 단축키를 알려 줍니다. Escape나 배경 클릭으로 대화 상자가 닫히고, 포커스는 팔레트가 열릴 때 포커스가 있던 요소로, 포커스가 없었다면 트리거로 돌아갑니다. 빈 결과 메시지는 `role="status"` 영역에 있어 스크린 리더가 읽어 줍니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** `Dialog`는 네이티브 모달 `<dialog>`이므로, 열려 있는 동안 뒤의 페이지는 inert 상태가 되고, 위에서 설명한 대로 닫히며 포커스를 돌려줍니다. [useCombobox](/utilities/use-combobox)는 입력을 `role="combobox"`로 만들어 `aria-activedescendant`로 활성 명령을 가리키고, 화살표 키, Home, End로 옮기며, Enter로 고릅니다. `getTriggerProps()`는 트리거에 `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`를 줍니다.

**직접 제공할 것:** 대화 상자에 이름을 주세요. `getDialogProps()`는 `options` 문자열(기본값 "Options")로 `aria-label`을 설정하므로, 위의 `aria-label="Commands"`처럼 스프레드 뒤에 직접 주세요. 입력에도 이름이 필요합니다. 여기서는 `Field.Root`의 `aria-label`입니다. `cb.ids.label`을 단 보이는 레이블이 없으므로 목록에도 이름을 주세요. 여기서는 `OptionList.Root`의 `aria-label`입니다. 트리거에는 보이는 텍스트와 단축키를 알리는 `aria-keyshortcuts`를 주세요. 빈 결과 메시지는 마운트된 채로 남는 `role="status"` 요소에 두세요. 명령이 보이는 효과를 남기지 않는다면, 실행 뒤에 상태 메시지처럼 알아챌 수 있는 결과를 주세요.

**주의할 점:** `aria-label`을 `{...cb.getDialogProps()}`보다 앞에 두면 스프레드의 이름이 이깁니다. 일치하는 항목이 없을 때 목록을 마운트 해제하지 마세요. `aria-controls`가 계속 가리키도록 `hidden`으로 숨기세요. 단축키로만 팔레트를 열 수 있게 하지 마세요.
