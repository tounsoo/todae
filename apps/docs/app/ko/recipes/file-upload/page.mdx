# File upload

패키지 네임스페이스가 아니라 레시피입니다. 컨트롤은 네이티브 `<input type="file">`이고, [useDropzone](/utilities/use-dropzone)이 드래그 앤 드롭과 파일 확인을 더하며, 업로드는 직접 작성하는 코드가 맡습니다. `FileUpload.*` export는 없습니다.

## 이미지

라벨이 드롭 대상입니다. 그래서 라벨 어디를 클릭해도 선택기가 열리고, 라벨의 텍스트가 입력의 이름이 됩니다. 거부된 파일은 입력의 `aria-describedby`가 가리키는 `ErrorMessage`에 나열하고, 입력에는 `aria-invalid`를 줍니다. 받은 파일은 그 아래에 나열합니다.

```tsx
const zone = useDropzone({
  accept: 'image/*',
  multiple: true,
  maxFiles: 3,
  maxSize: 2_000_000,
  minSize: 1,
  onFiles: (accepted, rejected) => {
    setFiles(accepted)
    setRejected(rejected)
  },
})

<label {...zone.getRootProps()}>
  <Text as="span">Drop images here, or choose them</Text>
  <input
    {...zone.getInputProps()}
    name="images"
    aria-invalid={rejected.length > 0 || undefined}
    aria-describedby={rejected.length > 0 ? `${hintId} ${errorId}` : hintId}
  />
</label>
<Description id={hintId}>Up to 3 images, 2 MB each.</Description>
{rejected.length > 0 ? <ErrorMessage id={errorId}>…</ErrorMessage> : null}
```

드롭 상태는 `[data-dragging]`이나 `dragging` 값으로 스타일을 주세요. 오류는 나타날 때 읽어 주지 않습니다. 읽어 주어야 한다면 [useAnnouncer](/utilities/use-announcer)를 쓰세요.

## 업로드

`onFiles`에서 파일을 보내거나, 입력에 남겨 두고 폼이 제출하게 하세요. 입력에는 받은 파일만 남아 있습니다. 진행률은 [Progress 페이지](/progress)처럼 네이티브 `<progress>`로 보여 주세요.

## 접근성을 지키는 조합

**Todae가 맡는 것:** [useDropzone](/utilities/use-dropzone)은 네이티브 `<input type="file">`을 계속 컨트롤로 두므로 role, 키보드, 선택기는 브라우저가 제공합니다. `getInputProps()`는 `type`, `accept`, `multiple`, `disabled`를 설정하고, `getRootProps()`는 드래그 핸들러와 `data-dragging`만 추가합니다. 검사가 끝나면 입력에는 받은 파일만 남습니다. 훅은 ARIA를 설정하지 않고 아무것도 읽어 주지 않습니다.

**직접 제공할 것:** 레시피의 마크업이 하는 일을 직접 하세요. 입력의 이름이 되는 `<label>` 텍스트, `aria-describedby`로 연결한 힌트, 말로 풀어 쓴 거부 이유, 파일이 거부되었을 때의 `aria-invalid`와 `aria-describedby`에 더한 `ErrorMessage` id, 이름이 있는 받은 파일 목록이 필요합니다. 거부를 들려주어야 한다면 알리세요. 업로드 진행률과 결과는 레이블이 있는 `<progress>`처럼 텍스트로도 보여 주세요.

**주의할 점:** 드롭 대상을 꾸미려고 `display: none`이나 `hidden`으로 입력을 숨기지 마세요. 드래그는 포인터로만 할 수 있으므로 키보드와 스크린 리더 사용자는 유일한 방법을 잃습니다. 포커스를 받을 수 있게 두고 포커스를 보여 주세요. 더는 렌더링하지 않는 `ErrorMessage`를 `aria-describedby`가 계속 가리키게 두지 마세요. 오류를 빨간 테두리만으로 보여 주지 마세요.
