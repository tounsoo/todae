# Dialog

`showModal()`로 여는 가운데 정렬 네이티브 `<dialog>`입니다. `open`으로 제어하거나, `defaultOpen`으로 비제어 방식으로 둘 수 있습니다. Escape와 배경 클릭으로 닫기는 기본으로 켜져 있고 끌 수 있습니다. 시트로 변하지 않습니다.

열릴 때는 200ms 동안 opacity가 변합니다. 지원되는 곳에서는 `@starting-style`을 쓰고, `data-entered`가 대체 수단이라 지원하지 않는 엔진에서도 전환이 일어납니다. 닫힐 때는 `transitionend`까지 마운트된 채로 있습니다(대체 시간 160ms).

```tsx
const keepRef = useRef<HTMLButtonElement>(null);

<Button.Root onClick={() => setOpen(true)}>Open dialog</Button.Root>
<Dialog.Root open={open} onOpenChange={setOpen} initialFocusRef={keepRef}>
  <Dialog.Header>
    <Dialog.Title>Discard draft?</Dialog.Title>
    <Dialog.Close />
  </Dialog.Header>
  <Dialog.Description>This cannot be undone.</Dialog.Description>
  <Dialog.Body>…</Dialog.Body>
  <Dialog.Footer>
    <Button.Root ref={keepRef} variant="secondary" onClick={() => setOpen(false)}>
      Keep
    </Button.Root>
    <Button.Root onClick={discard}>Discard</Button.Root>
  </Dialog.Footer>
</Dialog.Root>
```

오버레이는 `ThemeProvider` / `DensityProvider`에서 토큰을 상속합니다. 프로바이더 노드에 붙은 추가 클래스는 상속하지 않습니다.

iOS에서는 열린 오버레이 뒤의 페이지가 여전히 고무줄처럼 튕길 수 있습니다. Chrome은 사용자 활성화가 없으면 `cancel.preventDefault()`를 무시할 수 있습니다. 그래도 상태는 네이티브 `close` 이벤트로 다시 동기화됩니다.

## 아이콘

내용이 없는 `Dialog.Close`는 `close` 글리프를 보여 주며, [GlyphsProvider](/utilities/glyphs-provider)가 정하지 않으면 X 모양입니다. 이름은 `close` 문자열에서 옵니다. 닫기 버튼 하나에만 다른 아이콘을 쓰려면 `Button.Icon`에 넣으세요.

```tsx
import { X } from 'lucide-react';

<Dialog.Close>
  <Button.Icon>
    <X />
  </Button.Icon>
</Dialog.Close>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `Dialog.Root`는 `showModal()`로 네이티브 `<dialog>`를 엽니다. 그래서 브라우저가 dialog 역할을 주고, 최상위 레이어에 올리고, 뒤의 페이지를 inert로 만듭니다. `Dialog.Title`은 대화 상자의 `aria-labelledby`를, `Dialog.Description`은 `aria-describedby`를 설정합니다. 루트에 직접 넘긴 `aria-labelledby`나 `aria-describedby`가 우선합니다. 열리면 포커스는 `initialFocusRef`로, 없으면 첫 번째 탭 가능한 요소로, 그것도 없으면 대화 상자 자체로 갑니다. 닫힘 동작이 끝나면 포커스는 `restoreFocusRef`로, 없으면 열기 전에 포커스가 있던 곳으로 돌아갑니다. `Dialog.Close`는 아이콘처럼 자기 텍스트도 `aria-label`도 이름을 주지 않으면 `close` 문자열("Close")로 이름이 붙습니다.

**직접 제공할 것:** 이름입니다. `Dialog.Title`을 렌더링하거나, `Dialog.Root`에 `aria-label`이나 `aria-labelledby`를 넘기세요. 대화 상자를 닫는 버튼도 필요합니다. 특히 `dismissOnEscape`가 false라면 `Dialog.Close` 같은 버튼을 두세요. 메뉴 항목이나 `Toast.Action`처럼 닫힐 때 여는 요소가 사라지고 없다면 `restoreFocusRef`를 넘기세요. 파괴적인 확인에서 안전한 버튼처럼 작업이 첫 번째 컨트롤에서 시작하지 않는다면 `initialFocusRef`를 넘기세요.

```tsx
import type { ReactNode } from 'react';
import { Dialog, type DialogRootProps } from '@tounsoo/todae';

type ConfirmDialogProps = Omit<DialogRootProps, 'children'> & {
  title: string;
  children: ReactNode;
};

export function ConfirmDialog({ title, children, ...rest }: ConfirmDialogProps) {
  return (
    <Dialog.Root {...rest}>
      <Dialog.Title>{title}</Dialog.Title>
      <Dialog.Body>{children}</Dialog.Body>
      <Dialog.Footer>
        <Dialog.Close>Cancel</Dialog.Close>
      </Dialog.Footer>
    </Dialog.Root>
  );
}
```

**주의할 점:** `Dialog.Title` 대신 자체 제목을 렌더링하는 래퍼는 `aria-labelledby`를 넘기지 않으면 대화 상자에 이름이 없습니다. 나머지 props를 버리는 래퍼는 `aria-*`, `ref`, 포커스 ref를 잃습니다. `Dialog.Title`은 항상 `h2`를 렌더링하므로, 대화 상자 안의 제목은 `h3`부터 시작하세요. 닫힌 팝오버나 탭 패널 같은 숨겨진 컨테이너 안에 대화 상자를 렌더링하지 마세요. 페이지는 inert가 되는데 아무것도 보이지 않습니다.

## 언제 쓰나요

**언제:** 가운데 정렬 모달 작업이나 확인(네이티브 `<dialog>`, 제어 `open` 또는 비제어 `defaultOpen`). 이름은 `Dialog.Title`이나 `aria-label`로 붙입니다. Escape와 배경 클릭으로 닫기가 기본입니다.

**쓰지 않을 때:** 아래에서 올라오는 모바일 선택기 → BottomSheet. 높이를 가득 채우는 사이드 패널 → Drawer. 앵커에 고정된 비모달 패널 → Popover. 짧은 힌트 → Tooltip. 모바일에서 시트로 바뀌어야 할 때(Dialog는 절대 모양이 바뀌지 않습니다).
