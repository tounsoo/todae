# 기존 앱 옮기기

제거된 prop이나 토큰을 아직 쓰는 앱을 현재 패키지로 옮깁니다. 아래 각 섹션은 릴리스에 이미 들어간 호환성 변경 하나입니다. 앱에 남아 있는 항목만 적용하세요.

## 현재 릴리스 설치

`latest` dist-tag를 설치합니다.

```sh
npm install @tounsoo/todae@latest
```

`0.0.0-stage` 버전은 설치하지 마세요. 이 버전은 trusted publishing 전에 패키지 이름이 npm에 존재하도록 2026-10-16에 올린 스텁입니다. npm의 설명은 "Temporary package placeholder for staged publishing"입니다. dist-tag가 아닙니다. `npm dist-tag ls @tounsoo/todae`는 `latest`만 보여 주고, `latest`는 `0.0.0-stage`를 가리키지 않습니다.

게시 권한이 있는 메인테이너가 이 버전을 직접 deprecate합니다. 릴리스 워크플로는 하지 않습니다. 명령과 메시지는 [Deprecate the placeholder version](https://github.com/tounsoo/todae/blob/main/CONTRIBUTING.md#deprecate-the-placeholder-version)에 있습니다.

## Text `size` 바꾸기

`Text.Root`는 더 이상 `size`를 받지 않습니다. 개발 환경에서는 오류를 기록하고 prop을 버립니다. 본문 텍스트는 `font.size.3`에 머뭅니다. 제목의 `as`가 여전히 그 스케일을 고릅니다.

`size="label"`은 `variant="label"`로 바꿉니다.

```tsx
<Text.Root size="label">Name</Text.Root>
```

```tsx
<Text.Root variant="label">Name</Text.Root>
```

그 밖의 `size`는 그 크기가 쓰던 foundation 단계로 `font-size`를 설정해 바꿉니다. 그 단계는 `text.size.*`였습니다. 그 토큰은 사라졌습니다. `font.size.*`를 쓰세요. CSS 변수는 `--todae-font-size-*`입니다. 토큰을 바꾸면 그 단계를 쓰는 곳이 모두 바뀝니다.

| 이전 `size` | 대체 |
| --- | --- |
| `s` | `var(--todae-font-size-2)` |
| `m` | `size`를 빼세요. 본문은 이미 `font.size.3`입니다. |
| `l` | `var(--todae-font-size-4)` |
| `xl` | `var(--todae-font-size-5)` |
| `2xl` | `var(--todae-font-size-6)` |

```css
.lede {
  font-size: var(--todae-font-size-4);
}
```

제목 스케일은 h1이 `font.size.6`, h2가 `font.size.5`, h3가 `font.size.4`, h4와 h5가 `font.size.3`, h6가 `font.size.2`입니다. [Text](/text)를 보세요.

## Avatar `size`와 `Avatar.Group` 바꾸기

`Avatar.Root`에서 `size`를 빼세요. 개발 환경에서는 오류를 기록하고 prop을 버립니다. 아바타는 `avatar.size`로 그려지며, 그 값은 `2rem`(`--todae-avatar-size`)입니다. `data-size`는 더 이상 렌더링되지 않습니다. `AvatarSize`는 제거되었습니다. `avatar.size.sm`, `avatar.size.md`, `avatar.size.lg` 토큰도 사라졌습니다.

| 이전 `size` | `--todae-avatar-size` |
| --- | --- |
| `sm` | `1.5rem` |
| `md` | `2rem`, 기본값 |
| `lg` | `2.5rem` |

```css
.avatar {
  --todae-avatar-size: 1.5rem;
}
```

그 변수를 설정하거나, `inline-size`와 `block-size`를 아바타 또는 조상 요소에 설정하세요. 그 조상과 아바타 사이의 `ThemeProvider`나 `DensityProvider`는 토큰을 다시 선언합니다. 스코프 테마 루트도 그렇습니다. [ThemeProvider](/tokens)에서 `avatar.size`를 오버라이드할 수도 있습니다.

`Avatar.Group`은 제거되었습니다. `AvatarGroupProps`와 `avatar.group.overlap`, `avatar.group.ring.width`, `avatar.group.ring.color` 토큰도 함께 제거되었습니다. 그룹은 [Avatar group](/recipes/avatar-group) 레시피로 바꾸세요. 그 레시피의 CSS를 복사하세요. 그 CSS의 링 색은 `--avatar-group-ring`이고, 스택에 설정하며, 표면 색으로 폴백합니다.

```tsx
<Avatar.Group aria-label="Assignees" size="md">
  <Avatar.Root label={person.name}>
    <Avatar.Fallback>{person.initials}</Avatar.Fallback>
  </Avatar.Root>
</Avatar.Group>
```

```tsx
<div role="group" aria-label="Assignees" className={styles.avatarGroup}>
  <Avatar.Root className={styles.avatar} label={person.name}>
    <Avatar.Fallback>{person.initials}</Avatar.Fallback>
  </Avatar.Root>
</div>
```

## 컴포넌트 타입 스케일 바꾸기

`text.size.2`부터 `text.size.6`까지와 `--todae-text-size-*` 변수를 모두 제거하세요. `prose.size`와 `prose.h1.size`부터 `prose.h6.size`까지 제거하세요. `--todae-prose-size`와 `--todae-prose-h1-size`부터 `--todae-prose-h6-size`까지 제거하세요.

그 크기는 `font.size.*`를 가리키게 하세요. 같은 단계 번호가 대체입니다. `text.size.4`는 `font.size.4`와 `--todae-font-size-4`가 됩니다. 본문은 3단계에 머뭅니다. 제목과 prose는 위 Text 섹션의 스케일에 머뭅니다.

foundation 토큰 `font.size.1`부터 `font.size.6`까지는 두세요. 경로가 `font.size`로 끝나는 컴포넌트 토큰도 두세요. `text.label.font.size`, `field.font.size`, `button.base.font.size`가 그렇습니다. 이들은 여전히 `font.size.*` 단계를 참조합니다.

앱에서 제거된 이름을 찾으세요.

```sh
rg -n 'text\.size\.|prose\.size|prose\.h[1-6]\.size|--todae-text-size-|--todae-prose-' .
```
