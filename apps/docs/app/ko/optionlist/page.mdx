# OptionList

`aria-activedescendant`를 쓰는 `role="listbox"`입니다. 옵션은 문자열입니다. 키보드는 Arrow, Home, End, Enter, Space입니다. Escape는 부모 Popover를 닫을 수 있도록 처리하지 않습니다.

단일 선택의 `value`는 `string | null`입니다. 다중 선택의 `value`는 `string[]`입니다. 선택된 옵션은 `font-weight: 400`을 유지하고 액센트를 옅게 깐 행 배경(`color.bg.selected`, 액센트 12%)을 씁니다. 하이라이트된 선택 옵션은 20%(`color.accent.soft-strong`)입니다. 행 사이 간격은 `2px`입니다. 호버는 `@media (hover: hover)`로 제한합니다.

```tsx
<OptionList.Root aria-label="Fruit" value={value} onValueChange={setValue}>
  <OptionList.Option value="apple">Apple</OptionList.Option>
  <OptionList.Option value="pear">Pear</OptionList.Option>
</OptionList.Root>
```

<Example>
  <OptionListSingle />
</Example>

`selectionMode="multiple"`이면 모든 행에 체크 영역을 둡니다. 선택되면 상자를 채우고 체크 글리프를 그립니다.

```tsx
<OptionList.Root aria-label="Fruit" selectionMode="multiple" value={values} onValueChange={setValues}>
  <OptionList.Option value="apple">Apple</OptionList.Option>
  <OptionList.Option value="pear">Pear</OptionList.Option>
</OptionList.Root>
```

<Example>
  <OptionListMultiple />
</Example>

옵션은 `OptionList.Root` 안의 `OptionList.Option` 파트입니다.

Combobox는 `id`, `activeValue`, `onActiveValueChange`, `tabIndex={-1}`를 넘겨 입력이 포커스와 `aria-activedescendant`를 갖게 할 수 있습니다. 비제어 목록은 `tabIndex={0}`을 유지합니다.

## 아이콘

선택된 옵션은 `check` 글리프를 보여 줍니다. [GlyphsProvider](/utilities/glyphs-provider)가 정하지 않으면 Todae의 체크 표시입니다. 다중 선택 목록에서는 상자 안에 들어갑니다.

```tsx
import { Check } from 'lucide-react';

<GlyphsProvider glyphs={{ check: <Check /> }}>
  <OptionList.Root aria-label="Fruit" value={value} onValueChange={setValue}>
    <OptionList.Option value="apple">Apple</OptionList.Option>
    <OptionList.Option value="pear">Pear</OptionList.Option>
  </OptionList.Root>
</GlyphsProvider>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `OptionList.Root`는 활성 옵션을 가리키는 `aria-activedescendant`를 가진 `role="listbox"`이고, 다중 모드에서는 `aria-multiselectable`도 가집니다. 각 `OptionList.Option`은 `aria-selected`를 가진 `role="option"`이며, 비활성이면 `aria-disabled`를 가지고, id는 목록의 `id`와 자기 `value`로 만들어집니다. 방향 키, Home, End는 비활성 옵션을 건너뛰고 양 끝에서 멈춥니다. 키보드로 옮겨 간 옵션은 자기 스크롤 상자 안에서 보이도록 스크롤됩니다. 포커스는 목록이나, 목록을 가진 입력에 머뭅니다.

**직접 제공할 것:** `aria-label`이나, 보이는 레이블을 가리키는 `aria-labelledby`로 이름을 주세요. 타입은 이를 요구하지 않습니다. 문자열이 옵션의 이름이 되므로, 옵션 텍스트는 그것만으로 뜻이 통해야 합니다. 입력이 포커스를 가지면 [useCombobox](/utilities/use-combobox)로 연결하세요. 이 훅은 목록에 `tabIndex={-1}`을 주고, 입력에 `aria-activedescendant`, `aria-controls`, `aria-expanded`를 둡니다.

**주의할 점:** Escape는 처리하지 않으므로, 직접 만든 오버레이 안의 목록은 Popover처럼 Escape로 닫아 줄 다른 무언가가 필요합니다. 같은 `id`를 가진 목록 두 개는 옵션에도 같은 id를 줍니다. `aria-activedescendant`를 가진 입력 없이 `tabIndex={-1}`만 주면 키보드로 목록에 닿을 수 없습니다.

## 언제 쓰나요

**언제:** Popover나 BottomSheet 안의 오버레이 listbox. 단일 또는 다중 문자열 옵션. 키보드 listbox 패턴.

**쓰지 않을 때:** 페이지에 계속 남는 선택지 → Radio나 Checkbox. 같은 값을 Radio/Checkbox에 이중으로 연결하지 마세요.
