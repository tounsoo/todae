# Chip

텍스트만 담는 레이블입니다. 선택적인 제거는 이름이 있는 버튼입니다. `Chip.Overflow`는 표시 전용 `+N`입니다.

```tsx
<Stack.Root as="ul" direction="row" wrap aria-label="Tags">
  <li>
    <Chip.Root>Design</Chip.Root>
  </li>
  <li>
    <Chip.Root onRemove={remove}>Tokens</Chip.Root>
  </li>
  <li>
    <Chip.Overflow overflowCount={4} />
  </li>
</Stack.Root>
```

  <ChipExamples />
</Example>

`+N`은 버튼이 아니며 탭 순서에 들어가지 않습니다.

`tone`은 Badge와 같은 톤을 받습니다. 기본값인 `neutral`, 상태 톤 `info`, `success`, `warning`, `critical`, 그리고 카테고리 톤 `category-1`부터 `category-8`입니다. `neutral`은 `chip.bg`, `chip.fg`, `chip.border` 상태 토큰을 읽고, 다른 톤은 `chip.<tone>` contract 토큰을 읽으며 hover에서도 색을 유지합니다. 비활성 칩은 톤과 상관없이 비활성 색을 씁니다.

내용이 없으면 제거 버튼은 `close` 글리프를 보여 줍니다. [GlyphsProvider](/utilities/glyphs-provider)가 정하지 않으면 X 모양입니다. 칩 하나에만 다른 아이콘을 보여 주려면 `removeIcon`을 전달하세요. `svg`나 `img`는 `chip.icon.size` 토큰의 크기를 따릅니다. 버튼의 이름은 계속 `removeLabel`이나 그 기본값에서 옵니다. 그 기본값 `Remove {label}`과 `+N`에 읽히는 `{n} more`는 [StringsProvider](/utilities/strings-provider)에서 옵니다.

```tsx
import { X } from 'lucide-react';

<Chip.Root onRemove={remove} removeIcon={<X />}>
  Design
</Chip.Root>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `Chip.Root`는 레이블을 role이 없는 `<span>` 안에 일반 텍스트로 렌더링합니다. `onRemove`를 주면 네이티브 `<button type="button">`을 추가하고, `aria-label`로 이름을 붙입니다. 이름은 `removeLabel`이고, 없으면 `removeChip` 문자열(영어로 `Remove {label}`)입니다. `disabled`는 그 버튼을 비활성화하고 칩에 `data-disabled`를 설정합니다. `Chip.Overflow`는 보이는 `+N`을 `aria-hidden`으로 숨기고, 기본으로 `moreChips` 문자열인 이름을 시각적으로 숨긴 텍스트로 제공합니다.

**직접 제공할 것:** 칩을 여러 개 보여 줄 때는 목록 의미를 제공하세요. `<li>` 항목이 있는 `<ul>`을 쓰거나, 컨테이너에 `role="list"`를, 각 `Chip.Root`에 `role="listitem"`을 주세요. `Chip.Root`는 네이티브 props를 `<span>`에 전달합니다. 그 목록에 이름을 붙이세요. 레이블만으로 무엇을 지우는지 알 수 없다면 "Remove filter Design"처럼 말해 주는 `removeLabel`을 주세요. 제거한 뒤 포커스가 갈 곳도 정하세요. 제거 버튼은 칩과 함께 DOM에서 사라지므로, 포커스를 이웃 칩이나 칩을 추가한 컨트롤로 옮기세요. [ChipList](/chip-list)는 이 일을 대신 합니다.

**주의할 점:** 칩을 `<button>`이나 링크 안에 넣으면 제거 버튼이 중첩된 대화형 콘텐츠가 됩니다. `Chip.Overflow`를 컨트롤로 쓰지 마세요. 포커스를 받지 않는 `<span>`입니다. `+N`으로 나머지를 열려면 ChipList처럼 `<button>` 안에 넣어, 버튼이 숨긴 이름을 받게 하세요. 적용 상태를 칩 색상만으로 보여 주지 마세요.

## 언제 쓰나요

**언제:** 값을 나타내는 텍스트 전용 토큰. `onRemove`로 선택적인 제거 버튼(이름이 있는 버튼). +N 오버플로는 표시 전용입니다.

**쓰지 않을 때:** 입력 안에서 입력한 토큰 → `Field.ChipInput`. 클릭하거나 선택할 수 있는 칩 → Button.Root / Checkbox(Chip에는 선택 기능이 없음). 레이블 안의 아이콘이나 풍부한 콘텐츠(텍스트만 가능).
