# useControlledState

`useControlledState(controlled, defaultValue, onChange)`는 값 prop, 기본값, 변경 콜백을 받는 컴포넌트에 `[value, change, latest]`를 반환합니다. `controlled`가 `undefined`가 아닌 동안에는 그 값이 곧 값이므로, 부모가 결정합니다. 그렇지 않으면 훅이 `defaultValue`에서 시작하는 자체 상태를 가집니다.

```tsx
function Filter({ value, defaultValue = 'all', onValueChange }: FilterProps) {
  const [current, change] = useControlledState(value, defaultValue, onValueChange);
  return (
    <select aria-label="Status" value={current} onChange={(event) => change(event.currentTarget.value)}>
      <option value="all">All</option>
      <option value="open">Open</option>
    </select>
  );
}
```

`change(next, ...args)`는 마지막 렌더링이 아니라 가장 최근에 쓴 값을 기준으로 합니다. `next`가 그 값과 같으면(`Object.is`) 건너뜁니다. 그렇지 않으면 비제어일 때 `next`를 저장한 다음 `onChange(next, ...args)`를 호출합니다. 그래서 렌더링 전에 두 번 쓰면 둘 다 반영되고, 토글을 두 번 누르면 두 번 바뀝니다.

제어 상태에서 쓰면 훅이 다시 렌더링됩니다. 그때까지 부모가 돌려주지 않은 변경은 버려지고, 다음 쓰기는 부모가 넘긴 값을 기준으로 합니다. `onChange` 없는 제어 값은 읽기 전용이라 `change`가 아무것도 하지 않습니다.

Set open을 두 번 누르세요. 두 번째는 이미 가장 최근 값이라 `onChange`가 실행되지 않습니다. Reset parent는 훅 밖에서 제어 값을 씁니다.

이유(reason) 같은 추가 인자는 `onChange`로 그대로 전달됩니다. `useControlledState<boolean, [reason: string]>(…)`처럼 두 번째 타입 매개변수로 타입을 지정하세요. `undefined`는 비제어를 뜻하므로, 제어 상태의 빈 값은 `null`입니다. `change`는 업데이터 함수가 아닌 값을 받습니다. `latest()`는 다음 쓰기가 기준으로 삼을 값을 읽습니다. `change`는 훅이 제어 또는 비제어로 유지되는 동안 같은 함수이며, 실행될 때 가장 새로운 `onChange`를 읽습니다. 컴포넌트가 사는 동안 한 가지 모드를 유지하세요. 제어에서 비제어로 바뀌면 마지막 제어 값이 아니라 훅 자체의 상태가 보입니다.

[Checkbox](/checkbox), [useCombobox](/utilities/use-combobox) 같은 Todae 자체 부품도 이 훅 위에 만들어졌으므로, 직접 만든 컴포넌트도 이런 경우에 같은 방식으로 동작합니다.

## 언제 쓰나요

**언제:** 값 prop, 기본값, 변경 콜백을 받는 자체 컴포넌트.

**쓰지 않을 때:** 부모가 정할 수 없는 상태 → `useState`.
