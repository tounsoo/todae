# formatRelativeTime

`formatRelativeTime(value, now, options?)`는 `value` 시각이 `now`보다 얼마나 앞서거나 뒤인지를 로캘이 쓰는 대로 반환합니다. `en`에서는 `3 minutes ago`, `yesterday`, `in 2 weeks`, `ko`에서는 `3분 전`, `어제`, `2주 후`처럼 씁니다. 메시지를 보낸 때, 파일을 고친 때, 항목이 만료되는 때에 쓰세요. 텍스트는 `Intl.RelativeTimeFormat`으로 쓰고 시계는 두지 않으므로, `now`는 제품이 넘기고 텍스트가 언제 바뀔지도 제품이 정합니다.

```tsx
const editedAt = Temporal.Instant.from(file.editedAt).toZonedDateTimeISO(timeZone);

<time dateTime={editedAt.toInstant().toString()}>
  {formatRelativeTime(editedAt, Temporal.Now.instant(), { locale })}
</time>
```

## 단위

하루 미만이면 지난 초, 분, 시간을 온전한 단위로만 셉니다. 그래서 59분 50초는 `59분 전`입니다. 하루부터는 `value`의 시간대와 그레고리력에서 두 날짜 사이의 일을 세고, 7일부터는 주, 그다음은 월과 연을 셉니다. 그래서 이틀 전 밤 11시는 48시간이 지나지 않았어도 `2일 전`입니다. 시계가 바뀌어 25시간인 날에는 같은 날짜의 시각은 시간으로 남습니다.

`numeric`의 기본값은 `'auto'`이며, 로캘에 있으면 `어제`, `지금`, `지난주` 같은 낱말을 씁니다. `1일 전`처럼 쓰려면 `numeric: 'always'`를 넘기세요. 좁은 자리에는 `style`에 `'short'`(`3 min. ago`)나 `'narrow'`를 넘기세요.

## 최신으로 유지하기

텍스트는 받은 `now`에 맞습니다. 최신으로 유지하려면 `now`를 상태에 두고 타이머로 갱신하세요. 주기는 화면에 보이는 가장 작은 단위에 맞추세요.

```tsx
const [now, setNow] = useState(() => Temporal.Now.instant());

useEffect(() => {
  const timer = setInterval(() => setNow(Temporal.Now.instant()), 60_000);
  return () => clearInterval(timer);
}, []);
```

서버 렌더링과 브라우저의 첫 렌더링은 서로 다른 시계를 읽으므로 텍스트가 다를 수 있습니다. 서버에서 넘겨받은 `now`처럼 서버가 쓴 시각으로 먼저 렌더링하고, 하이드레이션 뒤에 타이머를 시작하세요.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 복수형을 포함해 로캘의 규칙에 따른, 읽는 사람의 언어로 된 텍스트.

**직접 제공할 것:** UTC 시각처럼 기계가 읽을 수 있는 `dateTime`이 있는 `<time>` 요소. `3일 전`은 정확히 언제인지 말해 주지 않으므로, 가까이 보이는 날짜나 포커스할 수 있는 트리거의 [Tooltip](/tooltip)처럼 정확한 시각을 읽을 방법. 페이지에 맞는 `locale`.

**주의할 점:** 라이브 영역 안에서 바뀌는 텍스트는 바뀔 때마다 읽힙니다. 계속 갱신되는 시각은 라이브 영역 밖에 두세요. `title` 속성만으로는 키보드나 터치로 닿을 수 없습니다.

## 언제 쓰나요

**언제:** 메시지, 댓글, 파일의 마지막 수정, 만료처럼 정확한 때보다 얼마나 지났는지가 중요한 시각.

**쓰지 않을 때:** 회의나 마감처럼 읽는 사람이 맞춰 움직여야 하는 시각 → [formatDateTime](/field/date-time-picker)이나 `Intl.DateTimeFormat`.
