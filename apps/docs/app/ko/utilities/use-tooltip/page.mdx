# useTooltip

`useTooltip`은 [Tooltip](/tooltip)의 열림 상태를 다루는 머신입니다. 트리거에는 `getTriggerProps`를, 팁의 외형만 담당하는 `Tooltip.Root`에는 `getTooltipProps`를 펼치세요. 호버는 `showDelay`만큼, 없으면 `tooltip.delay.show` 토큰(기본 300ms)만큼 기다리고, 포커스는 바로 열며, coarse 포인터는 포커스만 씁니다. 호버 팁이 열려 있는 동안, 그리고 마지막 호버 팁이 닫힌 뒤 `skipDelay` 밀리초 동안에는 다음 호버 팁이 바로 열립니다. `skipDelay`의 기본값은 300입니다. 포커스는 그 창을 시작하지 않습니다. 링크가 있는 팁에는 `interactive: true`를 넘기세요. Tab으로 들어갈 수 있는 비모달 팁 dialog가 되며, 이때 `Tooltip.Root`에는 `aria-label`과 `aria-labelledby` 중 정확히 하나가 필요합니다.

`+N` 개수 칩과 버튼이 아닌 다른 트리거는 훅을 직접 씁니다. 탭으로 갈 수 없는 감싸는 요소에는 `tabIndex={0}`을 붙이세요. `Button.Root`는 이미 자신의 레이블을 팁으로 보여 주므로, 훅이 팁을 담당할 때는 그 버튼에 `tooltip={false}`를 설정하세요.

```tsx
const tooltip = useTooltip();
const { moreChips } = useStrings();

<>
  <span {...tooltip.getTriggerProps({ tabIndex: 0 })}>
    <Chip.Root aria-hidden>+2</Chip.Root>
    <VisuallyHidden.Root>{moreChips(2)}</VisuallyHidden.Root>
  </span>
  <Tooltip.Root {...tooltip.getTooltipProps()}>Schema, Docs</Tooltip.Root>
</>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `getTriggerProps`는 포인터와 포커스 핸들러를 더하고, 팁이 열린 동안에는 트리거의 `aria-describedby`에 팁의 id를 더합니다. 직접 넘긴 id 뒤에 붙습니다. 포커스를 받으면 팁이 바로 열리므로 키보드 사용자도 팁을 받습니다. `Tooltip.Root`는 `role="tooltip"`을 더하고, `interactive: true`라면 `role="dialog"`를 더합니다. Escape는 팁을 닫고, 인터랙티브 팁 안에서 누르면 포커스를 트리거로 돌려보냅니다.

**직접 제공할 것:** 포커스를 받는 트리거입니다. 게터는 `tabIndex`나 역할을 더하지 않으므로, 위처럼 탭할 수 없는 래퍼에는 `tabIndex={0}`을 주세요. 트리거 자체의 이름도 필요합니다. `aria-describedby`는 팁을 이름이 아니라 설명으로 만들므로, 아이콘 전용 트리거에는 `aria-label`이 필요합니다. `interactive: true`라면 `Tooltip.Root`에 `aria-label`과 `aria-labelledby` 중 정확히 하나를 주고, 안에는 링크만 두세요.

**주의할 점:** 직접 쓰는 `aria-describedby`, `onFocus`, `onBlur`, `onPointerEnter`, `onPointerLeave`는 `getTriggerProps(props)`로 넘기세요. 스프레드 뒤에 두면 팁의 것을 덮어씁니다. 직접 넘긴 핸들러가 먼저 실행됩니다. `onPointerEnter`나 `onFocus`에서 `event.preventDefault()`를 호출하면 팁이 열리지 않습니다. `onPointerLeave`나 `onBlur`에서 호출해도 팁은 닫힙니다. 훅이 `Button.Root`의 팁을 맡는다면 그 버튼에 `tooltip={false}`를 설정하세요.

## 언제 쓰나요

**언제:** `Button.Root`가 아닌 트리거의 짧은 힌트, 또는 링크가 있는 팁(`interactive: true`).

**쓰지 않을 때:** 아이콘만 있거나 잘린 `Button.Root` → 내장 툴팁. 동작 메뉴 → [Menu](/menu). 다른 앵커 패널 → [usePopover](/utilities/use-popover). 긴 도움말 → Description.
