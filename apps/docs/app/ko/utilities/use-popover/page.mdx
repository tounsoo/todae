# usePopover

`usePopover`는 [Popover](/popover) 뒤에서 열림을 관리하는 상태 기계입니다. 트리거에는 `getTriggerProps`를, 표면 외형만 담당하는 `Popover.Root`에는 `getPopoverProps`를 펼치세요. [Menu](/menu)와 [Combobox 레시피](/recipes/combobox)가 이 훅 위에 만들어져 있습니다.

밖을 누르거나 Escape를 누르면 `outside` 또는 `escape`로 `onOpenChange(false, reason)`을 호출합니다. 트리거는 토글이므로 열 때와 닫을 때 모두 `trigger`를 알립니다. 소유자는 한 가지 이유를 거부하고 나머지는 유지할 수 있습니다. `onOpenChange(open, reason)`에서 `trigger`로 닫힘을 거부하기 전에 `open === false`인지 확인하세요. [Popover](/popover)에 거부 데모가 있습니다. `haspopup`은 트리거의 `aria-haspopup`을 설정합니다. `anchorRef`는 트리거가 `getTriggerProps`가 표시하는 요소가 아닐 때 쓰는 CSS 앵커입니다. 이것을 넘기면서 `getTriggerProps`도 펼치지는 마세요.

```tsx
const [open, setOpen] = useState(false);
const [value, setValue] = useState<string | null>(null);
const { getTriggerProps, getPopoverProps } = usePopover({ open, onOpenChange: setOpen, haspopup: 'listbox' });

<>
  <Button.Root tooltip={false} {...getTriggerProps()}>{value ? `Fruit: ${value}` : 'Choose fruit'}</Button.Root>
  <Popover.Root {...getPopoverProps()}>
    {/* Selecting does not close the popover: the owner closes it. */}
    <OptionList.Root aria-label="Fruit" value={value} onValueChange={(next) => { setValue(next); setOpen(false); }}>
      <OptionList.Option value="apple">Apple</OptionList.Option>
    </OptionList.Root>
  </Popover.Root>
</>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `getTriggerProps`는 `aria-expanded`, 표면의 id를 담은 `aria-controls`, `aria-haspopup`(`haspopup`을 정하지 않으면 `dialog`), 그리고 열고 닫는 `onClick`을 더합니다. 열리면 포커스가 표면 안으로 옮겨 갑니다. `initialFocusRef`로, 없으면 첫 번째 탭 가능한 요소로, 그것도 없으면 표면 자체로 갑니다. Escape와 바깥 누르기는 닫기를 요청합니다. 닫히면 포커스는 `restoreFocusRef`로, 없으면 열기 전에 포커스가 있던 곳으로 돌아갑니다. 단, 사용자가 이미 다른 곳으로 옮겼다면 그대로 둡니다.

**직접 제공할 것:** 트리거 요소입니다. `getTriggerProps`는 역할, `tabIndex`, 키 처리를 설정하지 않으므로 `<button>`이나 `Button.Root`에 스프레드하세요. 표면의 역할과 이름도 필요합니다. `haspopup: 'dialog'`라면 `role="dialog"`와 `aria-label`이나 `aria-labelledby`를 준 `Popover.Root`, `listbox`라면 위처럼 이름 붙은 `OptionList.Root`를 담은 역할 없는 표면입니다. 직접 쓰는 `onClick`, `ref`, `style`은 `getTriggerProps(props)`로 넘기면 합쳐집니다. 직접 넘긴 `onClick`이 먼저 실행되고, 그 안에서 `event.preventDefault()`를 호출하면 열고 닫기를 건너뜁니다. 그래서 `<a href>` 트리거에서 이동을 막는 클릭 핸들러는 팝오버도 막습니다. 대신 `<button>`을 쓰세요.

**주의할 점:** `getTriggerProps()` 스프레드 뒤에 둔 props는 그것이 설정한 것을 덮어씁니다. 뒤에 둔 `onClick`은 열고 닫기를 없앱니다. `enabled`가 false인 동안에도 트리거에는 `aria-expanded`와 `aria-haspopup`이 남으므로, 트리거도 비활성화하세요. 역할 없는 팝오버에 기본 `haspopup`을 그대로 두면 없는 대화 상자를 알립니다.

## 언제 쓰나요

**언제:** 트리거에 고정된 비모달 표면으로, 열기와 닫기는 훅이, 외형은 `Popover.Root`가 맡을 때.

**쓰지 않을 때:** 동작 메뉴 → [Menu](/menu). 모달이고 포커스 트랩이 있는 작업 → Dialog. 모바일 전체 폭 선택기 → BottomSheet, 또는 런타임에 고르려면 [useSheetPresentation](/utilities/use-sheet-presentation). 텍스트만 있는 호버 힌트 → [Tooltip](/tooltip).
