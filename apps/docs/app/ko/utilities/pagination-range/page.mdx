# paginationRange

`paginationRange({ page, count, siblings, boundaries })`는 `count`개 중 `page`에서 보여 줄 페이지를 돌려줍니다. 페이지 번호이며, 생략된 구간은 `"start-ellipsis"`와 `"end-ellipsis"`로 나타냅니다. 현재 페이지와 그 양옆의 `siblings`개 페이지, 양 끝의 `boundaries`개 페이지를 보여 줍니다. 둘 다 기본값은 1입니다. 목록은 [Pagination](/pagination)이 그립니다.

## 늘 같은 길이

페이지가 자리보다 많은 동안에는 목록 길이가 같게 유지되므로, 페이지가 바뀌어도 컨트롤 개수가 그대로이고 포인터 아래에서 아무것도 밀려나지 않습니다. 기본값으로는 일곱 항목입니다. 20페이지 중 1페이지는 `1, 2, 3, 4, 5, end-ellipsis, 20`이고, 10페이지는 `1, start-ellipsis, 9, 10, 11, end-ellipsis, 20`입니다. 생략 구간은 언제나 두 페이지 이상을 나타내므로, 생략 표시가 한 페이지만 가릴 자리에는 그 페이지를 보여 줍니다. 1보다 작은 `count`는 빈 목록을 돌려주고, 1부터 `count` 밖의 `page`는 가까운 끝으로 옮깁니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 화면에 보이는 것은 없습니다. 목록을 돌려줄 뿐입니다. 랜드마크, 현재 페이지, 생략 표시는 [Pagination](/pagination)이 맡습니다.

**직접 제공할 것:** [Pagination](/pagination)에서처럼 페이지 번호마다 링크나 버튼, 그리고 현재 페이지의 `aria-current="page"`.

**주의할 점:** 항목의 키를 순서로 정하는 것. 두 생략 표시가 함께 보일 수 있으므로, 페이지는 번호로, 생략 표시는 이름으로 키를 정하세요.

## 언제 쓰나요

**언제:** [Pagination](/pagination)이나, [Table](/table) 아래 같은 직접 만든 페이지 컨트롤의 페이지 번호.

**쓰지 않을 때:** 페이지 없이 스크롤해 읽는 목록 → 끝에 닿을 때 더 불러오세요.
