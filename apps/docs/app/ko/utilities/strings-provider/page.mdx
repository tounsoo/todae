# StringsProvider

`StringsProvider`는 Todae가 스스로 쓰는 텍스트를 그 안의 모든 요소에 대해 설정합니다. 아이콘만 있는 `Dialog.Close`처럼 자체 글자가 없는 파트의 기본 이름과, `Field.Counter`의 메시지 같은 스크린 리더 메시지가 여기에 속합니다. Todae는 영어만 제공합니다. 바꿀 키만 전달하세요. 생략한 키는 가장 가까운 상위 `StringsProvider`에서, 없으면 영어에서 가져옵니다. 요소는 렌더링하지 않습니다.

```tsx
const korean: Partial<Strings> = {
	close: '닫기',
	dismiss: '닫기',
	removeChip: (label) => `${label} 삭제`,
	moreChips: (count) => `${count}개 더 있음`,
	characterLimit: (max) => `최대 ${max}자`,
	charactersLeft: (remaining) => `${remaining}자 남음`,
	characterLimitReached: '글자 수 한도에 도달했습니다',
}

<StringsProvider strings={korean}>
	<App />
</StringsProvider>
```

중첩한 provider는 자신이 전달한 키만 바꿉니다.

```tsx
<StringsProvider strings={korean}>
	<StringsProvider strings={{ close: '취소' }}>
		{/* close is 취소 here; every other key is still Korean. */}
	</StringsProvider>
</StringsProvider>
```

파트 자체의 prop이 provider보다 여전히 우선합니다. 닫기 버튼, `Attachment.Remove`, `Conversation.ScrollButton`, `Composer.Submit`, 랜드마크의 비어 있지 않은 `aria-label`, `Chip.Root`의 `removeLabel`, `ChipList.Root`의 `removeLabel`, `overflowLabel`, `panelLabel`, `Field.ChipInput`의 `chipRemoveLabel`, `overflowLabel`, `Steps.Item`의 비어 있지 않은 `statusLabel`, `useCombobox`의 `createLabel`이 그렇습니다. `useStrings()`는 현재 적용되는 문자열을 반환하므로 직접 만든 컴포넌트에서 쓸 수 있습니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** Todae가 스스로 쓰는 텍스트를 맡습니다. 닫기 버튼, 랜드마크, 칩과 첨부의 삭제 버튼, `+N` 칩, `Conversation.ScrollButton`의 기본 이름, `useCombobox`가 주는 시트 이름, `Field.Counter`의 설명, `Field.Counter`, `useClipboard`, `Table.SortButton`, `Conversation`의 라이브 메시지, `Steps.Item`의 상태 단어, 그리고 `ErrorMessage.Root`와 `Form.Summary`의 검증 텍스트입니다. 위에 나열한 대로 부분 자체의 prop이 우선합니다.

**직접 제공할 것:** 앱에서 보이는 모든 키를 읽는 사람의 언어로 제공하세요. 함수인 키는 레이블이나 숫자를 받으므로, 언어에 맞는 자리에 넣고 복수형도 거기서 고르세요. `StringsProvider`는 요소를 렌더링하지 않고 `lang`도 설정하지 않습니다. 스크린 리더가 단어를 바르게 발음하도록 `<html>`에, 또는 다른 언어로 된 부분을 감싸는 요소에 `lang`을 설정하세요. 서버 엔트리의 `Breadcrumbs`와 `Pagination`에는 위에서 설명한 대로 `aria-label`을 직접 넘기세요.

**주의할 점:** 빈 문자열을 조심하세요. `undefined`와 달리 위의 문자열을 대신하므로, 자체 텍스트가 없는 닫기 버튼은 Todae가 붙였을 이름을 잃습니다. 텍스트가 보이는 닫기 버튼은 `close`나 `dismiss`로 이름이 붙지 않습니다. 버튼은 자기 텍스트로 이름이 붙고, 키는 쓰이지 않습니다.

## 언제 쓰나요

### StringsProvider

**언제:** 앱이 영어가 아니거나, 앱 전체나 일부에서 Todae 자체 텍스트의 표현을 바꾸고 싶을 때.

**쓰지 않을 때:** 파트 하나의 이름 → `aria-label` 같은 그 파트의 prop을 전달하세요. 대화상자 제목처럼 직접 쓰는 텍스트 → 직접 번역하면 됩니다.

### useStrings

**언제:** 닫기 버튼 이름처럼, Todae 문자열에 있는 텍스트를 쓰는 자체 컴포넌트.

**쓰지 않을 때:** 내 컴포넌트만 쓰는 텍스트 → 직접 번역하세요.
