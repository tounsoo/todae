# Code and Kbd

`Code.Root`는 네이티브 `<code>`, `Code.Block`은 네이티브 `<pre>`, `Kbd.Root`는 네이티브 `<kbd>`이며, `code`와 `kbd` contract 토큰으로 꾸밉니다. Server Components는 `@omsoo.design/todae/code`와 `@omsoo.design/todae/kbd`에서 가져올 수 있습니다.

## Code

`Code.Root`는 주변 텍스트 색을 그대로 쓰고 그 색으로 상자를 옅게 칠합니다. 그래서 링크나 기본 버튼 안에서도 똑같이 읽힙니다. 주변 텍스트보다 한 단계 작습니다. `Code.Block`은 줄이 너무 길면 가로로 스크롤하는 블록이고, 그 안의 코드는 `Code.Root`든 평범한 `<code>`든 자기 상자를 버립니다.

<Example block>
  <CodeInText />
</Example>

```tsx
<Text.Root>
  Call <Code.Root>getPlan()</Code.Root> before you render the billing page.
</Text.Root>
<Code.Block tabIndex={0} role="region" aria-label="Example code">
  <code>{source}</code>
</Code.Block>
```

스크롤하는 `Code.Block`에는 `tabIndex={0}`을 주어 키보드 사용자가 닿아서 스크롤할 수 있게 하고, 그 탭 위치에 이름이 있도록 `role="region"`과 `aria-label`을 주세요. `code.font.family`와 `code.font.scale`(주변 텍스트에 대한 크기 비율)은 인라인 코드와 코드 블록의 글꼴을 함께 정합니다. 인라인 상자는 `code.tint`(텍스트 색을 얼마나 쓰는지), `code.radius`, `code.padding.x`, `code.padding.y`로, 블록은 `code.block` 토큰으로 바꾸세요.

## Kbd

`Kbd.Root`는 키캡으로 그려집니다. 단축키는 HTML이 정한 대로 바깥 `Kbd.Root` 안에 키마다 `Kbd.Root`를 하나씩 넣으세요. 바깥 것은 주변 색 그대로 평범한 텍스트로 남으므로 키를 잇는 `+`에는 상자가 없습니다.

<Example>
  <KbdShortcut />
</Example>

```tsx
<Kbd.Root>
  <Kbd.Root>Ctrl</Kbd.Root>+<Kbd.Root>K</Kbd.Root>
</Kbd.Root>
```

`kbd.fg`, `kbd.bg`, `kbd.border`, `kbd.border-width`, `kbd.radius`, `kbd.font.family`, `kbd.font.scale`, `kbd.padding.x`, `kbd.padding.y`로 바꾸세요.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 모양만 맡습니다. 각 부분은 네이티브 `<code>`, `<pre>`, `<kbd>` 요소 그대로이고, Todae는 role도 `tabindex`도 이름도 더하지 않습니다. `Code.Root`는 주변 텍스트 색을 그대로 씁니다. `Code.Block`은 줄이 너무 길면 옆으로 스크롤되지만, Todae가 포커스를 받게 만들지는 않습니다.

**직접 제공할 것:** 스크롤되는 `Code.Block`에는 위에서 설명한 `tabIndex={0}`, `role="region"`, `aria-label`을 붙이세요. 회사의 코드 블록 컴포넌트는 기본 이름 하나를 채워 넣지 말고 props로 이름을 꼭 받으세요. 복사 버튼을 더한다면 버튼에 이름을 주고, 결과를 알리세요. 예를 들어 [useAnnouncer](/utilities/use-announcer)를 쓸 수 있습니다.

```tsx
type CodeBlockProps = { label: string; children: string };

export function CodeBlock({ label, children }: CodeBlockProps) {
  return (
    <Code.Block tabIndex={0} role="region" aria-label={label}>
      <code>{children}</code>
    </Code.Block>
  );
}
```

**주의할 점:** 모든 블록에 "Code" 같은 기본 이름을 주면 한 페이지에 같은 이름의 영역이 여러 개 생깁니다. 각 블록은 보여 주는 내용으로 이름을 지으세요. `role`과 `aria-label` 없이 `tabIndex={0}`만 붙이면 이름 없는 Tab 정지점이 생깁니다.

## 언제 쓰나요

**쓸 때:** Code → 읽는 사람이 코드에서 입력하거나 읽는 이름, 값, 코드 조각. Kbd → 읽는 사람이 누르는 키나 단축키.

**쓰지 않을 때:** 상태나 개수를 나타내는 레이블 → [Badge](/badge). Mono 글꼴만 필요한 텍스트 → 직접 만든 클래스. 그래야 스크린 리더와 검색이 코드로 다루지 않습니다.
