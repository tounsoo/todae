# Table

`Table.Root`는 `table` contract 토큰으로 스타일을 정한 네이티브 `<table>`입니다. 파트로 표를 만드세요. `Table.Caption`, `Table.Head`, `Table.Body`, `Table.Foot`, `Table.Row`, `Table.HeaderCell`, `Table.Cell`은 각각 `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`를 렌더링하므로, 표는 브라우저가 주는 의미를 그대로 유지합니다. 루트 안의 평범한 요소에는 Todae 스타일이 붙지 않습니다. 숫자는 고정폭 숫자를 써서 자릿수의 폭이 같습니다. 숫자 열에 `text-align: end`를 주면 값이 오른쪽으로 맞춰집니다.

<Example>

```tsx
<Table.Root>
	<Table.Caption>Invoices this quarter</Table.Caption>
	<Table.Head>
		<Table.Row>
			<Table.HeaderCell scope="col">Invoice</Table.HeaderCell>
			<Table.HeaderCell scope="col">Amount</Table.HeaderCell>
		</Table.Row>
	</Table.Head>
	<Table.Body>
		<Table.Row>
			<Table.Cell>INV-1042</Table.Cell>
			<Table.Cell>$1,200.00</Table.Cell>
		</Table.Row>
	</Table.Body>
</Table.Root>
```

Server Components는 `@omsoo/todae/table`에서 가져올 수 있습니다. 모든 열 머리글에는 `scope="col"`을, 모든 행 머리글에는 `scope="row"`를 주세요. `Table.Caption`은 스크린 리더에 표의 이름을 알려 줍니다. `table.border`, `table.rule.thickness`, `table.header.*`, `table.caption.fg`, `table.cell.padding.*`로 스타일을 바꾸세요. 패딩은 밀도를 따릅니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 스타일만 맡습니다. 파트가 렌더링하는 네이티브 `<table>`, `<caption>`, `<th>`, `<td>`는 의미를 그대로 유지하고, Todae는 role, ARIA, 키보드 동작을 더하지 않습니다. 머리글 셀은 자체 굵기와 색을 가지므로 배경색 없이도 눈에 띕니다.

**직접 제공할 것:** 표의 이름. `Table.Caption`이나 제목을 가리키는 `aria-labelledby`로 붙이세요. 위처럼 모든 머리글에 `scope`가 있는 `Table.HeaderCell`. 컨테이너보다 넓은 표라면, 키보드 사용자가 스크롤할 수 있도록 `tabIndex={0}`, `role="region"`, 이름이 있는 스크롤 래퍼.

**주의할 점:** `div`로 그린 표. 보조 기술에는 행도 머리글도 없습니다. 머리글로 쓴 굵은 `Table.Cell` 셀. `Table.Row`에 `onClick`을 걸어 누를 수 있게 만든 행. 포커스를 받지 않으니 셀 안에 링크나 버튼을 넣으세요. `Table.HeaderCell` 안의 `<button>`과 `Table.HeaderCell`의 `aria-sort`가 없는 정렬 열. Todae는 둘 다 더하지 않습니다.

## 언제 쓰나요

**쓸 때:** 행과 열을 가로질러 비교하는 데이터.

**쓰지 않을 때:** 표 형식이 아닌 콘텐츠의 배치 → [Stack](/stack)이나 CSS grid. 정렬, 열 크기 조절, 가상 스크롤, 셀 편집 → Todae의 범위 밖인 데이터 그리드.
