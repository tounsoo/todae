# Table

`Table.Root`는 `table` contract 토큰으로 스타일을 정한 네이티브 `<table>`입니다. 파트로 표를 만드세요. `Table.Caption`, `Table.Head`, `Table.Body`, `Table.Foot`, `Table.Row`, `Table.HeaderCell`, `Table.Cell`은 각각 `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`를 렌더링하므로, 표는 브라우저가 주는 의미를 그대로 유지합니다. 숫자는 고정폭 숫자를 써서 자릿수의 폭이 같습니다. 숫자 열에 `text-align: end`를 주면 값이 오른쪽으로 맞춰집니다.

```tsx
<Table.Root>
  <Table.Caption>Invoices this quarter</Table.Caption>
  <Table.Head>
    <Table.Row>
      <Table.HeaderCell scope="col">Invoice</Table.HeaderCell>
      <Table.HeaderCell scope="col" style={{ textAlign: 'end' }}>
        Amount
      </Table.HeaderCell>
    </Table.Row>
  </Table.Head>
  <Table.Body>
    <Table.Row>
      <Table.HeaderCell scope="row">INV-1042</Table.HeaderCell>
      <Table.Cell style={{ textAlign: 'end' }}>$1,200.00</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table.Root>
```

Server Components는 `@tounsoo/todae/table`에서 가져올 수 있습니다. 모든 열 머리글에는 `scope="col"`을, 모든 행 머리글에는 `scope="row"`를 주세요. `Table.Caption`은 스크린 리더에 표의 이름을 알려 줍니다. `table.border`, `table.rule.thickness`, `table.header.*`, `table.caption.fg`, `table.cell.padding.*`로 스타일을 바꾸세요. 패딩은 밀도를 따릅니다.

## 정렬

정렬할 수 있는 열의 `Table.HeaderCell`에 `sort`를 `'ascending'`, `'descending'`, `'none'` 중 하나로 주고, 그 안에 열의 레이블을 children으로 한 `Table.SortButton`을 넣으세요. 셀에는 `data-sort`가 붙고, 정렬된 열에만 `aria-sort`가 붙습니다. `'none'`은 `aria-sort`를 붙이지 않으므로 `data-sort`만이 그 열이 정렬 가능하다고 표시합니다. Todae는 행을 정렬하지 않습니다. 메모리에서든 요청으로든 직접 정렬하고, `onClick`에서 각 셀의 `sort`를 설정하세요.

```tsx
import { Table, type TableSort } from '@tounsoo/todae';
import { useState } from 'react';

export function Invoices() {
  const [direction, setDirection] = useState<TableSort>('ascending');
  const toggle = () => setDirection(direction === 'ascending' ? 'descending' : 'ascending');

  return (
    <Table.Root>
      <Table.Caption>Invoices this quarter</Table.Caption>
      <Table.Head>
        <Table.Row>
          <Table.HeaderCell scope="col" sort={direction}>
            <Table.SortButton onClick={toggle}>Invoice</Table.SortButton>
          </Table.HeaderCell>
          <Table.HeaderCell scope="col">Status</Table.HeaderCell>
        </Table.Row>
      </Table.Head>
      <Table.Body>…</Table.Body>
    </Table.Root>
  );
}
```

`Table.SortButton`은 네이티브 `<button>`입니다. 레이블 뒤에 [GlyphsProvider](/utilities/glyphs-provider)의 `sort` 글리프를 그리며, 기본은 위를 가리키는 화살표입니다. 정렬된 열에서는 보이고, 내림차순 열에서는 돌아가며, 정렬되지 않은 열에서는 흐리게 보입니다. hover할 수 있는 포인터가 있는 기기에서는 정렬되지 않은 열의 글리프가 hover나 포커스 때만 보입니다. 모양은 헤더 셀의 `data-sort`를 따르므로 `Table.HeaderCell`을 감싼 래퍼도 계속 동작합니다. 클릭하면 사용자가 다음에 무언가를 누르거나 키를 입력하기 전까지(스크린 리더를 멈추는 Control처럼 수정 키만 누르는 것은 세지 않습니다), 코드가 어떻게 바꾸든 셀의 `aria-sort`나 `data-sort`가 바뀌기를 기다렸다가, 결과를 [useAnnouncer](/utilities/use-announcer)로 한 번 알립니다. 열 이름은 버튼의 `aria-label`이나 텍스트이고, 문장은 [StringsProvider](/utilities/strings-provider)의 `sortedAscending`, `sortedDescending`, `sortCleared` 문자열입니다. `Table.SortButton`은 훅이 필요하므로 `@tounsoo/todae/table`이 아니라 `@tounsoo/todae`에서 가져오며, 클라이언트 컴포넌트 안에 둡니다.

## 행 선택

선택 상태는 [useSelection](/utilities/use-selection)과 `Checkbox.Root`입니다. 훅이 선택된 키를 보관하고, 그 getter가 각 체크박스에 props를 줍니다. `getSelectAllProps()`로 만든 헤더 체크박스는 모든 행이 선택되면 체크되고, 일부만 선택되면 혼합 상태가 됩니다. `Table.Row`는 `selected`를 받는데, 이는 `data-selected`와 배경색만 설정합니다. 그리드가 아닌 표의 행에는 `aria-selected`가 맞지 않으므로 더하지 않으며, 보조 기술에는 행의 체크박스가 상태를 전합니다.

```tsx
import { Checkbox, Table, useSelection, VisuallyHidden } from '@tounsoo/todae';

export function Team({ people }: { people: { id: number; name: string }[] }) {
  const selection = useSelection({ keys: people.map((person) => person.id) });

  return (
    <Table.Root>
      <Table.Caption>Team</Table.Caption>
      <Table.Head>
        <Table.Row>
          <Table.HeaderCell scope="col">
            <Checkbox.Root {...selection.getSelectAllProps()}>
              <VisuallyHidden.Root>Select all rows</VisuallyHidden.Root>
            </Checkbox.Root>
          </Table.HeaderCell>
          <Table.HeaderCell scope="col">Name</Table.HeaderCell>
        </Table.Row>
      </Table.Head>
      <Table.Body>
        {people.map((person) => (
          <Table.Row key={person.id} selected={selection.isSelected(person.id)}>
            <Table.Cell>
              <Checkbox.Root {...selection.getCheckboxProps(person.id)}>
                <VisuallyHidden.Root>{`Select ${person.name}`}</VisuallyHidden.Root>
              </Checkbox.Root>
            </Table.Cell>
            <Table.HeaderCell scope="row">{person.name}</Table.HeaderCell>
          </Table.Row>
        ))}
      </Table.Body>
    </Table.Root>
  );
}
```

행의 체크박스를 클릭하면서 Shift를 누르고 있으면, 또는 Shift를 누른 채 Space를 누르면, 마지막으로 토글한 행부터 이 행까지 모든 행이 선택되거나 해제됩니다. 배경색은 `table.row.bg.selected`로 바꾸세요.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 파트가 렌더링하는 네이티브 `<table>`, `<caption>`, `<th>`, `<td>`는 의미를 그대로 유지하고, 스타일은 머리글 셀에 자체 굵기와 색을 주므로 배경색 없이도 눈에 띕니다. `sort`가 있는 `Table.HeaderCell`은 정렬된 열에 `aria-sort`를 설정합니다. `Table.SortButton`은 진짜 버튼이고, 포커스를 받으며, 포커스 링을 보여 주고, 자신이 클릭된 뒤 새 순서를 알립니다. `Table.Row selected`는 행의 스타일만 정하고 ARIA는 설정하지 않습니다.

**직접 제공할 것:** 표의 이름. `Table.Caption`이나 제목을 가리키는 `aria-labelledby`로 붙이세요. 위처럼 모든 머리글에 `scope`가 있는 `Table.HeaderCell`. 컨테이너보다 넓은 표라면, 키보드 사용자가 스크롤할 수 있도록 `axis="inline"`, `focusable`, `aria-label`을 준 [ScrollArea](/scroll-area). 정렬 자체, 그리고 각 행의 체크박스에 어떤 행을 선택하는지 말하는 이름. 예를 들어 "Select Ada Lovelace"이고, 헤더의 체크박스에는 "Select all rows" 같은 이름입니다.

**주의할 점:** `div`로 그린 표. 보조 기술에는 행도 머리글도 없습니다. 머리글로 쓴 굵은 `Table.Cell` 셀. `Table.Row`에 `onClick`을 걸어 누를 수 있게 만든 행. 포커스를 받지 않으니 셀 안에 링크나 버튼을 넣으세요. 둘 이상의 열에 붙은 `aria-sort`. 정렬된 열에는 `sort`를 `'ascending'`이나 `'descending'`으로, 나머지에는 `'none'`으로 주세요. 헤더 셀 밖의 `Table.SortButton`. 글리프와 알림이 읽을 `data-sort`가 없습니다.

## 언제 쓰나요

**쓸 때:** 행과 열을 가로질러 비교하는 데이터. 데이터가 필요로 하면 열 정렬과 행 선택도 함께 씁니다.

**쓰지 않을 때:** 표 형식이 아닌 콘텐츠의 배치 → [Stack](/stack)이나 CSS grid. 열 크기 조절, 가상 스크롤, 셀 편집, 셀 사이의 화살표 키 이동 → Todae의 범위 밖인 데이터 그리드.
