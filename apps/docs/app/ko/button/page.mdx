# Button

`Button.Root`가 컨트롤입니다. `Button.Icon`은 컴파운드 파트입니다. 아이콘 위치는 DOM 순서를 따릅니다. 아이콘은 장식용입니다(`aria-hidden`). 아이콘만 있는 루트는 `Button.Root`에 `aria-label`이나 `aria-labelledby`가 필요합니다.

아이콘만 있는 루트는 그 이름을 팁으로 보여 줍니다. 레이블이 있는 버튼은 레이블이 넘칠 때만 전체 문자열을 팁으로 보여 줍니다. `tooltip={false}`로 끌 수 있습니다. 레이블이 다 들어가는 버튼은 팁을 보여 주지 않습니다. 자동 팁은 절대 인터랙티브가 아닙니다.

변형은 기존 페인트 팩을 씁니다. 기본 `type`은 `button`입니다.

```tsx
<Button.Root onClick={save}>Save</Button.Root>
<Button.Root variant="secondary" onClick={cancel}>
  Cancel
</Button.Root>
<Button.Root variant="ghost">Ghost</Button.Root>
<Button.Root disabled>Disabled</Button.Root>
```

## 토글

`pressed`나 `defaultPressed`를 주면 버튼이 토글이 됩니다. `aria-pressed`를 설정하고 클릭하면 상태가 바뀝니다. `onPressedChange`는 새 상태를 받습니다. 눌린 버튼은 active 색과 안쪽 테두리를 유지합니다. 토글 여러 개를 묶을 때는 [ToggleGroup](/toggle-group)을 쓰세요.

```tsx
<Button.Root variant="secondary" pressed={muted} onPressedChange={setMuted}>
  Mute
</Button.Root>
```

## Button.Group

형제 외형입니다. `role="group"`입니다. 자식은 `Button.Root`입니다. 붙은 가장자리는 테두리 두께만큼 겹치고 바깥 모서리 반경을 공유합니다. 선택 상태는 없습니다.

```tsx
import { AlignLeft } from 'lucide-react';

<Button.Group aria-label="Align">
  <Button.Root variant="secondary" aria-label="Left">
    <Button.Icon>
      <AlignLeft />
    </Button.Icon>
  </Button.Root>
  …
</Button.Group>
```

## 아이콘

`Button.Icon`에는 Lucide, Phosphor, Tabler 같은 어떤 라이브러리의 아이콘도 넣을 수 있습니다. 그 안에 바로 들어간 `svg`나 `img`는 아이콘 자체의 `size`나 `width`와 상관없이 `button.icon.size` 토큰의 크기를 따릅니다. 아이콘만 있는 버튼은 레이블이 있는 버튼과 높이가 같은 정사각형입니다.

```tsx
import { Plus, Settings } from 'lucide-react';

<Button.Root>
  <Button.Icon>
    <Plus />
  </Button.Icon>
  New project
</Button.Root>
<Button.Root variant="ghost" aria-label="Settings">
  <Button.Icon>
    <Settings />
  </Button.Icon>
</Button.Root>
```

## 링크

버튼처럼 보여야 하는 링크도 여전히 링크입니다. 어딘가로 이동하고, Enter로 따라가며, 스크린 리더는 페이지의 링크 목록에 넣습니다. `render`를 넘기고, 받은 props를 그대로 넘긴 링크를 반환하세요. 라우터가 [Link](/link)에 붙는 방식과 같습니다. 버튼은 모습과 아이콘과 팁을 그대로 가지고, 요소는 자기 역할을 그대로 가집니다. 링크는 `type`, `disabled`, `pressed`를 받지 않으므로 `render`와 함께 쓸 수 없습니다. `href`가 없는 `a`는 아무 데도 가지 않으며 비활성 모습으로 보입니다. `render`는 `a`나 `button`을 반환해야 하며, 그 밖의 요소는 개발 모드에서 오류를 기록합니다. 반환하는 `button`은 자기 `type`을 직접 설정합니다.

```tsx
import NextLink from 'next/link';

<Button.Root render={(props) => <NextLink {...props} href="/guides/build-on-todae" />}>
  Get started
</Button.Root>
<Button.Root variant="secondary" render={(props) => <a {...props} href="https://github.com/tounsoo/todae" />}>
  Source
</Button.Root>
```

`Button.Root`는 클라이언트 컴포넌트이므로 서버 컴포넌트는 `render` 함수를 넘길 수 없습니다. 링크는 직접 만든 클라이언트 컴포넌트 안에 쓰고, 그 컴포넌트를 렌더링하세요. 그 컴포넌트의 props는 `Omit<ButtonRenderedProps, 'render'>`에 받을 `href`를 더한 타입으로 정하세요. 그러면 `Button.Root`의 다른 props가 모두 링크에 전달됩니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 네이티브 `<button>`이고 `type="button"`이므로 브라우저의 키보드 동작을 그대로 가지며, `:focus-visible`에서 포커스 링을 보여 줍니다. `render`를 쓰면 요소는 자기 역할을 그대로 가지며, Todae는 역할을 더하지 않습니다. `pressed`는 `aria-pressed`를 설정합니다. `Button.Icon`은 `aria-hidden`입니다. 아이콘만 있는 루트는 `aria-label`이나 `aria-labelledby`의 텍스트를 툴팁으로 보여 주고, 툴팁이 보이는 동안 `aria-describedby`로 연결하며, 이름이 없으면 개발 모드에서 오류를 기록합니다. `Button.Group`은 항상 `role="group"`입니다.

**직접 제공할 것:** 아이콘만 있는 모든 버튼의 이름, 그리고 각 `Button.Group`의 `aria-label`. 버튼이 아이콘만 있을 수 있는 래퍼는 props 타입에서 이름을 필수로 받고, 그 이름을 `aria-label`로 넘기고, 나머지는 펼쳐 전달해서 `ref`와 `disabled`가 버튼에 닿게 해야 합니다.

```tsx
import type { ReactNode } from 'react';
import { Button, type ButtonRootProps } from '@tounsoo/todae';

type IconButtonProps = Omit<ButtonRootProps, 'aria-label' | 'aria-labelledby' | 'children'> & {
  label: string;
  icon: ReactNode;
};

export function IconButton({ label, icon, ...props }: IconButtonProps) {
  return (
    <Button.Root {...props} aria-label={label}>
      <Button.Icon>{icon}</Button.Icon>
    </Button.Root>
  );
}
```

**주의할 점:** 나머지 props를 버려서 `ref`와 ARIA를 잃는 래퍼. 링크 안의 `Button.Root`나 버튼 안의 링크. 인터랙티브 콘텐츠는 중첩할 수 없으니, 대신 `render`로 링크를 버튼으로 그리세요. `aria-pressed`가 바뀔 때 "Mute"에서 "Unmute"로 텍스트까지 바뀌는 토글. 레이블은 하나로 두고 상태는 `pressed`에 맡기세요. 아이콘만 있는 버튼의 `tooltip={false}`. 눈에 보이는 유일한 이름이 사라집니다.

## 언제 쓰나요

### Button.Root

**언제:** 네이티브 버튼 하나로 하는 액션 하나. 변형은 primary / secondary / ghost이고, 기본값은 `type="button"`입니다. 아이콘만 있으면 `aria-label`이 필요하며, 이를 자동으로 팁으로 보여 줍니다.

**쓰지 않을 때:** 글 속의 이동 → [Link](/link). 버튼처럼 보이는 이동 → `render`를 쓴 `Button.Root`. 바로 적용되는 설정 → Switch. 폼의 선택 → Checkbox. 선택된 세그먼트 → ToggleGroup(Button.Group에는 선택 상태가 없음).

### Button.Icon

**언제:** `Button.Root` 안의 장식용 아이콘. 위치 = DOM 순서. 항상 aria-hidden입니다.

**쓰지 않을 때:** 필드 안의 아이콘 → `Field.Icon`. Root에 `aria-label` 없이 아이콘이 유일한 이름일 때. `Button.Root` 바깥.

### Button.Group

**언제:** 서로 관련된 `Button.Root` 액션을 붙여 놓은 가로 행(`role="group"`). `aria-label`로 이름을 붙이세요.

**쓰지 않을 때:** 토글 → ToggleGroup(여기에는 선택 상태가 없음). 세로 행이나 줄바꿈되는 행 → Stack. 관련 없는 액션 → Stack 안의 별도 버튼.
