# Field

공유 외형입니다. `Field.Root`는 컴파운드 스코프입니다. 테두리가 있는 셸이 Root입니다. 값은 `Field.TextInput`, `Field.Textarea`, `Field.ChipInput`에 있습니다. 장식 요소는 순서로만 위치가 정해집니다. `Icon` / `Affix`를 입력 앞에 두면 앞쪽에, 뒤에 두면 뒤쪽에 놓입니다. `side` prop은 없습니다. `Label.Root`은 컴파운드 파트가 아니라 형제 요소입니다. 필드 안의 모든 파트(입력, Icon, Affix, 칩)는 필드 한 줄 높이이고, 셸의 패딩이 안쪽 여백입니다.

## Label

`Label.Root`은 컴파운드 파트가 아니라 형제 요소입니다. `Field.Root`에 넘기는 것과 같은 `id`를 받습니다. 둘을 하나의 `Field.Group`으로 감싸세요. `Field.Group`은 레이블을 셸 위 `field.label.gap` 간격에 둡니다. API는 [Label](/label)을 보세요.

```tsx
const id = useId()

<Field.Group>
	<Label.Root htmlFor={id}>Email</Label.Root>
	<Field.Root id={id}>
		<Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
	</Field.Root>
</Field.Group>
```

## 메시지

[Description](/description)과 [ErrorMessage](/errormessage)는 셸 아래에 형제 요소로 놓입니다. Field 파트가 아닙니다. `aria-describedby`는 `Field.Root`에 두세요. Root가 그 값을 입력에 복사합니다.

```tsx
const describedBy = invalid ? `${hintId} ${errorId}` : hintId

<Field.Group>
	<Label.Root htmlFor={id}>Email</Label.Root>
	<Field.Root id={id} invalid={invalid} aria-describedby={describedBy}>
		<Field.TextInput value={email} onChange={(event) => setEmail(event.target.value)} />
	</Field.Root>
	<Description.Root id={hintId}>Use your work address.</Description.Root>
	{invalid ? <ErrorMessage.Root id={errorId}>{error}</ErrorMessage.Root> : null}
</Field.Group>
```

## Chip input

제어되는 칩과 입력입니다. 필드는 칩을 직접 추가하지 않습니다. 부모의 `onCommit`이 결정합니다. 장식 요소는 칩 흐름 밖, `Field.Root`에 남습니다. ChipInput 안의 칩은 모든 밀도에서 입력과 같은 필드 한 줄 높이입니다. `chipLayout="row"`는 ChipInput 안에서 칩을 입력 위의 전체 너비 줄에 놓습니다. Icon과 Affix는 첫 줄에 놓입니다. 칩이 없으면 `Field.TextInput`과 같은 높이의 한 줄 필드입니다. row에서 `maxRows`는 칩 줄만 세고, 인라인 흐름처럼 잘라 냅니다. `Label.Root htmlFor`나 Root의 `aria-label`로 레이블을 붙이세요.

`maxRows`가 설정되면 흐름은 첫 페인트부터 토큰에서 계산한 줄 수로 제한되고, 첫 레이아웃 측정 전까지 칩을 숨깁니다. 그래서 SSR이 `+N`으로 접히기 전에 펼쳐지지 않습니다. 보이는 영역은 앞쪽 칩들입니다. 가장 새 칩은 `+N`으로 접히고 실제 흐름에서 언마운트됩니다. 이후 칩이 전체 너비로 들어가지 않으면 `+N`으로 옮겨집니다. 첫 칩과 `+N`, 입력이 한 줄을 함께 쓸 수 없으면 첫 칩은 말줄임표로 잘립니다. 접근 가능한 이름은 전체 레이블을 유지합니다.

칩 제거 버튼은 `chipRemoveIcon`을 전달하지 않으면 `close` 글리프를 보여 줍니다. [Chip](/chip)과 같습니다.

## 숫자, 날짜, 시간

## Select

`Field.Select`는 네이티브 `<select>`입니다. `appearance: base-select`를 지원하는 브라우저에서는 버튼과 선택 창을 field, option 토큰으로 그립니다. 그 밖의 브라우저에서는 같은 값과 키보드 동작으로 브라우저 자체 선택 창이 나타납니다. JavaScript listbox는 없습니다. 자식은 네이티브 `<option>`과 `<optgroup>` 요소이며, 다른 필드처럼 `Label.Root htmlFor`로 이름을 붙입니다.

```tsx
<Label.Root htmlFor={id}>Size</Label.Root>
<Field.Root id={id}>
	<Field.Select value={size} onChange={(event) => setSize(event.target.value)}>
		<option value="s">Small</option>
		<option value="m">Medium</option>
	</Field.Select>
</Field.Root>
```

## 아이콘

`Field.Icon`에는 어떤 라이브러리의 아이콘도 넣을 수 있고, 그 안에 바로 들어간 `svg`나 `img`는 `field.icon.size` 토큰의 크기를 따릅니다. `Field.Select`는 브라우저가 `::picker-icon`을 지원하고 select가 필드의 마지막 파트일 때 [GlyphsProvider](/utilities/glyphs-provider)의 `chevron` 글리프를 브라우저의 선택기 아이콘 위에 그립니다. 그렇지 않거나 provider가 없으면 브라우저의 아이콘이 보입니다. 선택된 `<option>` 옆의 체크 표시는 브라우저 자체의 것입니다. `Field.ChipInput`의 칩 제거 버튼은 `chipRemoveIcon`을 전달하지 않으면 `close` 글리프를 보여 줍니다.

```tsx
import { ChevronDown, Search } from 'lucide-react';

<Field.Root aria-label="Search">
	<Field.Icon>
		<Search />
	</Field.Icon>
	<Field.TextInput />
</Field.Root>

<GlyphsProvider glyphs={{ chevron: <ChevronDown /> }}>
	<Field.Root aria-label="Plan">
		<Field.Select value={plan} onValueChange={setPlan}>
			…
		</Field.Select>
	</Field.Root>
</GlyphsProvider>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `Field.Root`는 자신의 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 입력에 넘깁니다. 다른 ARIA props는 셸 `div`에 남습니다. 입력은 Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 셸을 누르면 입력에 포커스가 가고, 입력이 focus-visible인 동안 셸이 포커스 링을 그립니다. 장식용 `Field.Icon`은 `aria-hidden`입니다. `maxLength`가 있으면 `Field.Counter`가 한도를 입력의 설명에 더하고, 20자 남았을 때부터 남은 글자 수를 알립니다. `Field.ChipInput`에서는 각 삭제 버튼이 칩 이름을 따서 이름을 갖고, 칩을 지우면 포커스가 입력으로 돌아갑니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. [Description](/description)이나 [ErrorMessage](/errormessage)의 id는 Root의 `aria-describedby`에 넣고, 오류가 보이는 동안 `invalid`를 켜세요. 상호작용하는 `Field.Icon` 안의 버튼마다 이름을 주세요. 칩과 글자 수 문구는 [StringsProvider](/utilities/strings-provider)로 제품의 언어에 맞추세요.

**주의할 점:** `Field.TextInput`에 준 `id`는 Root의 id로 바뀝니다. id는 Root에 두세요. `Field.Root`에 준 `role`이나 `onClick`은 셸에 붙는데, 셸은 컨트롤이 아닙니다. 오버레이는 실제 버튼으로 여세요. `invalid`는 입력을 유효하지 않다고 표시하지만 이유는 말하지 않으므로 ErrorMessage를 함께 보여 주세요. `commitKeys`에 `'Tab'`을 넣으면 Tab이 포커스를 옮기지 않고 입력한 텍스트를 확정합니다.

## 언제 쓰나요

### Field.Root

**언제:** 텍스트, textarea, 칩 입력 하나를 위한 공유 필드 외형 — 포커스 링, disabled/invalid, 밀도. 값은 입력 파트에 있습니다.

**쓰지 않을 때:** 선택 컨트롤(Checkbox / Radio / Switch). 버튼인 오버레이 트리거. 안에 다른 컴파운드 루트를 중첩할 때.

### Field.TextInput

**언제:** `Field.Root` 안에서 한 줄로 입력하는 값(text / search / email / url / tel / password), 또는 네이티브 숫자, 날짜, 시간.

**쓰지 않을 때:** 여러 값의 토큰 → `Field.ChipInput`. 여러 줄 → `Field.Textarea`. Root 없이 단독으로 쓸 때.

### Field.Textarea

**언제:** 메모, 메시지, 설명 같은 여러 줄 자유 텍스트. `rows`가 시작 높이를 정하고, `autoGrow`는 CSS만으로 `maxRows`까지 늘립니다.
**쓰지 않을 때:** 한 줄 값에는 `Field.TextInput`을 쓰세요. 개별 태그나 토큰에는 `Field.ChipInput`을 쓰세요. 서식 있는 텍스트나 서식 지정은 제공하지 않습니다.

### Field.ChipInput

**언제:** `Field.Root` 안의 제어되는 칩 + 입력 하나. 부모가 `onCommit`으로 확정/추가를 담당하거나, [useChipField](/utilities/use-chip-field)의 `getChipInputProps()`를 펼쳐 그 상태를 보관합니다.

**쓰지 않을 때:** 자유 형식의 단일 문자열 → TextInput. 목록에서 고르는 옵션 → [Combobox 레시피](/recipes/combobox) + OptionList.

### Field.Select

**언제:** 폼 안에서 짧고 고정된 목록 중 값 하나를 네이티브 선택 창과 키보드로 고를 때.

**쓰지 않을 때:** 긴 목록을 필터링하거나 검색 → Combobox 레시피. 여러 값 → Checkbox 또는 `Field.ChipInput`. 값이 아닌 명령 → Menu.

### Field.Icon

**언제:** Root 안의 앞쪽/뒤쪽 아이콘이나 아이콘 컨트롤. 위치 = DOM 순서. 장식용 → `interactive={false}`(aria-hidden).

**쓰지 않을 때:** 텍스트 장식 → Affix. 클릭 가능한 지우기/보기는 전용 Action으로(제공하지 않음).

### Field.Row

**언제:** 필드 안에서 파트를 자체 전체 너비 줄로 묶을 때. 예를 들어 `Field.ChipInput` 위의 칩, 또는 `Field.Textarea` 아래의 첨부, `Field.Counter`, 보내기.

**쓰지 않을 때:** 입력 옆의 Icon이나 Affix 하나는 Row 없이 인라인으로 구성하고, 별개의 필드를 배치하는 데 Row를 쓰지 마세요.

### Field.Group

**언제:** 레이블이나 캡션을 컨트롤 위 `field.label.gap` 간격에 두고, Description이나 ErrorMessage를 그 아래에 쌓을 때. `Field.Root` 바깥에 두며, `Text.Root` 캡션 아래의 RadioGroup처럼 어떤 컨트롤에도 씁니다.

**쓰지 않을 때:** 서로 다른 필드 사이 간격은 `Stack.Root`를 쓰세요. 관련 컨트롤을 범례 하나로 묶을 때는 [Fieldset](/fieldset)을 쓰세요.

### Field.Affix

**언제:** Root 안의 정적 텍스트 장식(통화, 단위). 순서 = 위치.

**쓰지 않을 때:** 아이콘 → Icon. 인터랙티브 컨트롤 — Affix는 클릭할 수 없습니다.

### Field.Counter

**언제:** `Field.TextInput`이나 `Field.Textarea`의 실시간 글자 수를 보여 줄 때. `maxLength`가 설정되면 `n / max`로, 그렇지 않으면 `n`으로 표시합니다.
**쓰지 않을 때:** 글자 수를 보이지 않는 엄격한 제한에는 `maxLength`만 설정하고, 코드나 PIN 같은 짧은 고정 길이 값에는 쓰지 마세요.
