# Field

공유 외형입니다. `Field.Root`는 컴파운드 스코프입니다. 테두리가 있는 셸이 Root입니다. 값은 `Field.TextInput`, `Field.NumberInput`, `Field.OneTimeCode`, `Field.Textarea`, `Field.ChipInput`, `Field.Select`, `Field.ColorPicker`, `Field.DatePicker`, `Field.DateRangePicker`, `Field.TimePicker`, `Field.DateTimePicker`에 있습니다. 장식 요소는 순서로만 위치가 정해집니다. `Icon` / `Affix`를 입력 앞에 두면 앞쪽에, 뒤에 두면 뒤쪽에 놓입니다. `side` prop은 없습니다. `Label.Root`은 컴파운드 파트가 아니라 형제 요소입니다. 필드 안의 모든 파트(입력, Icon, Affix, 칩)는 필드 한 줄 높이이고, 셸의 패딩이 안쪽 여백입니다.

## 입력

입력 파트마다 자체 페이지가 있습니다.

- [Field.TextInput](/field/text-input): 한 줄 텍스트.
- [Field.NumberInput](/field/number-input): 로캘 형식으로 입력하거나 단계로 바꾸는 숫자. 옆에 `Field.Increment`와 `Field.Decrement` 버튼을 둘 수 있습니다.
- [Field.OneTimeCode](/field/one-time-code): 하나의 입력 위에 칸으로 그려지는 로그인·인증 코드.
- [Field.Textarea](/field/textarea): 여러 줄 텍스트.
- [Field.ChipInput](/field/chip-input): 칩과 입력.
- [Field.Select](/field/select): 네이티브 `<select>`.
- [Field.ColorPicker](/field/color-picker): 색 선택기를 여는 견본.
- [Field.DatePicker](/field/date-picker): 단독으로, 또는 날짜를 입력하는 텍스트 입력 옆에서 달력을 여는 버튼.
- [Field.DateRangePicker](/field/date-range-picker): 시작일과 종료일을 고르는 달력을 여는 버튼. 단독으로 쓰거나, 범위를 입력하는 텍스트 입력 옆에 둡니다.
- [Field.TimePicker](/field/time-picker): 시각 목록을 여는 버튼. 단독으로 쓰거나, 시각을 입력하는 텍스트 입력 옆에 둡니다.
- [Field.DateTimePicker](/field/date-time-picker): 달력과 시각 목록을 여는 버튼. 단독으로 쓰거나, 날짜와 시각을 입력하는 텍스트 입력 옆에 둡니다.

## Label

`Label.Root`은 컴파운드 파트가 아니라 형제 요소입니다. `Field.Root`에 넘기는 것과 같은 `id`를 받습니다. 둘을 하나의 `Field.Group`으로 감싸세요. `Field.Group`은 레이블을 셸 위 `field.label.gap` 간격에 둡니다. API는 [Label](/label)을 보세요.

```tsx
const id = useId()

<Field.Group>
	<Label.Root htmlFor={id}>Email</Label.Root>
	<Field.Root id={id}>
		<Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
	</Field.Root>
</Field.Group>
```

</Example>

Label은 Icon, Affix, ChipInput과 함께 동작합니다.

<Example block>

`Affix`는 컨트롤이 아니라 텍스트입니다. 장식용 `Icon`은 `aria-hidden`입니다. 인터랙티브 `Icon`은 이름을 유지합니다. 지우기는 내장 prop이 아닙니다. 지우기 버튼이나 비밀번호 보기 버튼처럼 필드의 줄 안에 버튼을 두려면 입력 앞이나 뒤에 아이콘만 있는 `Button.Root`를 넣으세요. 한 줄 필드에서는 필드 글자 한 줄 높이라서 필드의 높이가 그대로입니다. 입력에 포커스가 있으면 버튼을 눌러도 포커스가 입력에 남아 캐럿이 그대로이고, Tab으로는 여전히 버튼에 갈 수 있습니다. 필드의 컨트롤이 아니라 따로인 버튼이라 `Field.Root`의 `disabled`가 닿지 않으니, 버튼에도 `disabled`를 넘기세요. [Sign-in and sign-up](/recipes/sign-in)에 비밀번호 보기 토글이 있습니다.

## 메시지

[Description](/description)과 [ErrorMessage](/errormessage)는 셸 아래에 형제 요소로 놓입니다. Field 파트가 아닙니다. `aria-describedby`는 `Field.Root`에 두세요. Root가 그 값을 입력에 복사합니다.

```tsx
const describedBy = invalid ? `${hintId} ${errorId}` : hintId

<Field.Group>
	<Label.Root htmlFor={id}>Email</Label.Root>
	<Field.Root id={id} invalid={invalid} aria-describedby={describedBy}>
		<Field.TextInput value={email} onChange={(event) => setEmail(event.target.value)} />
	</Field.Root>
	<Description.Root id={hintId}>Use your work address.</Description.Root>
	{invalid ? <ErrorMessage.Root id={errorId}>{error}</ErrorMessage.Root> : null}
</Field.Group>
```

<Example block>
  <ErrorMessageSibling />
</Example>

이것은 직접 하는 연결입니다. [Form](/form) 안에서는 `Field.Group`이 브라우저 자체의 검증을 읽고, `id` 없는 `ErrorMessage.Root`가 문제를 보여 주면서 이 연결을 대신 해 줍니다.

## Counter

`Field.Counter`는 `Field.TextInput`이나 `Field.Textarea`의 실시간 글자 수를 보여 줍니다. 자체 줄을 차지합니다. 서버 HTML에 글자 수가 포함되도록 입력 뒤에 쓰세요. `Field.Root`마다 Counter는 하나입니다. 입력은 계속 제어 상태이며, `defaultValue`는 읽지 않습니다.

## Row

`Field.Row`는 전체 너비 줄입니다. 입력 앞에 쓰면 위에, 뒤에 쓰면 아래에 놓입니다. 필드에 아래쪽 줄이 있으면 `Field.Counter`를 Row 안에 두세요. 채팅의 프롬프트 입력창이라면 예시처럼 필드를 [Composer](/composer)로 감싸고 `autoGrow`를 쓰세요. Row에 텍스트를 그대로 넣지 말고 `Field.Affix`로 감싸세요. 뒤쪽 항목은 그 첫 항목에 `style={{ marginInlineStart: 'auto' }}`를 주어 끝으로 밀어 냅니다. `Composer.Submit`은 이미 끝에 놓입니다. 칩에는 `chipLayout="row"`를 설정하세요. ChipInput이 자체 칩 줄을 그립니다. `Field.Row` 안에서 칩을 직접 만들지 마세요.

## 커스텀 컨트롤

별점처럼 직접 만든 컨트롤은 [useField](/utilities/use-field)로 `Field.Root`에 연결됩니다.

## 아이콘

`Field.Icon`에는 어떤 라이브러리의 아이콘도 넣을 수 있고, 그 안에 바로 들어간 `svg`나 `img`는 `field.icon.size` 토큰의 크기를 따릅니다. `Field.Select`와 `Field.ChipInput`이 그리는 글리프는 각 파트의 페이지에 있습니다.

```tsx
import { Search } from 'lucide-react';

<Field.Root aria-label="Search">
	<Field.Icon>
		<Search />
	</Field.Icon>
	<Field.TextInput />
</Field.Root>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** `Field.Root`는 자신의 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 입력에 넘깁니다. 다른 ARIA props는 셸 `div`에 남습니다. 입력은 Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 셸을 누르면 입력에 포커스가 가고, 입력이 focus-visible인 동안 셸이 포커스 링을 그립니다. 장식용 `Field.Icon`은 `aria-hidden`입니다. `maxLength`가 있으면 `Field.Counter`가 한도를 입력의 설명에 더하고, 20자 남았을 때부터 남은 글자 수를 알립니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. [Description](/description)이나 [ErrorMessage](/errormessage)의 id는 Root의 `aria-describedby`에 넣고, 오류가 보이는 동안 `invalid`를 켜세요. 상호작용하는 `Field.Icon` 안의 버튼마다 이름을 주세요. 글자 수 문구는 [StringsProvider](/utilities/strings-provider)로 제품의 언어에 맞추세요.

**주의할 점:** `Field.TextInput`에 준 `id`는 Root의 id로 바뀝니다. id는 Root에 두세요. `Field.Root`에 준 `role`이나 `onClick`은 셸에 붙는데, 셸은 컨트롤이 아닙니다. 오버레이는 실제 버튼으로 여세요. `invalid`는 입력을 유효하지 않다고 표시하지만 이유는 말하지 않으므로 ErrorMessage를 함께 보여 주세요.

## 언제 쓰나요

### Field.Root

**언제:** 텍스트, textarea, 칩 입력 하나를 위한 공유 필드 외형 — 포커스 링, disabled/invalid, 밀도. 값은 입력 파트에 있습니다.

**쓰지 않을 때:** 선택 컨트롤(Checkbox / Radio / Switch). 버튼인 오버레이 트리거. 안에 다른 컴파운드 루트를 중첩할 때.

### Field.Icon

**언제:** Root 안의 앞쪽/뒤쪽 아이콘이나 아이콘 컨트롤. 위치 = DOM 순서. 장식용 → `interactive={false}`(aria-hidden).

**쓰지 않을 때:** 텍스트 장식 → Affix. 지우기나 비밀번호 보기 버튼 → Root 안의 아이콘만 있는 `Button.Root`.

### Field.Row

**언제:** 필드 안에서 파트를 자체 전체 너비 줄로 묶을 때. 예를 들어 `Field.ChipInput` 위의 칩, 또는 `Field.Textarea` 아래의 첨부, `Field.Counter`, 보내기.

**쓰지 않을 때:** 입력 옆의 Icon이나 Affix 하나는 Row 없이 인라인으로 구성하고, 별개의 필드를 배치하는 데 Row를 쓰지 마세요.

### Field.Group

**언제:** 레이블이나 캡션을 컨트롤 위 `field.label.gap` 간격에 두고, Description이나 ErrorMessage를 그 아래에 쌓을 때. `Field.Root` 바깥에 두며, `Text.Root` 캡션 아래의 RadioGroup처럼 어떤 컨트롤에도 씁니다. [Form](/form) 안에서는 그 안의 컨트롤에 대한 검증 범위이기도 합니다.

**쓰지 않을 때:** 서로 다른 필드 사이 간격은 `Stack.Root`를 쓰세요. 관련 컨트롤을 범례 하나로 묶을 때는 [Fieldset](/fieldset)을 쓰세요.

### Field.Affix

**언제:** Root 안의 정적 텍스트 장식(통화, 단위). 순서 = 위치.

**쓰지 않을 때:** 아이콘 → Icon. 인터랙티브 컨트롤 — Affix는 클릭할 수 없습니다.

### Field.Counter

**언제:** `Field.TextInput`이나 `Field.Textarea`의 실시간 글자 수를 보여 줄 때. `maxLength`가 설정되면 `n / max`로, 그렇지 않으면 `n`으로 표시합니다.
**쓰지 않을 때:** 글자 수를 보이지 않는 엄격한 제한에는 `maxLength`만 설정하고, 코드나 PIN 같은 짧은 고정 길이 값에는 쓰지 마세요.
