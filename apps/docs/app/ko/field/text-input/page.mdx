# Field.TextInput

`Field.TextInput`은 [Field](/field) 안에서 한 줄 텍스트를 받는 네이티브 `<input>`입니다. `value`는 문자열입니다. 이벤트가 필요하면 `onChange`를, 새 문자열만 필요하면 `onValueChange`를 넘기거나 둘 다 넘기세요. 둘 다 없으면 입력은 읽기 전용입니다. `type`은 `text`, `search`, `email`, `url`, `tel`, `password`를 받습니다. 숫자는 [Field.NumberInput](/field/number-input)입니다. 입력한 날짜, 시각, 날짜와 시각은 [Field.DatePicker](/field/date-picker), [Field.TimePicker](/field/time-picker), [Field.DateTimePicker](/field/date-time-picker) 옆에서 `parseDate`, `parseTime`, `parseDateTime`으로 읽으세요. `id`는 `Field.Root`에 두세요.

```tsx
const id = useId();

<Field.Group>
  <Label.Root htmlFor={id}>Email</Label.Root>
  <Field.Root id={id}>
    <Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
  </Field.Root>
</Field.Group>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** 입력은 `Field.Root`에서 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다.

**주의할 점:** `Field.TextInput`에 준 `id`는 Root의 id로 바뀝니다. id는 Root에 두세요.

## 언제 쓰나요

### Field.TextInput

**언제:** `Field.Root` 안에서 한 줄로 입력하는 값(text / search / email / url / tel / password).

**쓰지 않을 때:** 숫자 → `Field.NumberInput`. 시각 → `Field.TimePicker`. 날짜와 시각 → `Field.DateTimePicker`. 여러 값의 토큰 → `Field.ChipInput`. 여러 줄 → `Field.Textarea`. Root 없이 단독으로 쓸 때.
