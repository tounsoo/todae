# Field.TextInput

`Field.TextInput`은 [Field](/field) 안에서 한 줄 텍스트를 받는 네이티브 `<input>`입니다. `value`는 문자열이고 `onChange`는 필수이며, `onValueChange`도 새 문자열을 받습니다. `type`은 `text`, `search`, `email`, `url`, `tel`, `password`, `number`, `date`, `time`, `datetime-local`을 받습니다. `id`는 `Field.Root`에 두세요.

```tsx
const id = useId();

<Field.Group>
  <Label.Root htmlFor={id}>Email</Label.Root>
  <Field.Root id={id}>
    <Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
  </Field.Root>
</Field.Group>
```

## 숫자, 날짜, 시간

`Field.TextInput`은 `type="number"`, `"date"`, `"time"`, `"datetime-local"`을 받습니다. 브라우저 자체의 스피너, 날짜 선택기, 로캘 형식을 그대로 쓰는 네이티브 입력으로 남으며, 필드 토큰으로 스타일을 입히고 숫자를 세로로 맞춥니다. `value`는 입력의 문자열입니다. `"2"`, `"2026-10-07"`, `"14:30"`이거나, 입력이 덜 끝났을 때는 빈 문자열입니다. 네이티브 `min`, `max`, `step`으로 제한하세요.

```tsx
const id = useId();

<Field.Group>
  <Label.Root htmlFor={id}>Start date</Label.Root>
  <Field.Root id={id}>
    <Field.TextInput type="date" value={date} onChange={(event) => setDate(event.target.value)} />
  </Field.Root>
</Field.Group>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** 입력은 `Field.Root`에서 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다.

**주의할 점:** `Field.TextInput`에 준 `id`는 Root의 id로 바뀝니다. id는 Root에 두세요. 숫자, 날짜, 시간 입력은 값이 덜 끝났을 때 빈 문자열을 알리므로, 사용자가 아직 입력하는 동안 빈 `value`를 지운 필드로 다루지 마세요.

## 언제 쓰나요

### Field.TextInput

**언제:** `Field.Root` 안에서 한 줄로 입력하는 값(text / search / email / url / tel / password), 또는 네이티브 숫자, 날짜, 시간.

**쓰지 않을 때:** 여러 값의 토큰 → `Field.ChipInput`. 여러 줄 → `Field.Textarea`. Root 없이 단독으로 쓸 때.
