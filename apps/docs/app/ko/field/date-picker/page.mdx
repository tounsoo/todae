# Field.DatePicker

`Field.DatePicker`는 [Field](/field) 안에서 [Calendar](/calendar)를 [Popover](/popover)로 여는 버튼입니다. `value`는 `Temporal.PlainDate`나 `null`이고, `onValueChange`는 달력에서 고른 날짜를 받으며, 그러면 달력이 닫힙니다. 달력의 `min`, `max`, `isDateDisabled`, `firstDayOfWeek`, `locale`을 받습니다.

```tsx
const id = useId();
const [date, setDate] = useState<Temporal.PlainDate | null>(null);

<Field.Group>
  <Label.Root htmlFor={id}>Start date</Label.Root>
  <Field.Root id={id}>
    <Field.DateInput value={date} onValueChange={setDate} />
    <Field.DatePicker value={date} onValueChange={setDate} />
  </Field.Root>
</Field.Group>
```

<Example block>
  <FieldDatePicked />
</Example>

여기서는 같은 필드의 [Field.DateInput](/field/date-input)으로 날짜를 입력할 수도 있습니다. 둘은 상태 하나를 함께 쓰므로, 고른 날짜는 입력을 채우고, 입력한 날짜는 달력을 그 달로 옮깁니다. `Field.DateInput` 옆에서는 그 입력이 필드의 컨트롤입니다. 입력이 필드의 `id`, `name`, 설명을 받고, 필드의 다른 곳을 누르면 입력에 포커스가 갑니다. 버튼은 달력 글리프만 보여 주고, Chromium 브라우저에서는 입력 자체의 선택기 버튼이 숨겨집니다.

## 단독으로

단독으로 쓰면 `Field.DatePicker`가 필드의 컨트롤입니다. 날짜를 `locale`의 medium 스타일로, 날짜가 없으면 `placeholder`를 보여 주고, 필드의 다른 곳을 누르면 달력이 열립니다. Root에 `name`이 있으면 숨은 입력이 날짜를 `2026-10-13` 같은 ISO 문자열로 보냅니다.

<Example block>

</Example>

달력은 `open`과 `onOpenChange`, 또는 `defaultOpen`으로 열고 닫습니다. `onOpenChange`는 닫힌 이유를 받습니다. 날짜를 고르면 `'select'`, 그 밖에는 `'escape'`, `'outside'`, `'trigger'`, 필드가 비활성화되면 `'disabled'`입니다. 열리면 달력은 날짜에, 없으면 오늘이나 범위 안의 가장 가까운 날짜에 포커스를 둡니다. Escape를 누르면 닫히고, 포커스는 열리기 전에 있던 곳으로 돌아갑니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 단독으로 쓰면 버튼은 `Field.Root`에서 `id`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 레이블이 버튼의 이름이 되므로, 버튼에 보이는 날짜는 `aria-describedby`에 더해집니다. 날짜 입력처럼 다른 컨트롤이 필드에 함께 있으면 그 컨트롤이 대신 `id`와 `aria-describedby`를 받고, 버튼은 `disabled`와 `aria-invalid`를 유지하며, 자체 `aria-label`이 없으면 [StringsProvider](/utilities/strings-provider)의 `datePicker` 문자열로 이름이 붙습니다. 버튼에는 `aria-haspopup="dialog"`와 `aria-expanded`가, 달력이 열려 있는 동안에는 `aria-controls`가 붙습니다. 팝오버는 `datePicker` 문자열로 이름이 붙은 `role="dialog"`이고, 안의 달력은 [Calendar](/calendar)와 같은 키로 움직입니다. 글리프는 [GlyphsProvider](/utilities/glyphs-provider)의 `calendar`입니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. `Field.DateInput`과 그 옆의 선택기에는 같은 상태를 주세요.

**주의할 점:** 서버 렌더는 버튼 옆에 다른 컨트롤이 있는지 알 수 없으므로, 페이지가 하이드레이션될 때까지 버튼과 그 컨트롤 둘 다 필드의 `id`를 가집니다.

## 언제 쓰나요

### Field.DatePicker

**언제:** 예약이나 마감일처럼 한 달을 보면서 고르는 편이 좋은 폼의 날짜.

**쓰지 않을 때:** 생일처럼 외우고 있는 날짜 → [Field.DateInput](/field/date-input)만. 페이지에 펼쳐 둔 달력 → [Calendar](/calendar). 시각이 있는 날짜 → [Field.DateTimeInput](/field/date-time-input).
