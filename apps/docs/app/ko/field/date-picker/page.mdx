# Field.DatePicker

`Field.DatePicker`는 [Field](/field) 안에서 [Calendar](/calendar)를 [Popover](/popover)로 여는 버튼입니다. `value`는 `Temporal.PlainDate`나 `null`이고, `onValueChange`는 달력에서 고른 날짜를 받으며, 그러면 달력이 닫힙니다. 달력의 `min`, `max`, `isDateDisabled`, `firstDayOfWeek`, `locale`을 받습니다.

```tsx
const id = useId();
const [date, setDate] = useState<Temporal.PlainDate | null>(null);
const [text, setText] = useState('');
const [invalid, setInvalid] = useState(false);

<Field.Group>
  <Label.Root htmlFor={id}>Start date</Label.Root>
  <Field.Root id={id} invalid={invalid}>
    <Field.TextInput
      value={text}
      onChange={(event) => {
        setText(event.target.value);
        setDate(parseDate(event.target.value));
        setInvalid(false);
      }}
      onBlur={() => {
        if (date) setText(formatDate(date));
        else setInvalid(text.trim() !== '');
      }}
    />
    <Field.DatePicker
      value={date}
      onValueChange={(next) => {
        setDate(next);
        setText(formatDate(next));
        setInvalid(false);
      }}
      showValue={false}
    />
  </Field.Root>
</Field.Group>
```

여기서는 같은 필드의 [Field.TextInput](/field/text-input)으로 날짜를 입력할 수도 있습니다. 고른 날짜는 `formatDate`로 텍스트에 쓰이고, `parseDate`가 날짜로 읽은 입력은 달력을 그 달로 옮깁니다. `Field.TextInput` 옆에서는 그 입력이 필드의 컨트롤입니다. 입력이 필드의 `id`, `name`, 설명을 받고, 필드의 다른 곳을 누르면 입력에 포커스가 갑니다. `showValue={false}`이면 버튼은 달력 글리프만 보여 줍니다. 버튼은 자신의 `name`이 있으면 그 이름으로 폼에 날짜를 보냅니다. 없으면 필드의 `name`으로 보내는데, `Field.ColorPicker`, `Field.DatePicker`, `Field.TimePicker`가 아닌 Field 파트나 [`useField`](/utilities/use-field)로 연결한 컨트롤이 그 `name`을 가지고 있으면 보내지 않습니다. 자신의 `name`이 없는 `Field.TextInput`이 그런 경우입니다. 입력한 텍스트 대신 `2026-10-13` 형식으로 날짜를 보내려면 Root 대신 선택기에 `name`을 두세요.

## 입력한 날짜

`formatDate(date, { locale })`는 날짜를 로캘의 숫자로 씁니다. 예: `en-US`에서는 `10/13/2026`, `de`에서는 `13.10.2026`, `ko`에서는 `2026. 10. 13.`. `parseDate(text, { locale })`는 입력한 텍스트를 `Temporal.PlainDate`로 읽고, 날짜가 아니면 `null`을 돌려줍니다. 숫자로 쓴 날짜는 `formatDate`가 쓰는 순서대로 읽고, 글자가 있는 날짜는 `Intl.DateTimeFormat`이 로캘의 `medium`, `long`, `full` 날짜 스타일로 쓰는 대로 읽습니다. 예: `en-US`에서는 `Oct 13, 2026`, `Tuesday, October 13, 2026`. 대소문자는 상관없고, 숫자는 어느 문자 체계의 숫자여도 되며, 부분 사이는 어떤 문장 부호, 기호, 공백으로 나눠도 됩니다. 달은 `Oct`나 `October`처럼 긴 이름이든 짧은 이름이든 됩니다. 요일은 길게 쓰든 짧게 쓰든 빼든 되지만, 그 날짜의 요일이어야 합니다. `13 de octubre de 2026`의 `de`처럼 스타일의 다른 단어는 공백으로 바꿔도 됩니다. `2026-10-13`처럼 네 자리 이상의 연도로 시작하는 숫자 세 개는 연, 월, 일로 읽는데, 로캘이 연도를 앞에 두고 다른 순서로 쓰면 그 순서를 따릅니다. 연도는 로캘의 달력과 상관없이 그레고리력 연도입니다. 한두 자리 연도는 올해에 가장 가까운 그런 해로 읽으므로, 50년쯤 떨어진 날짜는 네 자리를 모두 써야 하고, 세 자리 연도는 읽지 않습니다. `locale`이 없으면 둘 다 런타임의 로캘을 씁니다.

예시에서는 날짜가 아닌 텍스트가 날짜를 비우므로 폼은 날짜를 보내지 않고, 필드는 포커스를 잃을 때 유효하지 않음으로 표시됩니다. `parseDate`는 선택기의 `min`, `max`, `isDateDisabled`를 확인하지 않으므로, 입력한 날짜는 직접 확인하세요.

## 단독으로

단독으로 쓰면 `Field.DatePicker`가 필드의 컨트롤입니다. 날짜를 `locale`의 medium 스타일로, 날짜가 없으면 `placeholder`를 보여 주고, 필드의 다른 곳을 누르면 달력이 열립니다. Root에 `name`이 있으면 숨은 입력이 HTML이 쓰는 형식으로 날짜를 보냅니다. 예: `2026-10-13`.

달력은 `open`과 `onOpenChange`, 또는 `defaultOpen`으로 열고 닫습니다. `onOpenChange`는 닫힌 이유를 받습니다. 날짜를 고르면 `'select'`, 그 밖에는 `'escape'`, `'outside'`, `'trigger'`, 필드가 비활성화되면 `'disabled'`입니다. 열리면 달력은 날짜에, 없으면 오늘이나 범위 안의 가장 가까운 날짜에 포커스를 둡니다. Escape를 누르면 닫히고, 포커스는 열리기 전에 있던 곳으로 돌아갑니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 단독으로 쓰면 버튼은 `Field.Root`에서 `id`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 레이블이 버튼의 이름이 되므로, 버튼에 보이는 날짜는 `aria-describedby`에 더해집니다. 텍스트 입력처럼 `Field.ColorPicker`, `Field.TimePicker`, 다른 `Field.DatePicker`가 아닌 Field 파트나 `useField`로 연결한 컨트롤이 필드에 함께 있으면 그 컨트롤이 대신 `id`와 `aria-describedby`를 받고, 버튼은 `disabled`와 `aria-invalid`를 유지하며, 자체 `aria-label`이 없으면 [StringsProvider](/utilities/strings-provider)의 `datePicker` 문자열로 이름이 붙습니다. 버튼에는 `aria-haspopup="dialog"`와 `aria-expanded`가, 달력이 열려 있는 동안에는 `aria-controls`가 붙습니다. 팝오버는 `datePicker` 문자열로 이름이 붙은 `role="dialog"`이고, 안의 달력은 [Calendar](/calendar)와 같은 키로 움직입니다. 글리프는 [GlyphsProvider](/utilities/glyphs-provider)의 `calendar`입니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. 텍스트 입력과 그 옆의 선택기에는 같은 날짜를 주고, `formatDate`로 쓰고 `parseDate`로 읽으세요.

**주의할 점:** 서버 렌더는 버튼 옆에 다른 컨트롤이 있는지 알 수 없으므로, 페이지가 하이드레이션될 때까지 버튼과 그 컨트롤 둘 다 필드의 `id`를 가지고 필드의 `name`으로 값을 보냅니다. `value`가 있으면 서버는 그 날짜를 서버의 로캘로 쓰므로, 서버에서 렌더링할 때는 `locale`을 넘기세요.

## 언제 쓰나요

### Field.DatePicker

**언제:** 예약이나 마감일처럼 한 달을 보면서 고르는 편이 좋은 폼의 날짜.

**쓰지 않을 때:** 생일처럼 외우고 있는 날짜 → `parseDate`로 읽는 [Field.TextInput](/field/text-input). 페이지에 펼쳐 둔 달력 → [Calendar](/calendar). 시각이 있는 날짜 → [Field.DateTimeInput](/field/date-time-input).
