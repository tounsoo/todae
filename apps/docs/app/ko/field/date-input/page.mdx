# Field.DateInput

`Field.DateInput`은 [Field](/field) 안에서 브라우저 자체의 날짜 선택기와 로캘 형식을 쓰는 네이티브 `<input type="date">`입니다. `value`, `min`, `max`는 `Temporal.PlainDate`이며, `onValueChange`는 `Temporal.PlainDate`를, 입력이 비어 있거나 덜 끝났을 때는 `null`을 받습니다. `PlainDate`에는 시간대가 없으므로 값은 사용자가 고른 그날입니다. `step`은 네이티브 그대로이며 일 단위입니다. `id`는 `Field.Root`에 두세요.

```tsx
const [date, setDate] = useState<Temporal.PlainDate | null>(null)

<Field.Group>
	<Label.Root htmlFor={id}>Start date</Label.Root>
	<Field.Root id={id}>
		<Field.DateInput value={date} onValueChange={setDate} />
	</Field.Root>
</Field.Group>
```

## Temporal

Todae는 Temporal 폴리필을 포함하지 않습니다. `onValueChange`는 `Temporal`로 입력을 읽으므로, 브라우저에 Temporal이 없는 곳에서는 앱이 폴리필을 불러옵니다([네이티브 플랫폼](/platform) 참고). Todae의 타입에는 `Temporal`을 선언하는 TypeScript 6 이상이 필요합니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 입력은 `Field.Root`에서 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 키보드와 선택 창은 브라우저가 처리합니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. `onChange`나 `onValueChange`도 주세요. 둘 다 없으면 입력은 읽기 전용입니다.

**주의할 점:** 사용자가 아직 입력을 채우는 동안 `onValueChange`는 `null`을 받으므로, 사용자가 입력을 떠나기 전에는 `null`을 지운 필드로 다루지 마세요.

## 언제 쓰나요

### Field.DateInput

**언제:** 시작일이나 생일처럼 달력의 날짜 하나를 브라우저 날짜 선택기로 받을 때.

**쓰지 않을 때:** 시각이 있는 날짜 → `Field.DateTimeInput`. 연월만처럼 일부만 있는 날짜 → `Field.TextInput`. 페이지에 계속 펼쳐 두는 달력 그리드는 이 입력을 중심으로 앱에서 조합할 부분입니다.
