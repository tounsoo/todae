# Field.DateInput

`Field.DateInput`은 [Field](/field) 안에서 날짜를 로캘의 방식대로 입력하는 텍스트 입력입니다. `value`는 `Temporal.PlainDate`나 `null`입니다. 텍스트는 확정될 때, 즉 포커스를 잃을 때, Enter를 누를 때, 폼을 제출할 때 읽고, `formatDate`가 쓰는 대로 다시 쓴 뒤 그 날짜로 `onValueChange`를 호출합니다. 입력하는 것만으로는 아무것도 호출하지 않습니다. `onValueChange`가 없으면 입력은 읽기 전용입니다. `min`, `max`, `required`, `locale`, `placeholder`와, 이들과 충돌하지 않는 네이티브 input 속성을 받습니다.

여기서는 입력 옆의 [Field.Picker](/field/picker)가 [Calendar](/calendar)를 [Popover](/popover)로 엽니다. 입력과 달력이 같은 `value`와 `onValueChange`를 받으므로, 입력한 날짜는 달력을 그 달로 옮기고, 고른 날짜는 텍스트에 쓰이며 팝오버를 닫습니다. 패널의 값은 직접 넘깁니다. 선택기는 패널을 열고 닫기만 합니다. `Field.DateInput` 옆에서 선택기의 버튼은 달력 글리프를 보여 주고 `datePicker` 문자열로 이름이 붙습니다.

## 입력한 날짜 {/*#typed-dates*/}

`formatDate(date, { locale })`는 날짜를 로캘의 숫자로 씁니다. 예: `en-US`에서는 `10/13/2026`, `de`에서는 `13.10.2026`, `ko`에서는 `2026. 10. 13.`. `parseDate(text, { locale })`는 입력한 텍스트를 `Temporal.PlainDate`로 읽고, 날짜가 아니면 `null`을 돌려줍니다. 숫자로 쓴 날짜는 `formatDate`가 쓰는 순서나 로캘의 `short` 날짜 스타일의 순서로 읽습니다. 예: `formatDate`가 `2026-10-13`으로 쓰는 `gsw`에서 `13.10.26`. 두 순서 모두 날짜로 읽히면 네 자리 이상의 연도는 `formatDate`의 순서로 읽고, 한두 자리 연도는 `short` 스타일이 연도를 두 자리로 쓸 때 그 스타일의 순서로 읽습니다. 글자가 있는 날짜는 `Intl.DateTimeFormat`이 로캘의 `medium`, `long`, `full` 날짜 스타일로 쓰는 대로 읽습니다. 예: `en-US`에서는 `Oct 13, 2026`, `Tuesday, October 13, 2026`. 대소문자는 상관없고, 숫자는 어느 문자 체계의 숫자여도 되며, 부분 사이는 어떤 문장 부호, 기호, 공백으로 나눠도 됩니다. 달은 `Oct`나 `October`처럼 긴 이름이든 짧은 이름이든 됩니다. 요일은 길게 쓰든 짧게 쓰든 빼든 되지만, 그 날짜의 요일이어야 합니다. `13 de octubre de 2026`의 `de`처럼 스타일의 다른 단어는 공백으로 바꿔도 됩니다. `2026-10-13`처럼 네 자리 이상의 연도로 시작하는 숫자 세 개는 연, 월, 일로 읽는데, 로캘이 연도를 앞에 두고 다른 순서로 쓰면 그 순서를 따릅니다. 연도는 로캘의 달력과 상관없이 그레고리력 연도입니다. 한두 자리 연도는 올해에 가장 가까운 그런 해로 읽으므로, 50년쯤 떨어진 날짜는 네 자리를 모두 써야 하고, 세 자리 연도는 읽지 않습니다. `locale`이 없으면 둘 다 런타임의 로캘을 씁니다.

`Field.DateInput`은 자신의 `locale`로 텍스트를 `parseDate`로 읽고 `formatDate`로 씁니다. 빈 텍스트는 `null`로 확정됩니다. 날짜가 아닌 텍스트는 입력한 그대로 남고, `onValueChange`는 호출되지 않으며, 확정하면서 읽으려다 실패한 뒤에는 필드가 유효하지 않음으로 표시됩니다. 텍스트가 날짜이거나 비어 있을 때까지 폼은 제출되지 않습니다. 입력하는 동안 제품이 정한 `value`는 텍스트를 바꾸고, 폼을 재설정하면 입력하던 텍스트는 사라집니다. 직접 만든 텍스트 입력에는 [Field.TextInput](/field/text-input)에서도 `formatDate`와 `parseDate`를 쓸 수 있습니다.

## 단독으로

단독으로 쓰면 `Field.DateInput`이 버튼 없이 필드의 컨트롤입니다. 날짜를 외우고 있는 사람은 그대로 입력하고, 입력을 벗어나면 텍스트는 로캘의 숫자로 다시 쓰입니다.

<Example of={FieldDateInputAlone} block />

날짜는 텍스트 입력 옆의 네이티브 `<input type="date">`에 담겨, 필드의 `name`이나 입력 자체의 `name`으로, HTML이 쓰는 형식으로 폼과 함께 전송됩니다. 예: `2026-10-13`. 텍스트 입력은 아무것도 보내지 않습니다. 네이티브 입력은 화면과 보조 기술에서 숨겨지고 탭 정지점이 아닙니다. `required`는 날짜가 없는 폼을, `min`과 `max`는 그보다 이르거나 늦은 날짜가 있는 폼을 유효하지 않게 하며, 브라우저가 네이티브 입력에서 세 가지를 모두 검사합니다. 날짜가 아닌 텍스트도 제출을 막습니다. [Form.Root](/form) 안에서는 문제가 필드의 `ErrorMessage.Root`에 페이지의 언어로 나타나고 `min`이나 `max`는 `formatDate`가 날짜를 쓰는 방식으로 표기되며, 포커스는 텍스트 입력으로 갑니다. `Form.Root` 밖에서도 브라우저가 제출을 막고, 포커스는 마찬가지로 텍스트 입력에 놓입니다. 네이티브 날짜 입력은 1년부터 275760년까지만 담을 수 있으므로, 그 밖의 값이나 범위는 날짜 없음으로 읽힙니다. 빈 값으로 전송되고 `required`, `min`, `max`는 이를 무시하며, 개발 빌드는 한 번 경고합니다. Calendar의 `isDateDisabled`는 검사에 포함되지 않습니다. 그것이 막는 날짜도 입력하면 날짜이므로, 직접 확인하고 `Field.Root`에 `customValidity`를 설정하세요.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 텍스트 입력은 `Field.Root`에서 `id`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 확정할 때 텍스트를 읽지 못하면 `aria-invalid`가, `required`가 있으면 `aria-required`가 붙습니다. IME 조합 중의 Enter는 아무것도 확정하지 않습니다. [Field.Picker](/field/picker) 옆에서도 입력이 필드의 컨트롤이고, 선택기의 버튼은 [StringsProvider](/utilities/strings-provider)의 `datePicker` 문자열로 이름이 붙으며 [GlyphsProvider](/utilities/glyphs-provider)의 `calendar` 글리프를 보여 줍니다. 읽기 전용이면 입력을 누를 때 선택기가 열립니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. 입력과 그 옆의 Calendar에 같은 날짜, 같은 `locale`, `min`, `max`를 주세요.

**주의할 점:** `value`가 있으면 서버는 그 날짜를 서버의 로캘로 쓰므로, 서버에서 렌더링할 때는 `locale`을 넘기세요. 가장 가까운 해로 읽힌 두 자리 연도처럼, 날짜로 읽히지만 뜻한 날짜가 아닌 텍스트도 있습니다. 중요할 때는 날짜를 글로 옆에 보여 주세요.

## 언제 쓰나요

### Field.DateInput

**언제:** 마감일, 예약, 생일처럼 폼에서 입력하거나, 옆의 [Field.Picker](/field/picker)와 Calendar로 한 달을 보며 고르는 날짜.

**쓰지 않을 때:** 페이지에 펼쳐 둔 달력 → [Calendar](/calendar). 시작일과 종료일 → [Field.DateRangeInput](/field/date-range-input). 시각이 있는 날짜 → [Field.DateTimeInput](/field/date-time-input).

### formatDate

**언제:** 직접 만든 텍스트 입력처럼, 날짜를 로캘에 맞는 텍스트로 쓸 때.

**쓰지 않을 때:** 요일이나 월 이름이 있는 날짜 → `Intl.DateTimeFormat`.

### parseDate

**언제:** 사람이 입력한 날짜를 읽을 때.

**쓰지 않을 때:** `2026-10-13`처럼 형식이 정해진 텍스트 → `Temporal.PlainDate.from`.
