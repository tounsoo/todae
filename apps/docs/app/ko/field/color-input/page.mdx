# Field.ColorInput

`Field.ColorInput`은 [Field](/field) 안의 네이티브 `<input type="color">`이며, 필드 한 줄 높이의 색 견본으로 그려집니다. 값은 `#rrggbb` 문자열입니다. 필드의 다른 곳을 눌러도 브라우저의 선택 창이 열립니다. 값을 텍스트로 보이려면 뒤에 `Field.Affix`를 두세요. 혼자 있으면 필드 너비는 견본 너비와 같습니다.

```tsx
<Label.Root htmlFor={id}>Accent</Label.Root>
<Field.Root id={id}>
	<Field.ColorInput value={color} onValueChange={setColor} />
	<Field.Affix>{color}</Field.Affix>
</Field.Root>
```

## 접근성을 지키는 조합

**Todae가 맡는 것:** 입력은 `Field.Root`에서 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 필드의 다른 곳을 마우스로 누르면 입력에 포커스가 가고, 브라우저가 허용하면 선택 창이 열립니다. 키보드와 선택 창은 브라우저가 처리합니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. `onChange`나 `onValueChange`도 주세요. 둘 다 없으면 입력은 읽기 전용입니다.

**주의할 점:** 견본은 색을 보여 주지만 값은 보여 주지 않습니다. 값을 읽어야 한다면 `Field.Affix`에 넣으세요.

## 언제 쓰나요

### Field.ColorInput

**언제:** 브랜드나 강조 색처럼 색 하나를 브라우저 선택 창으로 고를 때.

**쓰지 않을 때:** `oklch()`처럼 다른 형식의 색 → `Field.TextInput`, 고르기용으로 옆의 별도 필드에 `Field.ColorInput`. 정해진 색 몇 가지 → RadioGroup.
