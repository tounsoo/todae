# Field.TimeInput

`Field.TimeInput`은 [Field](/field) 안에서 브라우저 자체의 시간 선택기와 로캘 형식을 쓰는 네이티브 `<input type="time">`입니다. `value`, `min`, `max`는 `Temporal.PlainTime`이며, `onValueChange`는 `Temporal.PlainTime`을, 입력이 비어 있거나 덜 끝났을 때는 `null`을 받습니다. `PlainTime`에는 날짜와 시간대가 없습니다. `step`은 네이티브 그대로이며 초 단위입니다. `id`는 `Field.Root`에 두세요.

```tsx
const id = useId();
const [time, setTime] = useState<Temporal.PlainTime | null>(null);

<Field.Group>
  <Label.Root htmlFor={id}>Start time</Label.Root>
  <Field.Root id={id}>
    <Field.TimeInput value={time} onValueChange={setTime} />
  </Field.Root>
</Field.Group>
```

## 날짜와 시각

회의 시작처럼 사용자 시계의 날짜와 시각은 [Field.DatePicker](/field/date-picker)와 `Field.TimeInput`을 각자의 필드에 두고 [Fieldset](/fieldset)으로 묶습니다. 둘 다 정해지면 `date.toPlainDateTime(time)`이 둘을 `Temporal.PlainDateTime`으로 합칩니다. 이 값에는 시간대가 없습니다. 특정 순간으로 저장하려면 `dateTime.toZonedDateTime(zone)`처럼 직접 작성한 코드에서 시간대와 합치세요.

```tsx
const dateId = useId();
const timeId = useId();
const [date, setDate] = useState<Temporal.PlainDate | null>(null);
const [time, setTime] = useState<Temporal.PlainTime | null>(null);
const start = date && time ? date.toPlainDateTime(time) : null;

<Fieldset.Root>
  <Fieldset.Legend>Meeting starts</Fieldset.Legend>
  <Stack.Root direction="row">
    <Field.Group>
      <Label.Root htmlFor={dateId}>Date</Label.Root>
      <Field.Root id={dateId}>
        <Field.DatePicker value={date} onValueChange={setDate} placeholder="Pick a date" />
      </Field.Root>
    </Field.Group>
    <Field.Group>
      <Label.Root htmlFor={timeId}>Time</Label.Root>
      <Field.Root id={timeId}>
        <Field.TimeInput step={900} value={time} onValueChange={setTime} />
      </Field.Root>
    </Field.Group>
  </Stack.Root>
</Fieldset.Root>
```

## Temporal

Todae는 Temporal 폴리필을 포함하지 않습니다. `onValueChange`는 `Temporal`로 입력을 읽으므로, 브라우저에 Temporal이 없는 곳에서는 앱이 폴리필을 불러옵니다([네이티브 플랫폼](/platform) 참고). Todae의 타입에는 `Temporal`을 선언하는 TypeScript 6 이상이 필요합니다.

## 접근성을 지키는 조합

**Todae가 맡는 것:** 입력은 `Field.Root`에서 `id`, `name`, `aria-label`, `aria-labelledby`, `aria-describedby`를 받고, Root나 바깥 [Fieldset](/fieldset)에서 네이티브 `disabled`와 `aria-invalid`를 받습니다. 키보드와 선택 창은 브라우저가 처리합니다.

**직접 제공할 것:** 이름. `htmlFor`가 Root `id`인 [Label](/label)이나, Root의 `aria-label` / `aria-labelledby`입니다. `onChange`나 `onValueChange`도 주세요. 둘 다 없으면 입력은 읽기 전용입니다.

**주의할 점:** 사용자가 아직 입력을 채우는 동안 `onValueChange`는 `null`을 받으므로, 사용자가 입력을 떠나기 전에는 `null`을 지운 필드로 다루지 마세요.

## 언제 쓰나요

### Field.TimeInput

**언제:** 영업시간이나 매일 알림처럼 날짜 없는 하루 중 시각.

**쓰지 않을 때:** 특정 날의 시각 → 위처럼 `Field.DatePicker` 옆에 이 입력을 둡니다. 기간 → `type="number"`인 `Field.TextInput`과 단위를 보여 주는 `Affix`.
