import { Chip } from '@tounsoo/todae';

# Chip

Text-only label. Optional dismiss is a named button. `Chip.Overflow` is display-only `+N`.

<Example>
  <Chip>Default</Chip>
  <Chip onDismiss={() => undefined}>Dismissible</Chip>
  <Chip disabled onDismiss={() => undefined}>
    Disabled
  </Chip>
  <Chip.Overflow overflowCount={4} />
</Example>

`+N` is not a button and is not in the tab order.
