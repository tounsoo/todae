# Field

Shared chrome. `Field.Root` is the compound scope. The bordered shell is Root. Value lives on `Field.TextInput` or `Field.ChipInput`. Adornments are order-only: put `Icon` / `Affix` before the input to lead, after to trail. No `side` prop. `Label` is a sibling, not a compound part.

## Label

`Label` is a sibling, not a compound part. It takes the same `id` you pass to `Field.Root`. Wrap the pair in one `.labelled-field`. The gap is `field.label.gap`. See [Label](/label) for the API.

```tsx
const id = useId()

<div className="labelled-field">
	<Label htmlFor={id}>Email</Label>
	<Field.Root id={id}>
		<Field.TextInput value={v} onChange={(event) => setV(event.target.value)} />
	</Field.Root>
</div>
```

## Messages

[Description](/description) and [ErrorMessage](/errormessage) are siblings under the shell. They are not Field parts. Put `aria-describedby` on `Field.Root`. Root copies it onto the input. Do not set it on `Field.TextInput`.

```tsx
const describedBy = invalid ? `${hintId} ${errorId}` : hintId

<div className="labelled-field">
	<Label htmlFor={id}>Email</Label>
	<Field.Root id={id} invalid={invalid} aria-describedby={describedBy}>
		<Field.TextInput value={email} onChange={(event) => setEmail(event.target.value)} />
	</Field.Root>
	<Description id={hintId}>Use your work address.</Description>
	{invalid ? <ErrorMessage id={errorId}>{error}</ErrorMessage> : null}
</div>
```

## Chip input

Controlled chips plus input. The field never appends chips. Parent `onCommit` decides. Adornments stay on `Field.Root`, outside the chip flow.

When `maxRows` is set, the flow clamps to that many token-derived rows from the first paint and hides chips until the first layout measure, so SSR does not unfold before `+N` fold. The visible window is the leading prefix; newest chips fold into `+N` and unmount from the live flow. When chips overflow, the last visible chip ellipsizes to soak leftover width before `+N`; earlier chips stay full and `+N` never shrinks.

Deferred this slice: built-in clear, paste-split, clickable `+N`, chip arrow-key roving.
